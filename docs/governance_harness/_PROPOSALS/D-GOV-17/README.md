Status: `PROPOSED — AWAITING OWNER RULING`

This package stages the canonical model-capability doctrine for the D-GOV-17
ruling. The doctrine bytes are inactive until ruled; on an M1-A or M1-B
ruling, a controlled implementation places the exact proposed bytes in the
ruled home and verifies them against the pin below. The decision record
(M1–M4 slate) is
`docs/governance_harness/_DECISIONS/D-GOV-17_model_capability_doctrine.md`.

The doctrine is a generic redraft of the app-dev "Runtime capability
convention" (`projects/chirality-app-dev/AGENTS.md`, owner-revised
2026-07-12; re-homed under D-APP-61 M3-C) plus the capability-invariance
principle. It deliberately contains no project identifiers, paths, dates, or
project-local references; project-local history (rescinded steers, receipt
citations) remains in each adopting project's own binding.

No implementation is performed by ruling publication alone. Matters M2–M4 in
the decision record are dispositions and template/CONTRACT edits enumerated
there; they carry no staged bytes in this package.
