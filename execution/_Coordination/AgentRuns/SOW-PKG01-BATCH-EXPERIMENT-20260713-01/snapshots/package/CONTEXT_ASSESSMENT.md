# Context-Length and Task-Adherence Assessment

Package verdict: `NO OBSERVABLE CONTEXT DEGRADATION IN THIS THREE-MEMBER RUN`

The author completed the three members in numeric order with the same
seven-stage checkpoint family for each. Mapping/line coverage was 26/204,
34/290, and 28/233. Members 2 and 3 had zero author retries and complete
artifact families; member 3 was not abbreviated.

The fresh verifier emitted the same 103-file evidence inventory for every
member. Members 2 and 3 each completed the full nine-stage sequence on the
first attempt. Member-specific hashes, scope refs, objective refs, seeds,
candidates, and workspaces remained isolated; no wrong-reference reuse or
cross-member contamination was detected.

The author authority mismatch and verifier shell-quote restart occurred on
member 1, not late in either batch. Their proved causes are setup/tool-interface
and local harness defects, not progressive context loss. The manager's own
schema-key and portability reruns, plus the final overbroad parent-manifest
self-exclusion assertion, likewise concern evidence tooling rather than child
drift.

Native token counts and exact context-window occupancy were unavailable. The
experiment therefore uses sequence, equal evidence classes, member-specific
bindings, retry rates, brief re-reads, and terminal completeness as proxies.
Those proxies pass for three members. This result does not establish a safe
upper batch-size or source-volume bound.

Compared with the ordinary per-deliverable model, Agent-2 session count for
these three members fell from six sessions to two while retaining complete
per-member checks. The model is viable at PKG-01 size, but a reusable
package-harness interface should freeze the exact D-GOV-16 token, validate
shell syntax before execution, bind the parity schema, and normalize paths by
construction. Its manifest verifier should compare the exact current manifest
path rather than reject nested manifests. These controls are advisable before
treating the model as reliably more efficient.
