# software-decomp

Organize software intent into cohesive work domains and implementable bounded contexts.

WORKING_ITEMS coordinates this undertaking and assigns bounded contributions to TASK.

## Method

1. Extract atomic scope, objectives, dependencies, and unresolved decisions from the accepted software intent.
2. Define flat Packages and Deliverables, judging semantic coupling and verification demands.
3. Specify each Context Envelope, artifacts, interfaces, acceptance, and source mappings through the seven gates.
4. Ratify the decomposition and emit stable identifiers and a handoff suitable for bounded implementation.
