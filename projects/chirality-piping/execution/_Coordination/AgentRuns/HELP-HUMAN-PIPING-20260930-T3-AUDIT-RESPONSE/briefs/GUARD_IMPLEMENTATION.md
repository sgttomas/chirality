## ROOT's implementation decisions

1. Use a lightweight standalone standard-library Python tool. Invocation with
   explicit job parameters and a single-heavy-slot lock is ROOT's run grant.
   Do not create a new human approval-token interface, persistent network
   service, scheduler, broad cleanup mechanism or global configuration change.
2. Use a separate supervisor session/process group and a private authenticated
   control channel. Prefer asking the still-live supervisor to stop **its own**
   group over signaling a remembered numeric PGID from outside. Preserve live
   PID/start identity, UID and group/session checks. Prevent the supervisor's
   TERM behavior from being inherited as ignored TERM by workers.
3. The monitor stays outside the owned workload group. Guard/heartbeat loss
   must stop the owned workload through a validated path. No directory or
   command substring, old PID, pgrep/pkill or user-wide kill grants ownership.
   Unknown/recycled identities must not trigger a blind signal.
4. Scope initial qualification to commands whose children remain in the owned
   group. Document that historical K6/VR runners deliberately create process
   groups; those runners are **not qualified by this initial scope**. Propose
   the minimal later explicit registration/containment adapter before admitting
   them, without silently changing their existing watchdog or heap backstop.
5. Providers must distinguish live RSS, live physical footprint, system memory
   availability, pressure and swap baseline/deltas. `time -l` is additional
   post-run evidence, not a live footprint provider. Inspect the installed SDK
   declarations for libproc/ctypes layouts if using them; no copied guessed ABI.
   Unknown/denied/malformed/stale readings fail closed. ROOT has shown host
   visibility outside the default sandbox; do not describe the sandbox denial
   as a machine capability absence.
6. Start with explicit caps no higher than 2 GiB for an observation group and
   conservative stop/admission thresholds from E0 (35% reserve, proposed 40%
   early-stop threshold). Treat any adjustment as a recorded ROOT operating
   decision. Do not disable the observation binary's independent backstop or
   conflate heap and process memory. Compile jobs need their own grant.
7. Write complete job/metric/stop evidence under an owned runtime log directory.
   Keep raw host paths in local runtime logs only; supply sanitized evidence
   and raw hashes for the repository. Bound logging and avoid accumulating
   unbounded child output in the monitor's memory.
