# Narrow historical pressure regression route proposal

Not implemented. Root permits a private test-only adapter for genuine historical pressure regressions; this proposal is for per-test independent review after the core source backcheck. No shared fixture wrapper changes.

A named adapter should exist only under cfg(test), accept only explicitly legacy model versions/profile, and bypass only the prospective fresh-legacy-pressure refusal while retaining the original historical arithmetic. It must expose no model/request field, public API, runtime feature/permission bit, native/headless selector or fallback from failed exact validation. Prefer a scoped test-only execution guard with restoration on unwind and explicit calls at individually reviewed historical assertions, or an equally constrained independent historical test crate. Do not change global request() or alter original fixture bytes.

Current public integration tests link the normal library with the historical route absent and must continue proving PRESSURE_MODEL_REAUTHOR_REQUIRED, including identical old requests. Each retained historical test explicitly states its premise and cannot establish Current qualification. Every non-pressure test instead needs its own justified current input and assertion treatment; source-defined pressure rows are never silently discarded by the solver.

The material/current numerical-source interface must be reassessed when NUM integrates: a passing historical pressure test does not imply preserved old numerical execution or serializer compatibility unless that specific old recipe/basis is actually retained. Do not use a changed common engine to claim byte-faithful historical replay. Immutable saved-result binding tests remain distinct from recalculating old-premise mechanics.
