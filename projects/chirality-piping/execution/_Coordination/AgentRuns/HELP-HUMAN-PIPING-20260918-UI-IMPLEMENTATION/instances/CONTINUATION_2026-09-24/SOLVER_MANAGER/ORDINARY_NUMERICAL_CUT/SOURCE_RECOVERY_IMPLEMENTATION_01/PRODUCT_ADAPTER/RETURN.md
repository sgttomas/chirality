`solve(Input, exact::Limits)` accepts the actual authored/built invocation, full aggregate stiffness/force, complete free/prescribed partition, spring entries and actual load application plus thermal/pressure inventories. It returns an owned `SelectedSourceRecovery` or `RecoveryFailure` with exact cause, adapter stage, helper stage and cumulative charged/denied work. Ordinary factorization success is not an input or precondition.

The source-owning gate rejects nonlinear/contact, user/curved/component sources, generated/distributed/thermal/pressure/constant-effort/imposed-load producers, including their zero-valued presence. It verifies every identified nodal contribution against authored identity, target, dimension and operand bits; retains absorbed tails; requires the actual ordered source folds to match aggregate inputs; validates node/member/support/partition ownership and positive distinct spring operands; compares all local/transform/scatter entries against every ordered element assembly contribution. Actual signed-permutation transform entries are the sufficient closure boundary. No geometric fixture, load size or ID selects eligibility. Exact Context owns complete connected free-block size and positivity checks; tiny couplings are retained.

All twelve member-end node-on-element rows and all six j-side section actions at fractions `[0,.25,.5,.75,1]` are evaluated before displacement projection. The section moment descriptors retain shear, fraction and actual length operands, including both endpoint cuts. Each spring action is a distinct signed `-k*u` functional (current ground reference is zero). Full source-equilibrium reactions are separately projected on every global DOF. All six per-support global actions have source-owned descriptors; duplicate ideal-constraint attribution or duplicate same-support/DOF spring ownership rejects. Multiple springs at one DOF with different identities remain separate. Prescribed nonzero values are supported when explicitly supplied by the actual built imposed-displacement support; this does not claim a newly enabled authoring route.

The owned result exposes `displacements`, `reactions`, `members`, `spring_actions`, `support_actions`, `retained`, and `summary` accessors. Published nodal components are projected directly in mm/rad through `published_nodal_components`; their matching functional indices are available separately from the SI displacement proof. Each member/spring/support output exposes the corresponding immutable retained functional index. The private companion contains complete ordered recipes, exact ratios and leaf projection bounds at the unchanged relative `1e-9` criterion. The summary reports actual coverage, largest block, cumulative work and leaf-bound maxima (the latter span different units and are diagnostic maxima only).

Normalized source identity retains actual local and transform matrix bits, frame section parameters, scatter/range ownership, span, authored section quantities, source node/case/modulus identities and ordered load/support/spring records. These records accompany the numeric closure; labels are never treated as proof. `replay_against(&mut self, current Input)` independently regenerates source ownership, closure and descriptors before helper expected-source replay. The owned non-cloneable attempt budget is reused, and failed replay updates work rather than resetting the cap.
