## 1. Common design (inf; one connector type in every old slot position)

**The FK `connector` module** (`FK/src/connector.rs`) is a module, not a crate, so PP's `Cargo.lock` is unchanged.
- **The type:** `ObjectiveConnector { node_i, node_j: FrameNode, a_i, a_j, q: [[f64;3];3] (columns = axes), k: sym 6×6, q_ref: [f64;6] }`, implementing JR §2.
- **`b()` forms r as `(xⱼ − xᵢ) + (aⱼ − aᵢ)` componentwise.** It never forms pᵢ = xᵢ + aᵢ (S-3; compare T4-U1's "never form an absolute centre").
- **The methods:**
  - `global_stiffness()` = fl(BᵀKB), finite-checked;
  - `reference_load()` = +BᵀKq_ref with its bound (S13);
  - `recover(d)` (S14);
  - `force_scaled(b)`;
  - `formation_roundoff()`;
  - `definiteness()`, an exact PD decision (S11).

**One decode feeds every consumer** (RV130 §4). The decode takes K = D⁻ᵀHD⁻¹ from (H, Ls), and aᵢ from Qᵢ and its offset. Its consumers are dense and sparse assembly, SA evidence, the census, the q_ref term, recovery, W4's PD decision and K-D5. The decode is input representation, outside EF. Independent reference tests cover it (H → K congruence, the offset frames), because K-D5 cannot see a defect there.

**Same position, same order.** The connector replaces `UserStiffnessElement` in each parameter, field and loop, so the dense order stays frames → connectors → blocks → springs. Every admitted model without a joint keeps today's bits: no product path assembles the old element today (I3 §1.1).

**PP wrapper.**
- `BuiltModel.connectors` holds the FK type. A parallel PP record holds each connector's component id and replaced pipe index, as `CurvedBendMacroBuild.pipe_index` does; both are unpriced.
- Replaced spans are found through a lookup set built per use, as `curved_bends_by_pipe` is (`PP/src/lib.rs:4120-4124`). No field is added to `StraightPipeElement`, `FrameElement` or `PreviewPipe` (S-7).

**Scope:**
- v3 only (`3.0.0/exact_pressure_v3`, through T4-U2a's seam);
- topology `replaces_span` only;
- hardware `untied`;
- `JointPressureModel = unpressurized`;
- the connector's `mechanics_interface.solver_consumption` absent or `objective_connector` (N-6).

**No silent `continue`.** A connector that reaches `build_model` is either formed or refused by code.
