## Analytical and code check

Every finite binary64 operand is an integer multiple of 2^-1074. A subnormal contributes its fraction integer directly. A normal with encoded exponent e contributes its 53-bit significand shifted by e−1; sign only selects the positive or negative accumulator. The greatest finite input integer is (2^53−1)·2^2045, whose highest set bit is 2097. For at most 2^64−1 operands the separate positive/negative magnitude is less than 2^2162, requiring at most 2162 bits. The 34×64=2176-bit array therefore has spare capacity on the stated at-most-64-bit-usize cardinality envelope. The generic iterator does not itself enforce that cardinality; checked carry propagation still reports AccumulatorOverflow rather than wrapping if a larger stream were ever to exceed storage.

`add_operand` splits a shifted significand across at most two initial words. `add_word` propagates each carry through all affected higher words, including the interaction of the low-word carry and later high-word addition. The high-to-low magnitude comparison selects the subtraction orientation. Per-word two-step subtraction uses either borrow as the next borrow; since a≥b, the final borrow is zero. Zero magnitude projects to +0.

Projection finds the greatest bit h. For h<52, all integer bits fit directly into the subnormal fraction without rounding. At h=52, encoded exponent1 yields the smallest normal binade. For larger h, keeping bits h through h−52 retains exactly 53 significand bits. The next discarded bit is the round bit; all lower bits form sticky. Incrementing only for round && (sticky || retained odd) implements nearest-even. A significand carry renormalizes and advances h. Encoded exponent h−51 maps the integer-in-2^-1074 scale back to binary64. Exponent2047 after rounding is reported NonRepresentable, including the overflow midpoint. Both signs use the same magnitude rounding, which preserves nearest-even symmetry.

Finite true sums slightly above MAX may still round to MAX; this is correct one-round projection. A true sum whose nearest-even projection overflows returns NonRepresentable. Nonfinite operands return NonFinite even if another operand might nominally cancel them. Empty input, all −0 operands, and exact positive/negative cancellation return canonical +0. This **derived-zero policy is explicit in this review**: negative-zero input is not retained as physical sign evidence. Runtime coefficient grouping should use exact cancellation as zero, never infer original operand provenance from that derived zero.
