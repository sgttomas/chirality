# FE01 / FE02 narrow integration API

- `features/report/reportPackageRequest.ts`: new `SOURCE_BLOCKS_REPORT_PACKAGE_UNAVAILABLE` and `reportPackageUnavailableReason(result): string|null`. `buildReportPackageRequest` refuses source_blocks immediately. App uses the same reason to disable its menu/control availability and display why. The existing handler catches direct/native-command refusal and does not save.
- `services/previewService.ts`: private CapturedNativeInvocation additionally stores `callerModel` and `callerFingerprint`. Both the original caller and serialized invocation must remain unchanged; queried models may match either captured representation. Only actual direct IPC/known completed job can install origin, with prior cancellation/source checks preserved. Public query signatures are unchanged.
- `features/results/sourceBlockRecovery.ts`: `validateSourceBlockRecovery(source, invocation, callerModel?)` adds optional caller context. It independently snapshots/checks normalization, stores the live caller reference plus private snapshot, and rejects later mutation of either representation/source/invocation. Optional caller context is evidence input to this numerical validator, not a native-origin registrar. Existing calls with two arguments stay strict.
- `workspaceSession.ts`: solve snapshot uses structuredClone; native dispatch receives the original live model so pre-serialization context is observed before the service copies its payload. The manifest keeps the original representation. Preserve joined checkout’s later history/reference persistence and generation guards during adoption.

No physical, schema, table or report-format change; no namespace join. Use FINAL_SOURCE.json/REPAIR.patch for the exact8-path delta. Tests use genuine unchanged producer request/raw pairs via mocked IPC, not new native execution.
