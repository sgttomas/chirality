# Reference accuracy and relevance

Checked with primary supplier documentation on 2026-09-25 UTC. These references qualify definitions and known analysis distinctions; they do not validate SWBPIPE, provide operational material/library/code data, or qualify every described method. Existing accepted pressure/numerical/stress references were reused, not re-derived here. No unreviewed external OCR equation artifact was used.

1. [SIMULIA Abaqus 2025 — Thermal Expansion](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEMATRefMap/simamat-c-thermalexpan.htm). This versioned manual distinguishes total expansion from an indicated datum, differential data conversion and the initial-temperature correction. Its small-strain total-expansion convention substantiates the need to record coefficient meaning and both reference temperatures. Our free-length ratio is an independently derived normalization, not a claim that Abaqus uses that exact ratio in its small-strain equation. A derivative of strain per datum length and a derivative of logarithmic length are intentionally separate input kinds; calling both “instantaneous alpha” would be ambiguous. This source does not justify blindly using alpha at operating temperature times the full interval.
2. [COMSOL 6.4 — Thermal Expansion](https://doc.comsol.com/6.4/doc/com.comsol.help.sme/sme_ug_modeling.05.168.html). This current documentation discusses tangent/secant data, measured-data reference and the altered stress-free reference length. It supports treating the coefficient datum as distinct from installation temperature. The conversion in this design follows the independently checkable identity `L(T)/L(T_install)=[L(T)/L(T_m)]/[L(T_install)/L(T_m)]`. It does not add a finite-deformation claim to the existing frame solver. Table interpolation choice remains an explicit constitutive-data modeling assumption.
3. [SIMULIA Abaqus 2025 — Prescribed Conditions](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEPRCRefMap/simaprc-c-ov.htm) and [Boundary keyword](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEKEYRefMap/simakey-r-boundary.htm). These distinguish nonzero initial conditions, physical loads, displacement/rotation boundary conditions and fixed-at-start-of-step positions. They corroborate the separation in the design. `K_ff u_f=f_f-K_fc u_c` is independently derived by partitioning equilibrium, and the repository already contains this kernel route. No penalty stiffness or artificial force replacement is required.
4. [SIMULIA Abaqus 2025 — Initial Condition Types](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEPRCRefMap/simaprc-c-initialcond-t-SpecifyingTheTypeOfInitialConditionBeingDefined-sma-topic1.htm). Initial stress, initial geometry and stress-free configuration are distinct; an entered initial stress must equilibrate with loads/boundaries. This supports avoiding a cold-spring shortcut that enters force while also imposing equivalent geometric mismatch. The cut-short formula here is independently derived for a straight, small-strain elastic member, not copied as a universal installation model.
5. [SIMULIA Abaqus 2025 — Connector Friction Behavior](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEELMRefMap/simaelm-c-connfrictionbehav.htm) and [FRIC_COEF](https://docs.software.vt.edu/abaqusv2025/English/SIMACAESUBRefMap/simasub-c-fric_coef.htm). Their state/slip-dependent interface confirms that physical internal history is distinct from an equilibrium solver seed. It does not prove the current Piping active-set model can restart such a history, nor supply a choice of friction law or hidden stiffness. Generalized contact, return mapping and continuation methods must be qualified with the owning nonlinear work.
6. [SST CAEPIPE — Hydrotest](https://www.sstusa.com/docs/tech_manual/hydrotest.htm) describes pressure, test fluid and insulation alongside a product-specific automatic hanger treatment. It is relevant evidence of the required physical inputs, not authority to copy the automatic locking, test-fluid density or code classification into SWBPIPE. This design chooses explicit support and fluid inputs under the owner's retained data boundary.
7. [SST CAEPIPE — Cold Spring](https://www.sstusa.com/docs/tech_manual/cold_spring__cut_pipe_.htm) demonstrates separate cut-short/long input and support-load reporting. Its statements about code credit are not adopted as code rules. The proposed mechanics computes installation/operating states; any code treatment is supplied by a user's rule pack with its own basis.

A freshness check found COMSOL 6.4 supersedes the initially inspected 6.3 documentation; [6.4 release history](https://www.comsol.com/release-history) identifies its November 2025 release and [maintenance notes](https://www.comsol.com/product-update/6.4) identify the May 2026 update. The 6.4 thermal documentation retains the same essential reference/definition distinctions and explicitly gives logarithmic-length integration before its small-expansion approximation. The cited Abaqus material is explicitly version 2025; no newer public thermal-definition page was found in the bounded official-domain search, which does not establish that no newer product release exists.

8. [Ansys 2026 R1 — PIPE288](https://ansyshelp.ansys.com/public/Views/Secured/corp/v261/en/ans_elem/Hlp_E_PIPE288.html) explicitly couples internal-fluid free-surface input to mass and pressure effects and distinguishes effective tension output. [Abaqus 2025 — Distributed Loads](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEPRCRefMap/simaprc-c-loaddistributed.htm) discusses closed-end pipe-pressure effects and transition handling. These primary sources motivate checking one coherent pressure/contents-weight formulation; they are not proof of our column calculation or product. ROOT supplied the counterexample, which this design derives independently in HYDROSTATIC_CONTROL.md. No vendor numerical defaults, element recommendation thresholds or code content are imported.

The search found modern commercial formulations and stateful contact methods, not a reason to replace basic equilibrium, compatibility, constitutive reference distinctions or strain integration with a newer speculative theory. That is a bounded literature conclusion, not a claim of exhaustive novelty search. Finite-deformation, inelastic and staged-contact formulations are relevant extensions when their physical conditions occur; they require different state variables and validation and must not be claimed from this linear-elastic first tranche. Primary-source pages and our derivations have different evidentiary roles. No numerical expectation was copied from vendor demo output.
