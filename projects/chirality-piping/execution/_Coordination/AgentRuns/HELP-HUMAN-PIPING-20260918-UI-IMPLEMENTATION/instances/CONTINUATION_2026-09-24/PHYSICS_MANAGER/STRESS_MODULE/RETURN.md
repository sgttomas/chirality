## API and arithmetic

`evaluate_elastic_section(ElasticCircularSection, SignedSectionActions)` returns `Result<ElasticSectionStress, ElasticSectionError>`. Properties are A/I/J/ro in coherent SI; signed actions are N/My/Mz/T at the same section and cut. Outputs are signed axial, bending amplitude, maximum and minimum signed outer normal stress, maximum absolute normal stress, and signed outer torsional shear, all Pa. No pressure stress or flexibility/SIF factor is silently added.

All four section properties must be finite and positive; all four actions must be finite. Every required output must remain finite, and a nonzero scaled stress that rounds to zero is rejected. Binary mantissa/exponent separation avoids preventable intermediate product/ratio overflow and underflow; bending uses hypot of separately scaled component stresses so an overflowing moment norm does not reject a finite stress. Finite subnormal outputs are retained at f64 precision. This is not exact real arithmetic or a certified rounding-error bound. A nonrepresentable individual required component can reject the complete state even if a different dominant component would determine the headline.

The low-level numeric section record is deliberately not a geometry constructor: its caller must establish a homogeneous circular section, Iy=Iz=I, consistent J (2I for an annulus), compatible radius/area, and material applicability. No undocumented geometric-consistency tolerance is invented. If integration accepts user A/I/J/ro independently, it must validate their provenance/consistency before calling this qualified circular mapping.
