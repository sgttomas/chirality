For each candidate one-way state, solve the friction-free displacement u0 and reaction R0, then the unit tangential-force influence h. With p the signed friction reaction, the source normal satisfies `R_s = a + b*p`. Each signed sliding branch uses `p = -sign(u_t)*mu*sign(R_s)*R_s`, so `p = c*a/(1-c*b)`, `c=-sign(u_t)*mu*sign(R_s)`. Require signed normal branch consistency, nonzero slip opposed by friction, |p|=mu*|R_s|, free-DOF equilibrium, and one-way contact admissibility. Separately solve/check sticking against |R_t|<=mu*|R_s|. Exactly one branch survives in each frozen case/variant.

The supplied normal definition is the absolute reaction of a named bilateral linear guide DOF. It is not an independently inferred unilateral shoe-contact normal. Reversing that source reaction therefore preserves a positive normal magnitude under this explicit contract.
