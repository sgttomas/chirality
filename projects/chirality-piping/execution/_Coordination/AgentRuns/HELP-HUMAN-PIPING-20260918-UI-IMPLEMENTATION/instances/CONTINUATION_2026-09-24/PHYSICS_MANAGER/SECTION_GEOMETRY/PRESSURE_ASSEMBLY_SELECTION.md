# Bounded source-factor pressure assembly selection

Prospective implementation under ROOT's approved grouping direction, before activation. Ordinary material bounds remain E>0 and -1<nu<0.5; there is no near-incompressible material cutoff. Original1e-9 physical reference comparisons remain unchanged.

Group only exactly matching normalized source pressure bits, exact source inner-radius two-difference (hi,lo), and the magnitude bits of the same derived global direction component, at the same global node/axis. Source inner radius is OD/2-effective-wall; its error-free difference identifies source equality without replacing either source input. Derived zero directions contribute exactly zero and may be omitted; their original directions remain in the per-member ledger. No tolerance or rounding is used to force unrelated factors into a common group. Authored source values are not normalized to manufacture a match.

Within a group, retain separately identified cap coefficients (+/-1 only at transferring physical terminals) and pressure-Poisson coefficients (+/-2nu). Sum the binary64 coefficients exactly with pressure_sum's bounded integer accumulator and one nearest-even projection before multiplying the shared pAi and direction. Thus single-end P*(1-2nu) and interior2P*(nu2-nu1) retain their source-defined small difference. The independent coefficient-sum check binds the actual source and7707 Fraction/bit cases. The helper does not recover already rounded source products.

Evaluate each group with the existing scaled pressure factor. Sum group results using the same exact-F64 sum, retaining separate observational cap/eigen ledgers and explicit actual assembled RHS. Case evidence names the source grouping basis and each source coefficient; a sum of already-rounded ledger vectors is not substituted for the actual source-grouped RHS.

Different source factors can remain ill conditioned. A conservative cancellation screen uses32*binary64_epsilon times the maximum per-component sum of absolute group values, divided by the maximum magnitude of the actual pressure RHS. Zero/zero is an exact-zero grouped state; a nonzero numerator with zero or nonfinite denominator is unresolved. Above1e-9, emit PRESSURE_ASSEMBLY_CANCELLATION_UNRESOLVED and block this pressure solve. Positive source contributions that cannot be represented in the active F64 RHS also block. This is an admission screen and an explicit limit, not a certified overall displacement/stress error bound or a numerical passing receipt. Numerical original-system checks still consume the actual assembled RHS and remain independently required. Capability outside this bounded grouping/conditioning domain stays open, never silently discarded.

Source recovery must similarly retain common factors: from the actually recovered mechanical/thermal section force Nm, calculate wall force Nm+2nuP and effective force Nm+(2nu-1)P before publication. Do not derive effective force by subtracting already rounded published wall/P values. Mechanical distributed-load variation remains in Nm through the existing section-equilibrium recovery.
