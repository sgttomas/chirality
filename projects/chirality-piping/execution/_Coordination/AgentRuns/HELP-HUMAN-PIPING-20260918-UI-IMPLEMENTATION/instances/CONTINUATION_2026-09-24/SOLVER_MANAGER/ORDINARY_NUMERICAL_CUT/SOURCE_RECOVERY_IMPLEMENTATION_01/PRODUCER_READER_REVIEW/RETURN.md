## Scaled norm assessment

The largest normalized component is exactly magnitude one, so underflow of a smaller normalized component cannot erase the leading norm. Tiny discarded squares affect the sum absolutely and are covered by the conservative `64ε` allowance under the stated IEEE/gradual-underflow assumptions.

For componentwise input relative error bounded by `r`, the norm's input error is at most `r` by the Euclidean triangle inequality. Combining recipe error `a=64ε` gives `r+a+r*a`, so the implemented threshold `(1e−9−a)/(1+a)` is the appropriate composition.
