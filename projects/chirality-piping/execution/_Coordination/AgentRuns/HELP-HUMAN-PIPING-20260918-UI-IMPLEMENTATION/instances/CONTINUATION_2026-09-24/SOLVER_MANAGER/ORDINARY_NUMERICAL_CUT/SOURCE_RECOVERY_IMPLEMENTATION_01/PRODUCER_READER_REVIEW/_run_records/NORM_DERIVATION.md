# Bounded scaled-norm arithmetic assessment

Assume finite IEEE binary64 nearest arithmetic, correctly rounded square root and gradual underflow. Let `u=2^-53`, `η=2^-1074` and `m=max |x_i|`. For nonzero input `m>0`; max/abs introduce no rounding. At least one normalized value `x_i/m` is exactly ±1. Each other division has absolute error bounded by `u*|x_i/m|+η/2`; normalized values have magnitude at most one. Squaring and the two ordered additions are nonnegative operations. Their sum has a unit contribution, so its leading scale is never subnormal or cancelled.

The elementary division/square/sum error composition is fewer than 16u in relative terms with a negligible absolute underflow allowance compared with that unit contribution. Square root divides first-order relative sensitivity by two; its own rounding and final multiplication add two rounding allowances. A finite normal final result also avoids an unbounded relative error from output underflow. A deliberately loose 32u bound plus underflow allowances remains below `64*f64::EPSILON = 128u`. This supports the selected conservative reserve; no property of a platform-specific hypot implementation is borrowed. Overflow, nonfinite input and nonzero subnormal output are refused explicitly. Exact all-zero input returns +0.

For exact source vector x and projected vector y with `|y_i−x_i| <= r*|x_i|`, `||y−x||₂ <= r||x||₂`, hence `| ||y||₂−||x||₂ | <= r||x||₂`. If the recipe computes z with relative error at most a against `||y||₂`, then total relative error against `||x||₂` is at most `r+a+r*a`. The implemented input threshold `(1e−9−a)/(1+a)` follows by rearrangement. Zero source components have exact-zero projections; an unproven projected zero cannot enter this argument.

The 408-case Decimal check is a separate numerical crosscheck of these operations, not the proof of the universal reserve. This argument does not cover stress division, torsion radius products, MPa underflow, pressure composition, or the full physical model. PR-01 keeps those separate.
