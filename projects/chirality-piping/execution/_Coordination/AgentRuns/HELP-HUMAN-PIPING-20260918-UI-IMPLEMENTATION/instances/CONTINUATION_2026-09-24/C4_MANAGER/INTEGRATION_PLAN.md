Button/menu choice and unmodified L dispatch the same action; editable controls, modifiers, repeats and consumed events retain their existing guards (`PipeViewport.tsx:2198`). No native menu, persistence or live-controller transaction change is required. The current shell accelerator handles modifier-based view/history actions (`workspaceSession.ts:2522`); do not appropriate those routes accidentally.
