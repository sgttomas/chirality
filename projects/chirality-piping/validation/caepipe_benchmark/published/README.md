# Published CAEPIPE benchmark agreement

This folder publishes benchmark agreement between SWBPIPE and CAEPIPE. What a report here may contain, the
summary form it uses and the gate in `publication.json` are set by `docs/IP_AND_DATA_BOUNDARY.md` §6.2 and
DEL-17-05 `Design/caepipe-correlation-pilot.md` §8.1.
