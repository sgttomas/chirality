# Specification: DEL-001-03_construction-work-package — Construction Work Package

## Scope

This specification defines the minimum content requirements for the PKG-001 Construction Work Package for Earthworks for foundations. The package covers how the civil work will be physically installed, built, inspected, turned over, and tied into larger facility systems.

The work package shall include:

- construction work package content for PKG-001;
- installation and tie-in workface plan content;
- construction interface and turnover checklist content;
- interface controls for Grading / Site Drainage / Spill Containment and Structural / Foundations / Supports.

Exclusions are TBD. Gate 7 states no package-specific exclusions were identified in the current source materials for PKG-001.

## Requirements

| Req ID | Requirement | Verification |
|---|---|---|
| CWP-001 | The Construction Work Package shall identify the package as PKG-001, Earthworks for foundations, WBS 01, CoA tracking number 26020-01-42-001, Civil discipline. | Check against workbook Packages row 2 and Gate 7 package/deliverable registers. |
| CWP-002 | The Construction Work Package shall include a construction-facing plan for physical installation, construction, inspection, turnover, and tie-in to larger facility systems. | Confirm document sections or attached workface plan cover each named function. |
| CWP-003 | The Construction Work Package shall address the package interfaces marked for PKG-001: Grading / Site Drainage / Spill Containment and Structural / Foundations / Supports. | Cross-check interface matrix/checklist against workbook Packages row 2 and INTERFACE_REGISTER.csv rows for PKG-001. |
| CWP-004 | The Construction Work Package shall not treat geotechnical design parameters as final construction criteria until the geotechnical assessment report is completed and reviewed. | Confirm bearing capacity, lateral pile design, LPILE curves, dynamic criteria, pavement design, pavement layers, and geotextile need remain TBD or are backed by accepted geotechnical data. |
| CWP-005 | Site grading and drainage work planning shall preserve the DBM basis: prevent off-site surface overflow from entering the expansion facility, direct and contain on-site overflow into a retention pond, and consider surface controls around selected equipment. | Review grading/drainage execution plan against DBM-Deepcut SEC-11. |
| CWP-006 | Facility pad grading shall use the DBM basis of 1.5% slope down from pipe racks to each side, with reduction to 1.0% only where required to maintain reasonable top-of-pile-cap elevations. | Check issued grading plan/workface plan against DBM-Deepcut SEC-11 and approved engineering drawings. |
| CWP-007 | Grade slopes shall not exceed 3H:1V unless specifically engineered or mandated otherwise by the geotechnical report. | Check grading plan and inspection records. |
| CWP-008 | Ditch and culvert planning shall carry DBM minimums of 0.2% ditch slope, 0.5% culvert slope, and 1.0% preferred culvert slope, with final IDF duration to be confirmed during detailed engineering. | Check drainage plan and open item register. |
| CWP-009 | Foundation installation planning shall use driven steel piles as the default support basis for buildings, equipment, towers, tanks, modules, pipe racks, and similar structures unless detailed engineering confirms a different basis. | Check foundation drawings, pile records, and approved deviations. |
| CWP-010 | The Construction Work Package shall identify all unresolved inputs affecting construction readiness, including geotechnical report, topographical survey/grade surface file, plot plan/retention pond coordination, detailed drainage design, compressor dynamic analysis where applicable, and foundation support verification where applicable. | Review open item log and turnover checklist. |
| CWP-011 | ASSUMPTION: Because Gate 7 assigns the deliverable to the EPC Integrator while the 04-25 DBM assigns field construction to Tourmaline Oil Corporation, the work package should distinguish document ownership from field execution responsibility. | Human review of responsibility matrix. |

## Verification

The Construction Work Package is ready for controlled review when:

- identity fields match Gate 7 and workbook row 2;
- all PKG-001 interface facts are carried into the construction interface checklist;
- all DBM civil basis values used in the work package cite the DBM section or approved downstream engineering document;
- all missing construction quantities, coordinates, forms, and final geotechnical/topographical inputs are listed as `TBD` or open items;
- inspection and turnover records are named, even where final forms remain TBD.

## Documentation

The following documentation shall be produced or attached to the Construction Work Package:

- construction work package;
- installation and tie-in workface plan;
- construction interface and turnover checklist;
- responsibility matrix distinguishing EPC Integrator deliverable ownership from field construction execution responsibility;
- open input and TBD register;
- inspection and turnover record index, with final forms TBD.
