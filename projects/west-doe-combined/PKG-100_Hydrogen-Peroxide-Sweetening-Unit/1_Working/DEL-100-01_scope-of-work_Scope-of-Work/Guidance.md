# Guidance — DEL-100-01 Scope of Work (PKG-100 Hydrogen Peroxide Sweetening Unit)

## Purpose

This Scope of Work is the EPC Integrator's anchoring statement of *what the PKG-100 Hydrogen Peroxide Sweetening Unit is and how it integrates into the facility*. It is the upstream deliverable that the Package Datasheet (`DEL-100-02`), Construction Work Package (`DEL-100-03`), vendor production unit (`DEL-100-04`), vendor document turnover (`DEL-100-05`), and EPC review/acceptance (`DEL-100-06`) all consume (per `DELIVERABLE_REGISTER.csv`). Getting identity, function, boundary, responsibility, conditions, and interface set correct here prevents downstream rework when the vendor receives the technical handoff.

Source: `_CONTEXT.md`; `DELIVERABLE_REGISTER.csv`; package note "Mandatory Gate 5 EPC anchor deliverable defined by user instruction".

## Principles

1. **Vendor owns the package; EPC owns the integration.** Package engineering, design, vendor documentation, and equipment supply belong to the Package Vendor. Interfaces, tie-ins, constructability, procurement/construction coordination, and facility-level integration belong to the EPC Integrator. This split is the controlling responsibility model for `PKG-100`. Source: `PACKAGE_REGISTER.csv` ResponsibilityModel.
2. **Source-anchored content; no invention.** Every non-trivial statement should cite Workbook Packages row 63, `26020-Package_Requirements.docx` package heading 52, `DBM-Comp_and_Liquids/3-25_Comp_and_Liquids_DBM.md`, or another locally accessible source slice. Where a value is not in an accessible slice, mark `TBD` with `location TBD` rather than inferring it. Source: SKILL `four-documents` source-grounding rule.
3. **Interface set is exhaustive at the package boundary.** The 13 interface types in `INTERFACE_REGISTER.csv` for `PKG-100` form the integration surface. Omitting any of them in the SOW will create a hidden EPC scope item downstream. Source: `INTERFACE_REGISTER.csv`.
4. **Hydrogen peroxide is a hazardous reactive chemical.** Bulk H₂O₂ storage (400 BBL onsite), pumping, and reactor injection introduce material-compatibility, decomposition, ventilation, and fire/gas-safety considerations that travel with the package across the EPC integration boundary. Treat the package as part of the facility-wide chemical-safety system, not as an isolated mechanical skid. Source: `SCOPE_LEDGER.csv` SOW-0108–0110; `OBJ-009`.
5. **"By others" items are explicit EPC scope, not gaps.** SOW-0110 names interconnecting piping, DCS integration, foundations, and electrical supply to the MCC as "by others". These belong to EPC Integrator scope (or other facility deliverables) and must be tracked as integration responsibilities, not silently dropped. Source: `SCOPE_LEDGER.csv` SOW-0110.

## Considerations

- **Vendor-to-design components.** SOW-0109 explicitly states that the Hydrogen Peroxide Pumps, Static Mixer, and Hydrogen Peroxide Reactors are "Vendor to design"; SOW-0110 states pump capacity is "TBC (Vendor to design)". The SOW should make clear that detailed sizing belongs to the vendor design package (`DEL-100-04`) rather than being asserted in this SOW.
- **Self-framing building.** SOW-0109 declares a self-framing building is to be erected at site. The building introduces Building HVAC / Services, Fire & Gas / Safety Systems, and Structural / Foundations / Supports interfaces. Building responsibility (vendor-supplied vs. EPC-erected) is not delineated in source slices; resolve in Datasheet or capture as Conflict ID `CONF-100-01-02` below.
- **DCS integration "by others".** SOW-0110 places DCS integration outside the vendor package, but I&C / Control Cabling is listed as a PKG-100 interface in `INTERFACE_REGISTER.csv`. The signal-list, terminal-block, and control-strategy ownership split needs explicit interface definition in Datasheet (`DEL-100-02`); capture as Conflict ID `CONF-100-01-01`.
- **Operating vs. design conditions.** Source slices give operating conditions (T=9 °C, P=340.54 kPag, Q=160 m³/h) and ambient design temperatures (−40/+35 °C), but explicitly state "Design conditions TBC". The SOW must not promote operating conditions to design conditions.
- **Budgetary go-by is informational only.** `Bid Docs/Budgetary/26020-03-PT-RFQ-27-001-H202_Sweet_Unit.docx` is identified in `PACKAGE_REGISTER.csv` as a budgetary pricing/delivery go-by. Do not promote any value from it into a requirement without explicit human ruling. Source: `PACKAGE_REGISTER.csv` SourceRefRaw.
- **WBS 03 placement.** PKG-100 is WBS 03 (Compression and Liquids area), per the DBM-Comp_and_Liquids source basis; integration narrative should reflect that the package serves sour-water disposition leading into the produced-water storage system. Source: `PACKAGE_REGISTER.csv` WBS; SourceRefRaw.

## Trade-offs

- **Specificity vs. source coverage.** The locally accessible source slices (workbook row, scope ledger, package register) describe identity, function, equipment list, operating conditions, responsibility, and interface set, but do not provide clause-level design conditions, materials of construction, or code citations. SOW content should be specific where source supports it and explicitly `TBD` (with `location TBD`) elsewhere. Pushing more detail into the SOW than source supports compromises auditability.
- **EPC-authored vs. vendor-authored content.** This SOW is EPC-authored; technical design content belongs in the Package Datasheet (`DEL-100-02`) and the vendor's engineered equipment package (`DEL-100-04`). Resist drift of vendor design content (reactor sizing, pump curves, material selection rationale) into this deliverable.
- **Interface enumeration vs. interface design.** Naming the 13 applicable interfaces in this SOW satisfies the integration narrative requirement; interface *design* (signal counts, line sizes, cable schedules, EHT circuit IDs) belongs in the Package Datasheet and downstream EPC discipline deliverables.
- **Reproducing source text vs. paraphrasing.** Verbatim reproduction maximizes auditability; paraphrasing improves readability but risks subtle drift. Prefer verbatim for numeric values and equipment lists; paraphrase only for narrative framing.

## Examples

Source-grounded statement (good):
> "The package provides sour-water treatment at 24,154 BBL/D (160 m³/h) with sour-water inlet conditions of 9 °C and 340.54 kPag; treated water is routed to produced water storage tanks (SOW-0108, SOW-0110; `26020-Package_Requirements.docx` heading 52)."

Insufficiently grounded statement (avoid):
> "The reactors are sized for 30-second residence time at 5 wt% H₂O₂ dose." — no locally accessible source slice supports residence time or dose; mark `TBD` with `location TBD` and defer to vendor design.
