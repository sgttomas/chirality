# Procedure: DEL-048-03 — Construction Work Package

## Purpose

Define the steps to produce, issue, and maintain the Construction Work Package (CWP) for PKG-048 (Inlet / Sales Compressors), and the operational steps that the CWP itself directs during construction execution and turnover (Source: _CONTEXT.md Scope; 3-25_Comp_and_Liquids_DBM.md SEC-03).

## Prerequisites

- Accepted upstream decomposition snapshot: GATE-07_Final_Published_2026-05-24 (Source: _REFERENCES.md).
- Issued-For-Construction (IFC) drawings, specifications, and material take-offs for PKG-048 (location TBD; assumed produced upstream of CWP issue).
- Vendor engineered equipment package (DEL-048-04) terminal information and approved vendor documents (ASSUMPTION; declared-upstream not present in _DEPENDENCIES.md).
- Final geotechnical report accepted (Source: 3-25_Comp_and_Liquids_DBM.md SEC-03).
- Governing sour-service piping/material, welding, NDE, hydrotest, and electrical area-classification specifications (location TBD).
- Construction safety, H2S, and confined-space procedures for the 03-25 site (location TBD).
- Owner package requirements: 26020-Package_Requirements.docx package heading 3 (location TBD — binary source not parsed in this pass).

## Steps

### Phase A — Produce the CWP

A1. Compile package scope from _CONTEXT.md, the GATE-07 deliverable register row (DEL-048-03), and DBM SEC-03/SEC-04/SEC-05 source slices.

A2. Resolve owner package requirements from 26020-Package_Requirements.docx package heading 3 (TBD — to be done when the .docx is parsed).

A3. Author the CWP master document with: scope, references, organization, deliverables list, schedule integration, safety integration, quality integration, interfaces, and turnover plan.

A4. Author the installation and tie-in workface plan: enumerate workfaces by area/system (module receipt, foundations, module set, mechanical hookup, piping interconnect, electrical home runs, instrument hookup, tie-ins).

A5. Author the construction interface and turnover checklist: list all interfaces (vendor packages, shared utilities from 04-25, shared flares/incinerator, electrical, control system) and map each to a turnover boundary.

A6. Cross-link IFC drawings, ITPs, and procedures into the CWP index.

A7. Issue CWP for internal EPC review; resolve comments; issue to Owner for acceptance.

### Phase B — Execute construction per the CWP

B1. Mobilize site, establish lay-down, security, and site safety per CWP safety integration.

B2. Complete civil/structural per accepted geotechnical report: site prep, piling, foundations, frost protection (Source: 3-25_Comp_and_Liquids_DBM.md SEC-03).

B3. Receive and offload modularized compressor packages (KM-2150, KM-2250) and TEG package; set base modules on foundations; reassemble mid and roof modules into self-framing buildings (Source: 3-25_Comp_and_Liquids_DBM.md SEC-05).

B4. Execute mechanical hookups: bolt-up of vendor terminal flanges, installation of shipped-loose instruments and valves, pipe-support installation, ISBL/OSBL interconnecting piping (Source: 3-25_Comp_and_Liquids_DBM.md SEC-03).

B5. Execute electrical scope: home-run cabling, terminations, area lighting, fencing, security; VFD installation and parameterization for 5,200 hp compressor motors (Source: 3-25_Comp_and_Liquids_DBM.md SEC-03, SEC-05).

B6. Execute instrumentation scope: loop checks, calibrations, control-system terminations (specifics TBD; reference owner control-system spec, location TBD).

B7. Perform NDE and hydrotest on sour-service piping per governing specs; release per ITPs (location TBD).

B8. Execute plant inlet pipeline tie-in at the first aboveground flange within the lease boundary, sequenced with Doe-field pipeline contractor handover; execute sour-gas export tie-in to the 04-25 inlet gathering system (Source: 3-25_Comp_and_Liquids_DBM.md SEC-04).

B9. Manage demolition/removal scope limited to that required for tie-ins (Source: 3-25_Comp_and_Liquids_DBM.md SEC-03).

### Phase C — Inspect, turn over, and tie in

C1. Walk down each subsystem against IFC drawings; raise punch items into the register.

C2. Drive A-list punch items to closure prior to mechanical completion sign-off.

C3. Complete the construction interface and turnover checklist for each system/subsystem; obtain sign-off by EPC Integrator, vendor reps where applicable, and Owner.

C4. Hand over mechanical completion subsystems to commissioning per the turnover plan.

C5. Submit red-line as-built markups for incorporation into final record drawings.

## Verification

| Check | How |
|---|---|
| CWP completeness | Document review against the _CONTEXT.md anticipated artifact list; absence of any element triggers a deficiency note. |
| Workface plan coverage | Each module/package and each tie-in has at least one workface plan. |
| Interface and turnover checklist coverage | Every interface in the register has a turnover row with owner and acceptance signature blocks. |
| Foundation gate | Geotechnical report acceptance is on file before any foundation pour ITP is released. |
| Sour-service piping integrity | MTRs, NDE, hydrotest records complete and accepted per ITP. |
| Electrical readiness | Phasing, megger, VFD parameterization, motor solo-run records on file. |
| Tie-in execution | Tie-in walkdowns signed off; ESDV functional tests complete. |
| As-built submission | Red-line as-built submitted and accepted before turnover closure. |

## Records

- Issued CWP master document and revision history.
- Installation and tie-in workface plan (issued, revised, executed).
- Construction interface and turnover checklist (signed).
- ITP records: MTRs, NDE reports, hydrotest packages, calibration certificates, loop-check sheets.
- Punch list and closure records.
- Mechanical completion certificates by subsystem.
- Red-line as-built drawing set.
- Owner acceptance records for turnover handover.
