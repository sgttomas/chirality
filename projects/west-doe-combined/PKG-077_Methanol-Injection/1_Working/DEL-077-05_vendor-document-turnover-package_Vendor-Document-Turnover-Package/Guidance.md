# Guidance — DEL-077-05 Vendor Document Turnover Package (PKG-077)

## Purpose

This guidance frames how the Vendor Document Turnover Package is to be assembled, interpreted, and reviewed for PKG-077 (Methanol Injection). It supports `OBJ-001`, `OBJ-004`, `OBJ-005`, `OBJ-006`, `OBJ-007`, `OBJ-008`, `OBJ-009`, `OBJ-010` (PACKAGE_HEURISTIC mapping; treated as directional context unless human-confirmed) by ensuring the EPC Integrator receives a complete, traceable vendor documentation set sufficient for facility integration, transient hydrate-management operations, and regulatory readiness.

## Principles

1. **Source-driven document list.** The applicable document classes come from `_Sources/26020-Package_Requirements.docx` "Vendor Engineering Deliverables". This skill does not invent new document classes for the PKG-077 turnover. Methanol-injection-specific section text is not present in the accessible source set (gap recorded as `ART-CF38039426`); the package vendor and EPC reviewer must therefore explicitly dispose each line of the generic template.
2. **Discipline filtering, not document invention.** The vendor and EPC reviewer apply the source's discipline tables to mark each line APPLICABLE / N/A with a brief rationale, rather than removing or re-inventing IDs.
3. **EPC Integrator as acceptor, not author.** Per `_CONTEXT.md` and the `DELIVERABLE_REGISTER.csv`, the Package Vendor authors; the EPC Integrator reviews via `DEL-077-06`. Acceptance is a human decision.
4. **Traceability over volume.** The Vendor Document Index (`PRQ-009`) is the canonical contents list; every document submitted must appear in it with current revision and status. Volume alone is not acceptance.
5. **Codes and standards stay sourced.** Where the accessible source set does not cite a specific standard clause, the turnover set states the applicable standard and leaves clause-level claims to detailed-design documents.
6. **TBC parameters are surfaced, not hidden.** Items that DBM explicitly marks TBD/TBC (injection capacities, methanol tank SG, acid-gas-compressor injection details, required injection points) are carried as explicit open items on the Index and tracked to closure during detailed design and FAT.

## Considerations

- **Mechanical-led package with broad interfaces.** The package is identified Mechanical (`PACKAGE_REGISTER.csv` row 72), WBS 01, but the applicable interface set is broad: Process Piping; Utility Piping; Relief / Flare / Vent; Drain / Containment; Electrical Power; EHT; Grounding / Bonding; Area / Exterior Lighting; I&C / Control Cabling; Building HVAC / Services; Fire & Gas / Safety Systems; Maintenance Access; Structural / Foundations / Supports. Vendor documents must cover each applicable interface somewhere in the turnover set, even though the physical equipment is just a tank and a triplex pump.
- **Cold-climate basis drives EHT and freeze protection.** Methanol piping freeze protection, EHT design (`ELE-018`), and the cold-climate piping insulation/heat-tracing schedule (`PIP-020`, `PIP-021`) are not optional on this site (per `_Sources/DBM-Deepcut/4-25_Deepcut_DBM.md` site basis).
- **Atmospheric tank + reciprocating pump.** Per DBM line 1329, the tank is atmospheric and double-walled, and the pump is a triplex reciprocating injection pump. This determines applicability for `MEC-005` (atmospheric tank specification), `MEC-009` (only if pulsation dampener exists), `REG-022` (jurisdictional registration TBD), `PRO-014`/`PRO-015`/`PRO-016` (pump-discharge protection), and `CIV-014` (secondary containment for the tank). Pressure-vessel-only document classes are not blindly applied.
- **Single-point injection selection.** DBM line 1328 explicitly states the system is designed to inject into one point at a time. This drives the control narrative (`CTL-003`), C&E matrix (`CTL-005`), and the I&C package configuration. The vendor control philosophy must reflect this constraint and not assume parallel multi-point injection.
- **Gate 6 disposition / Cryogenic Unit co-issue.** Per `PACKAGE_REGISTER.csv` row 72, Methanol Injection scope is included with the Cryogenic Unit package scope at the workbook level. The EPC Integrator may choose to physically co-issue the PKG-077 vendor turnover with the PKG-076 turnover. This is a logistics decision; the deliverable identity and document register are not collapsed.
- **Vendor-document gap.** The accessible source set does not contain a per-package "Methanol Injection" vendor-document section. The generic template is the only basis. Reviewers must be alert for items that would be in a methanol-specific section if it existed (e.g., methanol-service material certifications, injection-point flow-distribution analysis, freeze-protection demonstration).
- **Turnover gate.** Turnover records (`PRQ-016`, `MEC-023`, `ELE-030`, `PIP-028`, `QLT-020`, `QLT-021`) are the critical evidence for `DEL-077-06` acceptance. Plan FAT/SAT/energization milestones backwards from the EPC Integrator's acceptance gate.

## Trade-offs

- **Breadth vs. signal.** A wide vendor document set is more defensible at regulatory and operational reviews, but increases review cost and submittal turnaround. Use the discipline applicability call to keep the set tight while preserving traceability.
- **Early submittal vs. as-built quality.** Releasing documents early gives the EPC Integrator time to coordinate facility-level integration but creates revisioning churn. The Vendor Document Control Procedure (`DOC-008`) should establish a small number of named milestones (e.g., preliminary, certified-for-construction, as-built) rather than continuous trickle.
- **Standalone vendor IOM vs. integrated turnover book.** A combined `PRQ-016` book is easier for operations to use long-term; per-document standalone files are easier for vendor revisioning. Decide upfront and reflect in `DOC-008`.
- **Co-issue with Cryogenic Unit vs. independent.** Co-issuing the vendor turnover with PKG-076 simplifies operations-side turnover handling and matches the Gate 6 disposition, but introduces external schedule dependency. Independent issue keeps the PKG-077 turnover decoupled but requires more careful index cross-referencing.

## Examples

- DBM lines 428, 630, 1328 illustrate the multi-location injection requirement (BAHX pass inlets, J-T valve inlet, inlet separators, acid-gas-compressor package). These define the tie-in scope (`PIP-004`) and the control-narrative single-point selection requirement (`CTL-003`).
- DBM line 1329 ("Atmospheric double-walled methanol tank adjacent to expander building; pure methanol tank design specific gravity 1.00 TBC; triplex reciprocating injection pump") gives the equipment-specification basis for `MEC-003`, `MEC-005`, and the pump-side `PRO-014`/`PRO-015` overpressure-protection requirement.
- The sibling PKG-019 (MV VFD) turnover specification illustrates the same template instantiated for an Electrical package; the PKG-077 instantiation follows the same shape with mechanical-led discipline filtering and added pressure-equipment / piping / structural / drainage / fire-and-gas coverage.
