# Specification — DEL-062-03 Construction Work Package (NGL Loading Pumps Building)

## Scope

### In Scope
- All EPC Integrator construction work required to physically install, build, inspect, turn over, and tie in the NGL Loading Pumps Building package (PKG-062) into the larger facility systems (source: `_CONTEXT.md` Scope; `DELIVERABLE_REGISTER.csv` row 422).
- The construction-side scope for the four NGL loading pumps P-9510-1, P-9520-1, P-9530-1, P-9540-1 housed in the building, including civil/structural, mechanical, piping, electrical, instrumentation, and HVAC site work needed to make the package ready for commissioning (source: `_Sources/DBM-Deepcut/4-25_Deepcut_DBM.md` line 2610; ASSUMPTION on discipline list).
- Coordination with the vendor-engineered equipment package (DEL-062-04) for receipt, set, and check-out of the supplied skid(s) (ASSUMPTION based on `DELIVERABLE_REGISTER.csv` row 423).
- Construction interface and turnover checklist and the installation/tie-in workface plan (source: `_CONTEXT.md` Anticipated Artifacts).

### Out of Scope
- Vendor package engineering, design, fabrication, and supply (covered by DEL-062-04, `DELIVERABLE_REGISTER.csv` row 423).
- Vendor document register and turnover document compilation (covered by DEL-062-05, `DELIVERABLE_REGISTER.csv` row 424).
- EPC vendor package review and acceptance (covered by DEL-062-06, `DELIVERABLE_REGISTER.csv` row 425).
- Package scope of work narrative (DEL-062-01) and the package technical datasheet (DEL-062-02) — both are inputs to this deliverable.
