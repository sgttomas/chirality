# Guidance — DEL-062-06 EPC Vendor Package Review and Acceptance

## Purpose

This deliverable exists to document the EPC integrator's review and acceptance of the vendor-supplied **NGL Loading Pumps Building** package (PKG-062). It is the integrator-side gate that confirms vendor delivery meets the EPC Scope of Work, Package Datasheet, and Construction Work Package before the package can be handed off to construction, commissioning, and operations (per _CONTEXT.md Notes: "Additional Gate 5 deliverable framed as EPC-integrator review and acceptance evidence").

## Principles

- **Integrator-led, vendor-supported.** The EPC integrator owns the acceptance decision; the package vendor provides supporting input. (_CONTEXT.md ResponsibleParty)
- **Source-anchored acceptance.** Acceptance criteria are anchored to the EPC Scope of Work (SOW-0153..0156), the Package Datasheet, and the Construction Work Package — not to ad-hoc judgment.
- **Traceable evidence.** Every acceptance assertion must point to a vendor document, test record, or walkdown observation.
- **No silent waivers.** Deviations from datasheet / SoW are recorded as PROPOSALS for human ruling, not closed unilaterally.

## Considerations

- The package contains four pumps in a "rotary vane" technology family (DBM-Deepcut line 2610). Acceptance considerations should reflect positive-displacement pump characteristics (e.g., pulsation, relief protection, slip / volumetric efficiency) rather than centrifugal-pump assumptions. ASSUMPTION pending Package Datasheet (DEL-062-02) consumption.
- The package is housed in a dedicated building. Building-scope acceptance items (HVAC, electrical, fire/gas, drainage, lighting) belong to package scope unless the SoW explicitly segregates them — location TBD.
- Service is NGL (light hydrocarbon liquid product) (DBM-Deepcut line 73). Sealing, electrical area classification, and relief-system tie-ins should be reviewed against hazardous-area requirements.

## Trade-offs

- **Document-only review vs. walkdown-supported review.** Document review is faster but can miss as-built deviations. Recommendation: require at least one walkdown event before acceptance closure.
- **Package-level acceptance vs. tag-level acceptance.** PKG-062 has four equipment tags; package-level acceptance is efficient but may mask tag-specific deficiencies. Recommendation: maintain per-tag rows in the acceptance checklist while issuing a single package-level acceptance decision.
