# Procedure — DEL-062-06 EPC Vendor Package Review and Acceptance

**Interpretation:** This procedure describes the steps to **produce** the acceptance evidence artifacts that constitute DEL-062-06. It is operated by the EPC integrator with input from the package vendor.

## Prerequisites

- EPC Scope of Work for PKG-062 (sibling deliverable DEL-062-01) issued and current. (ASSUMPTION — not consumed in this run.)
- Package Datasheet for PKG-062 (DEL-062-02) issued and current. (ASSUMPTION.)
- Construction Work Package for PKG-062 (DEL-062-03) issued. (ASSUMPTION.)
- Vendor Engineered Equipment Package (DEL-062-04) delivered. (ASSUMPTION.)
- Vendor Document Turnover Package (DEL-062-05) delivered. (ASSUMPTION.)
- Access to project QA/QC plan and applicable codes/standards (location TBD).
- Reviewer authority assigned (EPC integrator package engineer).

## Steps

### 1. Boundary Check
1. Confirm package boundary against the Deepcut DBM package roster: 4 equipment items, tags P-9510-1, P-9520-1, P-9530-1, P-9540-1 (rotary vane pumps), housed in the NGL Loading Pumps Building (DBM-Deepcut line 2610).
2. Reconcile any vendor-delivered tag list against this list; flag additions / omissions for ruling.

### 2. Document Review
1. Receive the Vendor Document Turnover Package (DEL-062-05) and reconcile against the turnover index.
2. For each controlled document: capture document number, revision, status (Approved / Approved with Comments / Rejected / Information Only) in the **vendor document review log**.
3. Record outstanding comments and required vendor responses with target dates.

### 3. Acceptance Checklist
1. Build the **package acceptance checklist** with one row per acceptance item, traced to:
   - SOW line (SOW-0153, SOW-0154, SOW-0155, SOW-0156),
   - Package Datasheet section (TBD references to DEL-062-02),
   - CWP item (TBD references to DEL-062-03).
2. Per row, record the evidence pointer (vendor document number + revision, or test record reference, or walkdown observation).
3. Per row, record disposition: Accepted / Accepted with Conditions / Rejected.

### 4. Test/Inspection Evidence
1. Collect factory test records (FAT) for each pump (P-9510-1 through P-9540-1): performance curves or PD-pump capacity / slip tests as applicable, hydrotest records, NDE reports.
2. Collect site test records (SAT, mechanical run, alignment) as available.
3. File under **test/inspection evidence**, cross-referenced from the acceptance checklist.

### 5. Walkdown (recommended)
1. Conduct at least one on-site walkdown covering the four pumps, building HVAC/electrical/fire-and-gas/drainage scope, and the package skid / piping tie-in points.
2. Record findings as walkdown observations attached to the acceptance checklist rows.

### 6. Turnover
1. Verify mechanical completion certificates for each pump and for the building-scope sub-systems.
2. Confirm punch list status (Category A items closed; Category B items dispositioned).
3. Confirm vendor document turnover index closure (all required documents at terminal revision).
4. Assemble the **turnover evidence** file.

### 7. Acceptance Decision
1. EPC integrator package engineer signs the package acceptance checklist.
2. If acceptance carries conditions, list each condition with owner, due date, and verification method.
3. Per Chirality K-AUTH-1, any binding approval is a human signature; this deliverable produces the evidence supporting that signature, not the signature itself.

## Verification

| Check | Method |

| SOW traceability | Confirm every SOW line item (SOW-0153..0156) maps to at least one acceptance checklist row. |

| Document turnover completeness | Confirm vendor document review log reconciles to the turnover index with no unaddressed documents. |
| Boundary coverage | Confirm building-scope sub-systems (HVAC, electrical, F&G, drainage, lighting) are addressed or explicitly excluded per SoW. |
| Datasheet conformance | TBD — pending Package Datasheet (DEL-062-02) consumption. |
| Conditions tracking | Confirm every "Accepted with Conditions" row has owner, due date, and verification method. |

## Records

The acceptance evidence set delivered by this deliverable:

- **Vendor document review log** — per-document status, comments, responses.
- **Package acceptance checklist** — per-acceptance-item disposition with evidence pointers.
- **Test/inspection evidence** — collected FAT/SAT/NDE/hydrotest records for P-9510-1 through P-9540-1.
- **Turnover evidence** — mechanical completion, punch list disposition, document turnover index closure.

These four artifacts together constitute the EPC integrator's acceptance evidence for PKG-062 and are the consumable input to the human acceptance signature.
