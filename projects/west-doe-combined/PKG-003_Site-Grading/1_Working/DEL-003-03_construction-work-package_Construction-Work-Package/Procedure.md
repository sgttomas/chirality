# Procedure: DEL-003-03_construction-work-package

## Purpose

Use this procedure to produce and use the `PKG-003` Site Grading Construction Work Package for construction planning, field execution control, inspection, interface closeout, and turnover.

## Prerequisites

Before releasing the CWP for construction, confirm the status of:

- accepted Gate 7 decomposition basis for `DEL-003-03_construction-work-package`;
- workbook source row for Site Grading, WBS 01, CoA `26020-01-42-003`;
- IFC or accepted-for-construction grading, drainage, road, retention pond, and containment drawings;
- geotechnical report and any accepted geotechnical exceptions or constraints;
- topographical survey and grade-surface file;
- plot plan and retention pond location basis;
- detailed drainage design, including final IDF duration, ditch/culvert sizing, and retention pond capacity;
- environmental, surface-water, erosion/sediment, and contaminated-drainage controls required by project procedures;
- construction quality plan, inspection and test plan, survey plan, and turnover procedure;
- declared upstream/downstream dependencies: none declared in `_DEPENDENCIES.md` during PREPARATION.

Items not yet available must be recorded as `TBD`, an open item, or a release constraint.

## Steps

1. Confirm deliverable identity.
   - Verify the package is `PKG-003` Site Grading, WBS 01, Civil discipline, CoA `26020-01-42-003`, and deliverable `DEL-003-03_construction-work-package`.

2. Compile the construction source package.
   - Include IFC drawings, specifications, geotechnical/topographical inputs, drainage calculations, applicable permits, quality requirements, and project turnover forms.
   - Mark missing inputs as `TBD`; do not replace them with assumed field criteria.

3. Define workface boundaries.
   - Identify the physical limits of Site Grading work and the relationship to roads, drainage, retention pond, process areas, foundations, pipe racks, modules, buildings, and access routes where shown by project drawings.
   - Mark boundary details `TBD` where the current source set does not define them.

4. Carry interface facts into the work plan.
   - Add Drain / Containment and Grading / Site Drainage / Spill Containment to construction planning, inspection, and turnover checklists.
   - Identify required tie-in points or surface-control transitions from IFC drawings; mark unavailable tie-in details `TBD`.

5. Plan grading and drainage controls.
   - Apply accepted drawings and calculations.
   - Preserve source basis for main pipe rack ridges, facility pad slopes, maximum grade slope, ditch slope, culvert slope, storm basis, retention pond, and surface-control features unless superseded by accepted detailed engineering.

6. Establish inspection and survey hold points.
   - Include pre-grade existing condition review, subgrade/preparation checks, interim grade checks, ditch/culvert checks, retention pond/berm checks, final grade survey, and drainage/containment walkdown as applicable.
   - ASSUMPTION: final hold-point names and witness requirements will be set by the project construction quality plan.

7. Execute and document field work.
   - Build to the accepted CWP and drawings.
   - Capture survey results, inspection records, redlines, field changes, nonconformances, and open items.
   - Escalate field conditions that affect drainage, containment, access, tie-ins, or accepted design criteria.

8. Verify interface and turnover readiness.
   - Confirm drain/containment and grading/site drainage/spill-containment interfaces are installed, inspected, or recorded as open.
   - Confirm unresolved geotechnical, survey, plot-plan, drainage, or retention pond items are either closed or accepted as turnover exceptions.

9. Assemble turnover package.
   - Compile final CWP, inspection records, survey/as-built evidence, redlines, nonconformance dispositions, open-item register, and construction interface and turnover checklist.

## Verification

| Check | Evidence |
|---|---|
| Identity check complete | Datasheet or CWP cover page names `DEL-003-03`, `PKG-003`, WBS 01, and CoA `26020-01-42-003`. |
| Source package complete or controlled | Input checklist lists IFC drawings, geotechnical/topographical data, plot plan, drainage design, quality plan, and turnover forms as available, `TBD`, or constrained. |
| Interface checks complete | Drain / Containment and Grading / Site Drainage / Spill Containment appear in inspection and turnover evidence. |
| Grading/drainage criteria checked | Survey, drawing review, and field inspection records address applicable slopes, ditches, culverts, retention pond/berm, surface-control, and contaminated-drainage routing. |
| Open items controlled | Open-item register identifies unresolved design inputs, field deviations, and turnover exceptions with owner and disposition. |
| Turnover package assembled | Final records package contains inspections, as-builts/redlines, nonconformance dispositions, interface checklist, and turnover checklist. |

- Construction Work Package.

- IFC drawing index and redline/as-built set.
- Geotechnical, topographical, and drainage-design input log.
- Inspection and test records.
- Survey/as-built verification records.
- Field change and nonconformance records.
- Open-item register.
- Turnover acceptance evidence.
