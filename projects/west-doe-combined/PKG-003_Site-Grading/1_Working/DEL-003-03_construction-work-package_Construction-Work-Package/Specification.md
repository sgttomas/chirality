# Specification: DEL-003-03_construction-work-package

## Scope

This specification governs the Construction Work Package for `PKG-003` Site Grading, WBS 01, CoA tracking number `26020-01-42-003`. The package is an EPC Integrator deliverable for the Civil Site Grading scope and must describe how the package will be physically installed, built, inspected, turned over, and tied into the larger facility systems.

The package covers construction-facing planning and controls for site grading, drain/containment interfaces, grading/site drainage/spill-containment interfaces, inspection, turnover, and construction interface closeout. It does not replace IFC civil drawings, final geotechnical design, the detailed drainage design, plot plan, construction quality plan, or project-wide turnover procedure.

## Documentation

The Construction Work Package must include or reference:

- construction work package narrative and workface plan;
- IFC grading, drainage, road, retention pond, and containment drawings or drawing index;
- geotechnical and topographical input status;
- applicable permits and environmental controls, if required by project procedure;
- inspection and test plan for grading/drainage work;
- survey and as-built verification plan;
- construction interface and turnover checklist;
- open-item and `TBD` register for geotechnical, hydrology, plot-plan, drainage-design, and field-change items;
- final turnover record package.
