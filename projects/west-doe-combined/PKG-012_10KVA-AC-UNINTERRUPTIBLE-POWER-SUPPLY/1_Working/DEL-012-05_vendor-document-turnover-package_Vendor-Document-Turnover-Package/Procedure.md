# Procedure: Vendor Document Turnover Package

## Purpose

Define the bounded process for producing and checking the `DEL-012-05_vendor-document-turnover-package` turnover package for `PKG-012`, using Gate 7 as the accepted upstream truth.

## Prerequisites

- Accepted Gate 7 PROJECT_DECOMP snapshot dated 2026-05-24.
- Deliverable-local `_CONTEXT.md`, `_REFERENCES.md`, `_DEPENDENCIES.md`, and `_STATUS.md`.
- Vendor document register or interim gap record.
- Vendor document submittals and turnover records when available.
- EPC Integrator review path for Electrical Power, Grounding / Bonding, Maintenance Access, and Structural / Foundations / Supports interfaces.
- No declared upstream dependencies are recorded for this deliverable during PREPARATION.

## Steps

1. Confirm the deliverable identity against Gate 7:
   - `DEL-012-05_vendor-document-turnover-package`;
   - `PKG-012`;
   - 10KVA AC UNINTERRUPTIBLE POWER SUPPLY;
   - Electrical discipline;
   - Vendor Document Turnover type.
2. Establish or obtain the vendor document register.
   - If the only available artifact remains `TBD vendor document register`, record this as an open human-ruling item and do not close turnover.
3. Populate the turnover package with vendor document submittals, source-required vendor documentation rows where available, and turnover records.
4. Confirm each submittal is traceable to the vendor document register by document number/title, revision, status, and review disposition.
5. Route applicable items for EPC Integrator interface/integration review.
6. Record interface review disposition for:
   - Electrical Power;
   - Grounding / Bonding;
   - Maintenance Access;
   - Structural / Foundations / Supports.
7. Identify missing governing details as `TBD`, including document-control procedure, review status codes, turnover acceptance criteria, final record-document requirements, and package-specific exclusions.
8. Compile the turnover package and attach or reference all review evidence and unresolved open items.

## Verification

- Identity fields match Gate 7 registers.
- Required artifact classes are present or explicitly marked `TBD`.
- Vendor/EPC responsibility split is preserved.
- EPC Integrator review evidence exists for each Gate 7 interface type or includes a not-applicable disposition.
- The `TBD vendor document register` gap is resolved by accepted vendor/human evidence before closure.
- No unsupported package-specific requirement has been inserted without an accepted source.

## Records

- Vendor document register.
- Vendor document submittals.
- Turnover records.
- EPC Integrator review comments/status.
- Interface review dispositions.
- Open-item or human-ruling log for unresolved `TBD` items.
- Evidence that Gate 7 gap artifact `ART-68AD3064DD` was replaced or closed.
