# Guidance — DEL-041-05 Vendor Document Turnover Package (PKG-041)

## Purpose

This guidance frames how the Vendor Document Turnover Package is to be assembled, interpreted, and reviewed for PKG-041 (13.8kV, 3.0MW Standby Generator Building 490-1). It supports `OBJ-001`, `OBJ-004`, `OBJ-005`, `OBJ-006`, `OBJ-007`, `OBJ-008`, `OBJ-009`, `OBJ-010` by ensuring the EPC Integrator receives a complete, traceable vendor documentation set sufficient for facility integration, operations, regulatory readiness, and turnover.

## Principles

1. **Source-driven document list.** The applicable document classes come from `_Sources/26020-Package_Requirements.docx` "Vendor Engineering Deliverables". This skill does not invent new document classes for the PKG-041 turnover.
2. **Discipline filtering, not document invention.** The vendor and EPC reviewer apply the source's discipline tables to mark each line APPLICABLE / N/A with a brief rationale, rather than removing or re-inventing IDs.
3. **EPC Integrator as acceptor, not author.** Per `_CONTEXT.md` and `DELIVERABLE_REGISTER.csv` row 232, the Package Vendor authors; the EPC Integrator reviews via `DEL-041-06`. Acceptance is a human decision.
4. **Traceability over volume.** The Vendor Document Index (`PRQ-009`) is the canonical contents list; every document submitted must appear in it with current revision and status. Volume alone is not acceptance.
5. **Codes and standards stay sourced.** Where the accessible source set does not cite a specific standard clause, the turnover set states the applicable standard and leaves clause-level claims to detailed-design documents.
6. **Identity nominal vs. as-engineered.** The package title "13.8kV, 3.0MW" is a nominal identity carried from the workbook (`PACKAGE_REGISTER.csv` row 43). The current facility design basis (DBM-Deepcut line 2943) has shifted to TOU low-voltage standby generators at the 600 V MCC level. Vendor documentation should report as-engineered ratings as ordered, and the EPC Integrator owns reconciliation in `DEL-041-06`.

## Considerations

- **Electrical-led, but building-shaped.** The package is identified Electrical (`PACKAGE_REGISTER.csv` row 43), WBS 01. Electrical and I&C document classes lead the applicable list; mechanical applies extensively because the deliverable is a packaged engine-generator inside a vendor-supplied enclosure (`_Sources/DBM-Deepcut/4-25_Deepcut_DBM.md` lines 2076, 2787). Structural and HVAC apply because the enclosure is a building.
- **Foundations and drainage interface, not interior civil.** The package's Civil/Grading/Drainage interface types (per `PACKAGE_REGISTER.csv` row 43) are tie-in interfaces — the EPC Integrator owns the foundation pad and facility drainage; the Package Vendor provides loads, anchor patterns, and containment basis.
- **Interface basis is wide.** Per `PACKAGE_REGISTER.csv` row 43, applicable interface types include Utility Piping, Drain/Containment, Electrical Power, Grounding/Bonding, Area/Exterior Lighting, I&C/Control Cabling, Communications/Network, Building HVAC/Services, Fire & Gas/Safety Systems, Maintenance Access, Grading/Site Drainage/Spill Containment, Structural/Foundations/Supports. The turnover set must cover each somewhere (basis, drawing, IOM, or interface document).
- **Turnover gate.** Turnover records (`PRQ-016`, `MEC-023`, `ELE-030`, `QLT-020`, `QLT-021`) are the critical evidence for `DEL-041-06` acceptance. Plan FAT/SAT/energization milestones backwards from the EPC Integrator's acceptance gate.
- **Cold-climate, outdoor enclosure.** Per DBM line 2076, the genset is delivered in a vendor-supplied weather-protective enclosure suitable for outdoor installation, with 1 m access walkway maintained. Vendor documentation must address cold-climate operability (heating, fuel selection, battery/charger sizing) and confirm overhead lift provisions.

## Trade-offs

- **Breadth vs. signal.** A wide vendor document set is more defensible at regulatory and operational reviews, but increases review cost and submittal turnaround. Use the discipline applicability call to keep the set tight while preserving traceability.
- **Early submittal vs. as-built quality.** Releasing documents early gives the EPC Integrator time to coordinate facility-level integration but creates revisioning churn. The Vendor Document Control Procedure (`DOC-008`) should establish a small number of named milestones (e.g., preliminary, certified-for-construction, as-built) rather than continuous trickle.
- **Standalone vendor IOM vs. integrated turnover book.** A combined `PRQ-016` book is easier for operations to use long-term; per-document standalone files are easier for vendor revisioning. Decide upfront and reflect in `DOC-008`.
- **Carry nominal package title vs. flag the rating change.** The vendor can either propagate the workbook nominal title across documents (clean but stale) or flag the design-basis change up-front (more truthful, but more revision churn). Recommend flagging via a single rating-basis annotation on the Index and using as-engineered ratings on all engineered documents.
