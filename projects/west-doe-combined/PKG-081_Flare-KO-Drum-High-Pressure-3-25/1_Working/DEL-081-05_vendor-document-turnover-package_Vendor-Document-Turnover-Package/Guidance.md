# Guidance — DEL-081-05 Vendor Document Turnover Package (PKG-081)

## Purpose

This guidance frames how the Vendor Document Turnover Package is to be assembled, interpreted, and reviewed for PKG-081 (Flare KO Drum (High Pressure) 3-25 — two HP flare KO drums V-4100-2 and V-4150-2 and two transfer pumps P-4100-2 and P-4150-2). It supports `OBJ-002`, `OBJ-004`, `OBJ-005`, `OBJ-006`, `OBJ-007`, `OBJ-008`, `OBJ-009`, `OBJ-010` (objectives are associated by package-grouping heuristic and remain ASSUMPTION pending human confirmation) by ensuring the EPC Integrator receives a complete, traceable vendor documentation set sufficient for facility integration, pressure-vessel regulatory readiness, and operations.

## Principles

1. **Source-driven document list.** The applicable document classes come from `_Sources/26020-Package_Requirements.docx` "Vendor Engineering Deliverables" (package heading 34 for PKG-081). This skill does not invent new document classes. Where the docx is not text-accessible at run time, the standard core/discipline ID set is mirrored from the sibling vendor-document-turnover deliverable (e.g., DEL-019-05) which previously walked the same template; rows so mirrored are explicitly labeled **ASSUMPTION** below and in `Specification.md`.
2. **Discipline filtering, not document invention.** The vendor and EPC reviewer apply the source's discipline tables to mark each line APPLICABLE / N/A with a brief rationale, rather than removing or re-inventing IDs.
3. **EPC Integrator as acceptor, not author.** Per `_CONTEXT.md` and the DELIVERABLE_REGISTER row, the Package Vendor authors; the EPC Integrator reviews and accepts via `DEL-081-06`. Acceptance is a human decision.
4. **Traceability over volume.** The Vendor Document Index (`PRQ-009`) is the canonical contents list; every document submitted must appear in it with current revision and status.
5. **Codes and standards stay sourced.** Where the accessible source set does not cite a specific standard clause (the case for most code citations on PKG-081 at this stage), the turnover set states the applicable standard and leaves clause-level claims to detailed-design documents.
6. **Pressure-vessel rigor.** Because the package contains ASME-regulated pressure vessels (HP flare KO drums) in flare service, ITP hold/witness points, NDE records, hydrostatic test certificates, and ASME Data Reports are not optional — they are the spine of the turnover record.

## Considerations

- **Mechanical discipline center.** The package is identified Mechanical (`PACKAGE_REGISTER.csv` row 54), WBS 02. Mechanical equipment, pressure-vessel, and rotating-equipment document classes dominate. Electrical and I&C apply for the transfer-pump drivers and the KO drum instrumentation. Civil applies for vessel saddles, anchor bolts, and pump skid foundations.
- **Multiple identical equipment items.** The package contains two HP KO drums (V-4100-2 in the compressor area; V-4150-2 in the tank farm) and two HP KO drum transfer pumps (P-4100-2, P-4150-2, 1 x 100% per KO drum per DBM line 583). The vendor document set should clearly separate per-tag documentation while allowing reuse where the items are identical.
- **Flare-system context.** The HP KO drums sit upstream of a sonic HP/Cryo flare stack (660 mm OD by 60,957 mm tall per DBM line 499) that is shared with the 4-25 facility. The HP relief header is 508 mm / 20 in. Vendor documents must clearly identify nozzle sizes, ratings, and orientation against this header; flare-stack design is outside this vendor's scope.
- **Interface basis.** Per `PACKAGE_REGISTER.csv` row 54, applicable interface types include: Process Piping; Relief / Flare / Vent; Drain / Containment; Electrical Power; EHT; Grounding / Bonding; Area / Exterior Lighting; I&C / Control Cabling; Maintenance Access; Structural / Foundations / Supports. Vendor documents must cover each of these interfaces somewhere in the turnover set.
- **Cold-climate site.** Per DBM context (3-25 plant), heat tracing (EHT), winterization, and electrical area-classification documentation are facility-level expectations that affect vendor documentation content even where the documents themselves are issued in standard ID classes.
- **Turnover gate.** Turnover records (`PRQ-016`, `MEC-023`, `QLT-020`, `QLT-021`, hydrostatic test certificates, ASME Data Reports) are the critical evidence for `DEL-081-06` acceptance. Plan FAT/hydrotest/release milestones backwards from the EPC Integrator's acceptance gate.

## Trade-offs

- **Breadth vs. signal.** A wide vendor document set is more defensible at regulatory and operational reviews, but increases review cost and submittal turnaround. Use the discipline applicability call to keep the set tight while preserving traceability.
- **Early submittal vs. as-built quality.** Releasing documents early gives the EPC Integrator time to coordinate facility-level integration but creates revisioning churn. The Vendor Document Control Procedure (`DOC-008`) should establish a small number of named milestones (e.g., preliminary, certified-for-construction, as-built) rather than continuous trickle.
- **Per-tag vs. consolidated documentation.** Two identical KO drums and two identical pump trains can be documented with shared design reports and per-tag MTRs/NDE/hydrotest records, reducing redundancy. Alternatively, fully per-tag books keep each train independently auditable. Decide upfront and reflect in `DOC-008`.
- **Standalone vendor IOM vs. integrated turnover book.** A combined `PRQ-016` book is easier for operations to use long-term; per-document standalone files are easier for vendor revisioning. Decide upfront and reflect in `DOC-008`.

## Examples

- The source's standard `Vendor Engineering Deliverables` template is the same template instantiated for every package in the workbook; the PKG-019 vendor-document-turnover deliverable (an MV VFD package) walked the same template and produced an analogous Datasheet/Specification/Guidance/Procedure set. PKG-081 instantiates the same shape with Mechanical/pressure-vessel-appropriate discipline filtering instead of Electrical/I&C-centric filtering.
- DBM line 583 explicitly enumerates "HP flare KO drum transfer pumps - One per KO drum, 1 x 100 percent" as a facility-design requirement, validating the per-tag pump documentation expectation and the 1 x 100 % redundancy assumption used in `Specification.md`.
