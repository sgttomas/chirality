# Procedure — DEL-066-05 Vendor Document Turnover Package

## Purpose

Operational steps to produce, control, review, and turn over the vendor document set for the 4-25 condensate storage tank package (26020-01-PT-19-004; tanks TK-9110-1..TK-9150-1), culminating in EPC Integrator acceptance.

## Prerequisites

| Item | Notes |
|---|---|
| DEL-066-01 Scope of Work (EPC) | Available and current — defines vendor scope contractually. |
| DEL-066-02 Package Datasheet (EPC) | Available and current — defines vendor design inputs and interface matrix. |
| DEL-066-03 Construction Work Package (EPC) | Available — defines installation/tie-in interfaces vendor docs must support. |
| DEL-066-04 Vendor Engineered Equipment Package | In progress — vendor must be under contract and engineering active. |
| Source package specification | 26020-Package_Requirements.docx §26020-01-PT-19-004 accessible to vendor and EPC reviewers (note: 4-25 scope is analog-based; RFQ pending). |
| Analog RFQ | `26020-03-PT-19-006_Tanks_Cond/Bid Docs/Budgetary/26020-03-PT-RFQ-19-006 - Conde Tanks.docx` (location TBD; required as analog reference until 4-25 RFQ issues). |
| Document control system | Vendor and EPC Integrator each operate an electronic document management system (TBD which platforms). |

## Steps

### 1. Establish document control basis
1.1 Vendor issues DOC-008 Vendor Document Control Procedure for EPC review.
1.2 Vendor issues initial PRQ-009 Vendor Document Index listing every document required by Specification R-01..R-19 plus any additional RFQ-imposed items.
1.3 EPC Integrator reviews DOC-008 and PRQ-009; aligns on status codes, transmittal numbering, revision conventions, and expected submittal schedule (target dates).
1.4 PRQ-009 becomes the live register; vendor updates it with every submittal/revision.

### 2. Engineering submittal cycle (iterative)
2.1 Vendor produces engineering documents per the index (MEC-001..MEC-025; MEC-005 Static Equipment Specifications; MEC-011 Storage Tank Data Sheets; PRO-008/014..018/023; PIP-003..028; CIV-014; PLN-015/016; INS/CTL set; ELE-012/017/019; STR-001..020; CIV-003/004/015/019).
2.2 Vendor issues each submittal under a transmittal with explicit revision and status code.
2.3 EPC Integrator routes each submittal to the responsible discipline reviewer.
2.4 Reviewer returns disposition: approved / approved-with-comments / not-approved / for-information.
2.5 Vendor re-issues as required; update PRQ-009 to reflect current status.
2.6 Verify discipline-level consistency at each revision (e.g., MEC-011 Tank Data Sheets vs MEC-003 Equipment Data Sheets; PRO-014..018 Relief/Flare basis vs INS-016/017 Control/Shutdown Valve Data Sheets; STR-005/006 Foundation vs CIV-003 Grading). Raise Conflict Table entries when disagreements appear.

### 3. Quality and inspection execution
3.1 Vendor issues QLT-006 Supplier Quality Plan and QLT-003 Inspection and Test Plan for EPC approval before fabrication.
3.2 Witness and hold points executed per the approved ITP for tank shell, bottom, roof, weld inspection, nozzle attachment, and appurtenance fit-up; EPC Integrator (or its inspection authority) witnesses as required.
3.3 Material Test Reports / Certificates (QLT-013) collected for shell, bottom, roof plate, nozzles, and weld consumables.
3.4 Non-conformance reports (NCRs) raised and dispositioned per QLT-006.

### 4. Hydrotest (in lieu of conventional FAT for field-erected tanks)
4.1 Vendor issues MEC-021 (Equipment FAT / Performance Test Procedure — interpreted as hydrotest procedure) for EPC approval prior to test.
4.2 Hydrotest executed per API 650 modified requirements (settlement survey, hold periods, leak inspection); EPC Integrator attends per RFQ.
4.3 Vendor issues MEC-022 (Equipment FAT / Performance Test Report — interpreted as hydrotest report) and addresses punch-list items.

### 5. Pre-release / pre-handover
5.1 All open NCRs closed or accepted with concession.
5.2 Manufacturing Record Book (QLT-021) assembled and reviewed (includes shop-fabrication records for sub-assemblies plus field-erection records for site-built portions).
5.3 Inspection Release Certificate (QLT-020) signed; package released for site handover.
5.4 PRQ-013 Logistics / Shipping Plan executed for shop-fabricated components and field-erection material deliveries.
5.5 PRQ-015 SPIR submitted (commissioning and operating spares: tank gauges, PVRV/EPRV cartridges, blanket-gas regulator parts, etc.).
5.6 Jurisdictional registration submission (if applicable; see Guidance Conflict Table C-03).

### 6. Site and commissioning records
6.1 Vendor supports installation and commissioning per IOM (MEC-025).
6.2 Instrument loop checks (INS-008) and Cause-and-Effect verification (CTL-005) completed at site.
6.3 Piping As-Built Drawings (PIP-028) updated as installed (tank nozzle tie-ins, blanket-gas, vent, drain, truck-out).
6.4 Cathodic protection commissioning records (PLN-016) completed; reference cell potentials recorded.
6.5 Blanket gas system and PVRV/EPRV setting verification completed; records retained.
6.6 Punch-list items closed.

### 7. Final turnover
7.1 Vendor assembles PRQ-016 Vendor Data Book / Final Supplier Documentation and MEC-023 Mechanical Final Documentation Vendor Data Book using accepted final-revision documents from PRQ-009.
7.2 Vendor transmits Final VDB to EPC Integrator.
7.3 EPC Integrator performs completeness check against PRQ-009 and the source-required document list.
7.4 EPC Integrator records acceptance in DEL-066-06 (EPC Vendor Package Review and Acceptance log).
7.5 PRQ-009 closed at final revision; turnover record set frozen.

## Verification

| Check | Method | Acceptance |
|---|---|---|
| PRQ-009 completeness | Compare index entries against the Specification R-01..R-19 enumerated documents and against any additional RFQ items | Every required document present, with current revision and status |
| Document status integrity | Random audit of 5 documents per submittal cycle | Status codes correct; transmittals reconcile |
| ITP execution | Inspection records vs ITP | Every hold/witness point signed |
| Hydrotest acceptance | MEC-022 review | Hydrotest report signed; punch list captured |
| Pre-release | QLT-020 IRC signed | All NCRs closed or concessioned |
| Jurisdictional registration | Acceptance letter on file (if applicable) | Acceptance letter present |
| Final VDB completeness | Completeness audit by EPC | 100% of PRQ-009 final-revision items present in VDB |
| EPC acceptance | DEL-066-06 acceptance log entry | Signed acceptance |
