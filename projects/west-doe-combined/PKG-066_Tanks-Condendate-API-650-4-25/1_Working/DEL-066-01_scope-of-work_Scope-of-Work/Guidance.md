# Guidance — DEL-066-01 Scope of Work (PKG-066 Tanks, Condendate (API 650) 4-25)

## Purpose

This Scope of Work is the EPC Integrator's anchoring statement of *what the condensate tank package is and how it integrates into the facility*. It is the upstream deliverable that the Package Datasheet, Construction Work Package, vendor production unit, vendor document turnover, and EPC review/acceptance deliverables all consume (per `DELIVERABLE_REGISTER.csv` for `PKG-066`). Getting identity, function, boundary, responsibility, and interface set correct here prevents downstream rework when the vendor receives the technical handoff.

Source: `_CONTEXT.md`; `DELIVERABLE_REGISTER.csv`; package note "Mandatory Gate 5 EPC anchor deliverable defined by user instruction".

## Principles

1. **Vendor owns the package; EPC owns the integration.** Package engineering, design, vendor documentation, and equipment supply belong to the Package Vendor. Interfaces, tie-ins, constructability, procurement/construction coordination, and facility-level integration belong to the EPC Integrator. This split is the controlling responsibility model for `PKG-066`. Source: `PACKAGE_REGISTER.csv` ResponsibilityModel.
2. **Source-anchored content; no invention.** Every non-trivial statement should cite Workbook Packages row 89, `26020-Package_Requirements.docx` package heading 21, the 04-25 Deepcut DBM, or another locally accessible source slice. Where a value is not in an accessible slice, mark `TBD` with `location TBD` rather than inferring it. Source: SKILL `four-documents` source-grounding rule.
3. **Interface set is exhaustive at the package boundary.** The nine interface types in `INTERFACE_REGISTER.csv` for `PKG-066` (Process Piping; Relief/Flare/Vent; Drain/Containment; Grounding/Bonding; Area/Exterior Lighting; Cathodic Protection; I&C/Control Cabling; Grading/Site Drainage/Spill Containment; Structural/Foundations/Supports) form the integration surface. Omitting any of them in the SOW will create a hidden EPC scope item downstream. Source: `INTERFACE_REGISTER.csv`.
4. **3-25 analog is a basis, not a requirement.** SOW-0206 and SOW-0207 cite the 3-25 condensate tank package as the nearest analog (four 3,800 bbl tanks). The Deepcut roster suggests five 4-25 tanks. Neither value is yet a confirmed design requirement for 4-25; both are candidate bases pending human confirmation. Source: `SCOPE_LEDGER.csv` SOW-0207/0208.
5. **Commercial disposition anchors the storage function.** C5+ condensate is the on-spec product delivered to the NorthRiver Midstream NEBC Connector via LACT (with cross-facility transfer between 04-25 and the 03-25 Liquids Hub). The SOW should preserve this disposition because it is what makes the tanks *product* storage rather than slop or intermediate storage. Source: `DBM-Deepcut/4-25_Deepcut_DBM.md` Process and Commercial Basis; `OBJ-003`.

## Considerations

- **Tag preservation.** No specific tank tags are stated in locally accessible slices for 4-25; carry `TBD` for individual tank tags and explicitly cite that the Deepcut roster's tank count (five) and the 3-25 analog tank list (four × 3,800 bbl) are candidates only.
- **VRU and blanket gas ownership.** SOW-0207 lists VRU header connection and blanket gas as part of the major equipment, but does not specify which interface (Process Piping vs. Relief/Flare/Vent vs. a separate fuel-gas service) owns the blanket-gas supply and the VRU tie-in. Resolve in Datasheet/Construction Work Package; captured as Conflict ID `CONF-066-01-01` below.
- **Mercaptan treating bypass/recycle.** SOW-0208 explicitly flags whether mercaptan treating bypass/recycle paths apply at 4-25 as an open item. The SOW should not commit either way; the open item belongs in the Conflict Table.
- **Cathodic protection / grounding split.** SOW-0207 lists grounding and cathodic protection as provisions inside the tank package, while `INTERFACE_REGISTER.csv` lists both as facility-level interfaces. The package-vs-facility split for CP rectifier supply, test station placement, and tank-bottom anodes is not delineated in accessible slices; captured as Conflict ID `CONF-066-01-02`.
- **Spacing-driven plot impact.** Atmospheric condensate tank spacing rules from the DBM (e.g., ≥50 m from flare; ≥30.48 m from pressurized bullets; ≥80 m from public road) materially constrain plot. Carry these as facility-integration considerations even though they are facility-spacing rather than package-internal requirements.
- **Analog source treated as informational only.** `26020-03-PT-RFQ-19-006 - Conde Tanks.docx` (3-25 condensate tank analog) and the 3-25 DBM are identified as analog references. Do not promote any value from them into 4-25 requirements without explicit human ruling. Source: `PACKAGE_REGISTER.csv` SourceRefRaw.

## Trade-offs

- **Specificity vs. source coverage.** Locally accessible slices (workbook row 89, scope ledger rows SOW-0205…0208, package register PKG-066, interface register, DBM site/spacing and commercial basis) describe identity, function, candidate equipment, responsibility, and interface set, but do not provide clause-level design conditions, tank counts, or material grades for 4-25. SOW content should be specific where source supports it and explicitly `TBD` (with `location TBD`) elsewhere. Pushing more detail into the SOW than source supports compromises auditability.
- **EPC-authored vs. vendor-authored content.** This SOW is EPC-authored; technical design content belongs in the Package Datasheet (`DEL-066-02`) and the vendor's engineered equipment package (`DEL-066-04`). Resist drift of vendor design content (tank shell thickness, weld details, foundation loads) into this deliverable.
- **Interface enumeration vs. interface design.** Naming the nine applicable interfaces in this SOW satisfies the integration narrative requirement; interface *design* (line sizes, EHT circuits, cable schedules, foundation loads) belongs in the Package Datasheet and downstream EPC discipline deliverables.
- **Carry-the-question vs. resolve-the-question.** SOW-0208 is structured as an open-items list. The SOW should *preserve* those open items as TBD/Conflict-Table entries rather than guessing answers. Resolution belongs to subsequent deliverables and explicit human ruling.

## Examples

Source-grounded statement (good):
> "The package supplies condensate product storage tanks for 4-25 on-spec C5+ condensate product storage, using the 3-25 condensate tank package as the nearest analog (SOW-0206; `26020-Package_Requirements.docx` heading 21, Basic scope). The major equipment basis includes API 650 modified atmospheric tanks with blanket gas, PVRV/EPRV protection, VRU header connection, grounding/cathodic protection provisions, tank instrumentation, and standard appurtenances (SOW-0207). Final tank count, tags, and capacity are TBD — the Deepcut roster indicates five tanks and the 3-25 analog uses four 3,800 bbl tanks (SOW-0207/0208)."

Insufficiently grounded statement (avoid):
> "The package supplies four 3,800 bbl API 650 condensate tanks." — the 3-25 analog values are not yet confirmed for 4-25; this would silently adopt the analog as a requirement. Use the TBD + candidate-basis form instead.
