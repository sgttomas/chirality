# Guidance — Package Datasheet for Storage Bullets (PKG-059)

> Directional guidance for the EPC Integrator authoring `DEL-059-02_package-datasheet`. This document explains *why* the requirements in `Specification.md` are framed as they are and the trade-offs the author should weigh when interpreting source ambiguities.

## Purpose

The Storage Bullets Package Datasheet is the technical handoff anchor between the EPC Integrator and the Package Vendor (RFQ tag `26020-01-PT-RFQ-17-007`) for engineering, fabrication, and supply of the two unstable condensate storage bullets and sixteen LPG product storage bullets. It exists so that the vendor receives a single, source-grounded statement of *what the package must do, where it connects, and what regulatory and project-spacing constraints govern its layout* — without requiring the vendor to mine the source documents directly.

## Principles

1. **Source over narrative.** The authoritative source slice for bullet attributes is `26020-Package_Requirements.docx` package heading 14, extracted in `SCOPE_LEDGER.csv` rows SOW-0182..SOW-0184. The Deepcut DBM (`_Sources/DBM-Deepcut/4-25_Deepcut_DBM.md`) is the authoritative source for layout/spacing (API 2510). Decomposition prose and `_CONTEXT.md` route and frame the deliverable; they do not generate design values.
2. **Carry interface facts as evidence.** The decomposition explicitly chose to fold package interfaces into this deliverable rather than create a standalone interface deliverable (`_CONTEXT.md` Notes; PACKAGE_REGISTER scope-split text). The datasheet therefore includes the Interface Requirements Matrix covering all ten declared interface types and does not push them elsewhere.
3. **Mark, don't invent.** Where the source slice does not provide a value (MOC, MAWP, internals, nozzle schedule, per-bullet LPG service mix, EHT specifics), the datasheet records `TBD` rather than typical industry values. The RFQ document itself (`26020-01-PT-RFQ-17-007`) is the most likely repository of these values but is not locally accessible in this pass.
4. **Spacing is a hard input.** API 2510 pressurized-bullet spacing values from the DBM-Deepcut table are not vendor design parameters but are EPC layout constraints. They go on the datasheet so the vendor's cluster geometry, skid envelope, and platform layout are compatible with the plot plan.
5. **Preserve traceability to scope and objectives.** Every requirement is traceable to one or more of `SOW-0181`..`SOW-0184` and to the package-heuristic objective set (`OBJ-001`, `OBJ-003`..`OBJ-010`).
6. **Surface, do not silently reconcile, source conflicts.** The DBM-Deepcut treats post-depropanizer storage as NGL storage; the SCOPE_LEDGER (per the 26020 package heading 14 extract) treats it as LPG product (C3, C4, C3/C4 mix). This is captured in the Conflict Table rather than smoothed over in prose.

## Considerations

- **Two services, one package.** The package contains two distinct services: two bullets storing C5 unstable condensate (upstream of the condensate transfer pumps) and sixteen bullets storing LPG product (downstream of the depropanizer, en route to the off-site liquids hub via booster pumps). The vendor must produce equipment datasheets that distinguish the two services even though both come under the same RFQ.
- **LPG composition is open at the per-bullet level.** SOW-0184 states "C3, C4, or C3/C4 LPG mix" but does not allocate which of the sixteen bullets holds which composition. This affects nozzle sizing, vapour-equalization topology, and butane blanket-gas distribution. The Datasheet records the constraint set and marks the allocation TBD.
- **Vapour equalization without pockets.** SOW-0184 requires that LPG vapour equalization piping must avoid pockets. This is a topology and slope constraint on the package piping plan and should be flagged for vendor attention; the vendor's piping isometric should show no pockets between equalized bullets.
- **Butane blanket gas.** SOW-0184 explicitly requires blanket gas for butane storage. The Datasheet records this; the blanket-gas source (fuel gas? inert gas?) is a project decision not yet visible in the source slice and is TBD.
- **Cluster spacing dominates plot plan.** DBM-Deepcut lines 245-259 carry API 2510 spacing values that constrain cluster geometry: max 6 bullets per cluster, 15.24 m between clusters, 38.1 m to property line, 30.48 m to nearest atmospheric tank. With sixteen LPG bullets plus two condensate bullets (eighteen total), the plot plan needs at least three clusters of LPG bullets plus the condensate-bullet cluster, with inter-cluster geometry that respects all of the above. The datasheet conveys these constraints so the vendor's skid envelope and platform layout do not assume a tighter footprint than the plot plan allows.
- **"By others" scopes drive interface clarity, not vendor scope reduction.** Foundations, DCS integration, and electrical MCC supply are by others (SCOPE_LEDGER SOW-0184). The interface matrix captures EPC ownership for those scopes; the vendor still must provide the data needed for the EPC to execute them (saddle reactions, anchor bolt patterns, I/O list, MCC load list).
- **Facility-of-record is assumed (CONF-01).** The package row PACKAGE_REGISTER.csv does not name a facility, but DBM-Deepcut places NGL/product storage bullets at 04-25 (line 1627-1629). The Datasheet assumes 04-25 as facility-of-record. If detailed design later places one of the storage bullet groups at the 03-25 Liquids Hub, the facility-of-record statement must be revised.
- **Native RFQ and interface workbook not parsed in this pass.** `26020-01-PT-RFQ-17-007` (the RFQ for these bullets) and `26020-Packages_Interfaces_4_export.xlsx` (the interface workbook) were not text-extracted in this pass. Items derived solely from those native files are TBD and should be picked up in a later semantic-lensing or detailed-design pass.

## Trade-offs

- **One package datasheet vs. per-bullet datasheets.** Carrying both bullet services and all eighteen vessels in one package datasheet matches the RFQ tag (single RFQ for the package) but creates a dense document. The EPC Integrator should produce vendor-facing per-vessel datasheets *derived from* this package datasheet, not in place of it.
- **PACKAGE_HEURISTIC objective association.** Objectives `OBJ-001`, `OBJ-003`..`OBJ-010` are inherited from the package row and labeled ASSUMPTION per skill default (`OBJECTIVE_ASSOCIATION_MODE = PACKAGE_HEURISTIC`). A future tightening to deliverable-ID-level mapping may narrow this set.
- **EPC/Vendor interface split (PROPOSAL).** The split column in the Interface Requirements Matrix is a PROPOSAL framed by package-level responsibility text and standard EPC convention. Until `26020-Packages_Interfaces_4_export.xlsx` is parsed, individual line-item splits remain provisional.
- **Carrying spacing constraints on the datasheet vs. only on layout drawings.** Spacing values are conventionally on plot plans, not vendor equipment datasheets. We carry them on this datasheet because the decomposition explicitly folds interface facts into the datasheet (`_CONTEXT.md` Notes); a vendor reading only this document still needs to size skids and platforms to respect them.
- **Cite SCOPE_LEDGER vs. cite native .docx.** SCOPE_LEDGER carries character-for-character extractions of the package heading 14 text. We cite SCOPE_LEDGER as the proximate source and note `26020-Package_Requirements.docx package heading 14; native .docx not parsed in this pass` as the underlying source. When the .docx is parsed in a future pass, citations should be tightened to the native source.

## Examples

- A reference passage to cite when stating bullet dimensions and design conditions:
  > "Two unstable condensate storage bullets and sixteen LPG product storage bullets. Each bullet is 3658 mm ID x 42494 mm S/S, nominally 454 m3 / 120,000 US gal at 84% maximum volume, designed for 1724 kPag at 66 C and full vacuum, with outdoor saddle mounting and stairs/platforms." — `SCOPE_LEDGER.csv` row SOW-0183 (extract of `26020-Package_Requirements.docx` package heading 14, Major included equipment).
- A reference passage to cite when stating cluster spacing:
  > "Pressurized bullet maximum per cluster | <=6 | API 2510" and "Distance between pressurized bullet clusters | 15.24 m (50 ft) | API 2510." — `_Sources/DBM-Deepcut/4-25_Deepcut_DBM.md`, lines 249-250 (Sec. Pressurized Bullet Spacing).
- A reference passage to cite when stating "by others" exclusions:
  > "Foundations, DCS integration, and electrical supply to MCC are by others." — `SCOPE_LEDGER.csv` row SOW-0184.
