# Guidance — DEL-058-01 Scope of Work (PKG-058 Medium Pressure Flash Feed Separator)

## Purpose

This Scope of Work is the EPC Integrator's anchoring statement of *what the MPFF package is and how it integrates into the facility*. It is the upstream deliverable that the Package Datasheet (`DEL-058-02`), Construction Work Package (`DEL-058-03`), Vendor Engineered Equipment Package (`DEL-058-04`), Vendor Document Turnover (`DEL-058-05`), and EPC Vendor Package Review and Acceptance (`DEL-058-06`) all consume (per `DELIVERABLE_REGISTER.csv` for `PKG-058`). Getting identity, function, boundary, responsibility, interface set, and capacity/condition basis correct here prevents downstream rework when the vendor receives the technical handoff.

Source: `_CONTEXT.md`; `DELIVERABLE_REGISTER.csv`; package note "Mandatory Gate 5 EPC anchor deliverable defined by user instruction".

## Principles

1. **Vendor owns the package; EPC owns the integration.** Package engineering, design, vendor documentation, and equipment supply belong to the Package Vendor. Interfaces, tie-ins, constructability, procurement/construction coordination, and facility-level integration belong to the EPC Integrator. This split is the controlling responsibility model for `PKG-058`. Source: `PACKAGE_REGISTER.csv` ResponsibilityModel.
2. **Source-anchored content; no invention.** Every non-trivial statement should cite Workbook Packages row 71, `26020-Package_Requirements.docx` package heading 13, the 04-25 Deepcut DBM, or another locally accessible source slice. Where a value is not in an accessible slice, mark `TBD` with `location TBD` rather than inferring it. Source: SKILL `four-documents` source-grounding rule.
3. **Interface set is exhaustive at the package boundary.** The nine interface types in `INTERFACE_REGISTER.csv` for `PKG-058` form the integration surface. Omitting any of them in the SOW will create a hidden EPC scope item downstream. Source: `INTERFACE_REGISTER.csv`. Note: Electrical Power is *not* a declared package-boundary interface type for PKG-058 even though SOW-0142 names "electrical power supply from plant MCC" as a by-others item — see Conflict Table.
4. **Train pairing context.** Per the facility DBM, one MPFF and one stabilizer act as a single inlet liquids processing train; if a stabilizer is out of service, its corresponding MPFF is also not operational. Normal operating sparing is 2 x 100%. Treat the MPFF as part of a paired train, not as an isolated mechanical skid. Source: `DBM-Deepcut/4-25_Deepcut_DBM.md` (MPFF and Stabilizer Train Relationship).
5. **Carry source-stated TBDs forward; do not "resolve" them in the SOW.** SOW-0142 explicitly leaves Design Pressure as TBD. The facility DBM additionally flags MPFF low and expected-high operating pressures, post-upstream-HEX inlet temperatures, and internal heater-bundle retention as open items. The SOW must reproduce these as TBDs; resolution belongs in the Package Datasheet and downstream process simulation work. Source: `SCOPE_LEDGER.csv` SOW-0142; `DBM-Deepcut/4-25_Deepcut_DBM.md`.

## Considerations

- **Tag preservation.** The facility DBM names `V-7110-1` and `V-7310-1` for the two MPFF vessels (one per inlet-liquids train). The package requirements clause (SOW-0140/0141) does not state these tags. Carry the DBM tag binding as an ASSUMPTION; downstream P&ID, datasheet, and construction documents will need confirmed tag assignment.
- **Operating-temperature CONFLICT.** SOW-0142 states an operating inlet temperature of −9.55 °C. The facility DBM (4-25 Deepcut DBM, MPFF section) describes pre-HEX winter temperature values as *not current design values* and indicates a design operating temperature of 40 °C is assumed pending upstream HEX thermal reassessment. The SOW must surface both values and mark the discrepancy for human ruling (see Conflict Table CONF-058-01-01).
- **EHT + winterization scope ownership.** EHT is a declared package-boundary interface, and the facility DBM identifies methanol injection upstream of the MPFF inlet level/pressure control valve as a retained safeguard pending HEX outlet temperature confirmation. Specific ownership of trace circuits, controllers, and methanol injection scope is TBD at SOW level; capture in CONF-058-01-02 if unresolved.
- **By-others vs. interface declarations.** SOW-0142 names "interconnecting piping at skid edge, DCS integration, foundations, electrical power supply from plant MCC, installation/erection" as by-others. These map to Process Piping, I&C / Control Cabling, Structural / Foundations / Supports, Electrical Power (not declared as an interface row for PKG-058 — see CONF-058-01-03), and construction-coordination scope respectively. The SOW should explicitly cross-walk by-others items to the interface set so that nothing falls between the package boundary and the EPC discipline scope.
- **Budgetary Word source is informational only.** `Bid Docs/Budgetary/26020-01-PT-RFQ-17-006_MPFF Separator_R0.docx` is the Word source basis listed in `PACKAGE_REGISTER.csv`. Do not promote any value from it into a requirement without explicit human ruling. Source: `PACKAGE_REGISTER.csv` SourceRefRaw.
- **Internal heater bundle disposition.** The facility DBM keeps the MPFF hydrocarbon liquid heater bundle (U-bundle / BKU arrangement) under evaluation after upstream HEX installation. The SOW must not commit to retention or removal; downstream Package Datasheet resolves bundle scope. Source: `DBM-Deepcut/4-25_Deepcut_DBM.md` (MPFF section).

## Trade-offs

- **Specificity vs. source coverage.** The accessible source slices give identity, function, equipment list, by-others scope, operating conditions, design conditions (with explicit Design Pressure TBD), responsibility, and interface set. Beyond that, design values are not in locally accessible clauses. Pushing more detail into the SOW than source supports compromises auditability.
- **EPC-authored vs. vendor-authored content.** This SOW is EPC-authored; technical design content (vessel sizing, materials, code-stamp data, residence-time geometry beyond the DBM 10-minute statement) belongs in the Package Datasheet (`DEL-058-02`) and the vendor's engineered equipment package (`DEL-058-04`).
- **Train-level vs. package-level statements.** The facility DBM speaks at the inlet-liquids-train level (MPFF + stabilizer pairing, 2 x 100% sparing, line-pack scenarios). The SOW is package-level. Carry train-level facts only as integration context, not as package requirements.

## Examples

Source-grounded statement (good):
> "The package supplies one (1) MPFF Separator — Two Phase fitted with a mistex mist extractor, a heated self-framing building module enclosing instrumentation and one vessel end, two PITs, one TIT, two LTs (condensate level; produced-water level), and one inlet LCV (SOW-0141; `26020-Package_Requirements.docx` heading 13, Major included equipment)."

Insufficiently grounded statement (avoid):
> "The MPFF vessel is designed for 2,500 kPag at 60 °C, carbon steel SA-516 Grade 70 with 3 mm corrosion allowance." — there is no locally accessible source slice for these values; mark `TBD` with `location TBD`.
