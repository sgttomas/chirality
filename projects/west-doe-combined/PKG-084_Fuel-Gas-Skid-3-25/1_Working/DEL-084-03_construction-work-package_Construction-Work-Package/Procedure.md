# Procedure — Construction Work Package (DEL-084-03)

Pass: P1_P2 (initial draft + cross-reference sweep)

Interpretation: This procedure describes how to **produce** the Construction Work Package (CWP) for PKG-084 Fuel Gas Skid 3-25 and how the CWP is **used** to execute and turn over the field installation.

## Prerequisites

- Accepted GATE-07 PROJECT_DECOMP snapshot (source: `_REFERENCES.md`).
- Accessible `3-25_Comp_and_Liquids_DBM.md` (source basis for cross-facility utility context).
- Vendor package documents for PKG-084 (datasheets, cause-and-effect, shipped-loose list, vendor document register) — TBD when issued.
- Skid-specific clauses from `26020-Package_Requirements.docx` heading 37 — TBD (binary source not yet extracted).
- Accepted geotechnical report (R-3 input) — TBD.
- Accepted plot plan, equipment list, and miscellaneous facilities list (R-10 input).
- Hazard review outcome for sweet-gas purge / mercaptan exposure (source: `3-25_Comp_and_Liquids_DBM.md` lines 467-469).
- Coordination agreement with the 04-25 operator/owner for shared utility interfaces (ASSUMPTION; authority TBD).
- Human ruling on emergency buyback fuel gas (Conflict C-1 in `Guidance.md`).

## Steps

### A. Produce the CWP

1. Compile the CWP basis section citing the GATE-07 snapshot, the DBM utility context, and the vendor package issue revision.
2. Build the field tie-in list (R-1) by walking every skid boundary connection: process LP fuel-gas headers, blanket-gas branches, purge supply, drains, vents, electrical home-runs, control loops, fire/gas detection, HVAC/heat tracing.
3. Build the skid-edge isolation register (R-2) using the facility isolation philosophy as a baseline.
4. Reference the accepted geotechnical report and confirm foundation/site-prep values are no longer placeholders (R-3).
5. Develop the cold-weather construction plan (R-4), including winter pours, insulation/heat-tracing close-out, and personnel protection.
6. Cross-check vendor package deliverables (R-5) against the document register; raise gaps to the vendor before mobilization.
7. Coordinate multi-discipline interfaces (R-6) at a joint walkdown; capture outcomes in the interface checklist.
8. Draft the workface plan (R-8) covering installation sequencing, tie-in execution windows (including any 04-25 outage windows), and access management.
9. Draft the turnover/interface checklist (R-7) aligned to mechanical completion, pre-commissioning, commissioning, and operations handover gates.
10. Assemble the ITP package (R-11): skid setting tolerances, piping hydrotest/pneumatic test, electrical/loop checks, fire/gas commissioning. Skid-specific ITP detail is TBD pending vendor input.
11. Resolve open items: Conflict C-1 (emergency buyback) per human ruling; Conflict C-2 (heading 37 source slice) by extracting and incorporating before final issue.
12. Issue the CWP for construction only after R-10 inputs are at accepted revision and all `NEEDS_HUMAN_RULING` items are closed.

### B. Use the CWP in the field

1. Mobilize per the workface plan; confirm geotechnical and civil readiness at the skid foundation location.
2. Receive, inspect, and set the skid per vendor handling instructions and the cold-weather plan.
3. Execute mechanical hookups per the field tie-in list, signing each tie-in line by line.
4. Energize/connect electrical, instrument, and controls per home-run schedule; perform loop checks per ITP.
5. Execute the purge and pre-commissioning plan only after the mercaptan/purge hazard review acceptance is in hand.
6. Walk down skid-edge isolation against the register and confirm operable, tagged, and registered.
7. Complete the turnover checklist with operations; obtain mechanical completion sign-off.
