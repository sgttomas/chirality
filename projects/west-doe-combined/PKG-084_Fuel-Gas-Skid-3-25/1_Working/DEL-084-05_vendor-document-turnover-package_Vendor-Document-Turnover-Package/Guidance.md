# Guidance — DEL-084-05 Vendor Document Turnover Package (PKG-084)

## Purpose

The Vendor Document Turnover Package exists so that all vendor-originated documentation for the PKG-084 Fuel Gas Skid 3-25 — the register, the submittals themselves, source-required vendor document rows carried as artifacts, and turnover records — is collected, controlled, reviewable by the EPC Integrator, and able to support package acceptance and operational handoff. It is the documentation half of the Package Vendor production scope; the engineered equipment itself is DEL-084-04. (`_CONTEXT.md` Scope; DELIVERABLE_REGISTER.csv rows DEL-084-04, DEL-084-05.)

## Principles

- The Package Vendor authors and owns this deliverable; EPC Integrator reviews and accepts it via DEL-084-06. (`_CONTEXT.md` Identity; DELIVERABLE_REGISTER.csv row DEL-084-06.)
- The vendor document register is the spine: every required vendor document for the package appears as a register row, and every submittal traces back to a register row. (DBM-Comp_and_Liquids line 617; `_CONTEXT.md` Anticipated Artifacts.)
- Source-required vendor document rows are carried as artifacts/evidence under this deliverable, not as separate deliverables, to preserve the decomposition principle that documents are evidence for a single production unit. (`_CONTEXT.md` Notes; DELIVERABLE_REGISTER.csv row DEL-084-05 Notes.)
- Turnover is the goal: the package only finishes when the documentation supports EPC acceptance and project turnover. (DELIVERABLE_REGISTER.csv row DEL-084-06 artifacts: turnover evidence.)

## Considerations

- The PKG-084 fuel gas skid sits inside a shared utility allocation between 03-25 and 04-25; documentation should make package boundaries and shared-utility interfaces unambiguous. (DBM-Comp_and_Liquids lines 37, 56, 452, 454.)
- Package documentation typically includes datasheets, cause-and-effect inputs, utility load summaries, relief/load data, field tie-in lists, operating and design envelopes, sparing philosophy, materials and coating basis, maintenance access, and shipped-loose item lists. The register should account for these categories to the extent each applies to a fuel gas skid. (DBM-Comp_and_Liquids line 617. ASSUMPTION: not every category necessarily applies; vendor scope governs.)
- Document control conventions (numbering, revision codes, status codes, transmittal practice) are governed by the project document control specification — exact specification reference is TBD pending `26020-Package_Requirements.docx` heading 37 access.

## Trade-offs

- Carrying source vendor document rows as artifacts (rather than minting separate deliverables) keeps the deliverable count tractable at the cost of internal indexing discipline inside DEL-084-05. The decomposition's choice is to bear the indexing cost here. (`_CONTEXT.md` Notes.)
- Aggressive early issue of vendor documents can reduce turnover risk but increases re-issue volume if engineering changes occur late. Trade-off resolution is vendor- and project-specific. (ASSUMPTION; not source-grounded.)
