# Procedure — DEL-084-05 Vendor Document Turnover Package (PKG-084)

This procedure covers production and management of the Vendor Document Turnover Package by the Package Vendor, through EPC Integrator review (DEL-084-06) and package turnover.

## Prerequisites

- PKG-084 vendor scope established via DEL-084-01 (EPC Scope of Work) and DEL-084-02 (EPC Package Datasheet). (DELIVERABLE_REGISTER.csv rows DEL-084-01, DEL-084-02.)
- Project document control specification available (numbering, revisions, status codes, transmittal conventions). TBD — `location TBD` (`26020-Package_Requirements.docx` heading 37 not locally text-accessible).
- Access to `26020-Package_Requirements.docx` heading 37 and Workbook Packages row 60 for package-specific document requirements. Currently `location TBD`.
- DBM-Comp_and_Liquids package deliverable categories (line 617) as drafting checklist.
- Declared upstream/downstream dependencies: none declared during PREPARATION (`_DEPENDENCIES.md`).

## Steps

1. **Compile the Vendor Document Register.** Enumerate every vendor document required for PKG-084 against `26020-Package_Requirements.docx` heading 37 (TBD), the DBM line 617 categories applicable to a fuel gas skid, and the vendor's own engineered scope (DEL-084-04). Capture for each row at minimum: document number, title, type, revision, status, due date, transmittal reference, acceptance state. (`_CONTEXT.md` Anticipated Artifacts; DBM line 617.)
2. **Confirm document control conventions.** Apply project document numbering, revision codes, and status codes per the project document control specification. (TBD — `location TBD`.)
3. **Produce and collect vendor document submittals.** Generate or receive each vendor document required by the register. Submittals SHALL trace back to a register row. (`_CONTEXT.md` Anticipated Artifacts.)
4. **Carry source-required vendor document rows as artifacts.** Where individual source-required vendor document rows exist (per source materials), file them as artifacts/evidence inside DEL-084-05 rather than minting separate deliverables. (`_CONTEXT.md` Notes; DELIVERABLE_REGISTER.csv row DEL-084-05 Notes.)
5. **Transmit submittals for EPC Integrator review.** Issue submittals through the project transmittal process; track review status and re-issue revisions under DEL-084-06's vendor document review log. (DELIVERABLE_REGISTER.csv row DEL-084-06.)
6. **Incorporate EPC review comments.** Re-issue affected vendor documents at the next controlled revision; update register status accordingly. (DELIVERABLE_REGISTER.csv row DEL-084-06.)
7. **Compile turnover records.** Assemble acceptance evidence, transmittal trails, and any handoff documentation required for project turnover. (`_CONTEXT.md` Anticipated Artifacts; DELIVERABLE_REGISTER.csv row DEL-084-06 artifacts.)
8. **Hand off to EPC Integrator for acceptance.** Acceptance occurs under DEL-084-06 against the EPC Scope of Work, Package Datasheet, and Construction Work Package. (DELIVERABLE_REGISTER.csv row DEL-084-06.)

## Verification

- Vendor Document Register row count and content reconcile to `26020-Package_Requirements.docx` heading 37 (TBD) and applicable DBM line 617 categories.
- Each register row has a submittal in the document set at the required revision and status.
- Source-required vendor document rows are present as artifacts inside the deliverable folder, not as standalone deliverables.
- EPC Integrator vendor document review log (DEL-084-06) shows all submittals through review.
- Turnover records present and complete; EPC package acceptance checklist (DEL-084-06) satisfied.

## Records

- Vendor Document Register (controlled, revisioned)
- All transmitted vendor document submittals (each at its accepted revision)
- Source-required vendor document artifacts (filed inside this deliverable)
- Transmittal records (issue/return/re-issue history)
- Vendor document review log (held under DEL-084-06)
- Package acceptance checklist and turnover evidence (held under DEL-084-06)
