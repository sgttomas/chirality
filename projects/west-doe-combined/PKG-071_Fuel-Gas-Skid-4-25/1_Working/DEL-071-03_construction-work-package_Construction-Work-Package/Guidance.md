# Guidance — DEL-071-03 Construction Work Package (Fuel Gas Skid 4-25)

## Purpose

This deliverable exists so the EPC Integrator has a single, source-anchored construction plan that converts the vendor-supplied Low Pressure Fuel Gas Skid (`26020-01-PT-23-001`, 4-25 West Doe Deepcut) into an installed, tied-in, inspected, and turned-over asset within the West Doe Deep Cut Facility. It complements DEL-071-01 (Scope of Work) and DEL-071-02 (Package Datasheet) by translating package facts into field execution. (Sources: `_CONTEXT.md`; `_Sources/26020-Package_Requirements.docx`, Basic Scope.)

## Principles

1. **Vendor delivers the skid; EPC installs and integrates it.** The source explicitly assigns shipping, installation, tie-in piping, and electrical tie-in to "By others" (i.e., EPC). The CWP must treat every "By others" item as in-scope work to be planned and tracked. (Source: `_Sources/26020-Package_Requirements.docx`, Scope Notes / Open Items.)
2. **Interface applicability is binary at the package boundary.** The Physical Interface Summary lists each interface as Yes or No. Construction effort is required wherever the source says Yes; absence at the boundary is a positive design statement, not an oversight — except where it conflicts with the Major Included Equipment list (see Conflict Table). (Source: `_Sources/26020-Package_Requirements.docx`, Physical Interface Summary.)
3. **Test before turnover.** Hydrotest (PIP-024), flushing/cleaning/drying (PIP-025), electrical FAT/SAT (ELE-029/ELE-030), F&G commissioning (TSF-003/TSF-004), and mechanical FAT (MEC-021/MEC-022) precede turnover. The CWP sequences these against the workface plan. (Source: `_Sources/26020-Package_Requirements.docx`, Vendor Engineering Deliverables.)
4. **One workface plan per package boundary.** The Installation and Tie-In Workface Plan must address every Physical Interface Summary "Yes" row so that turnover sign-off maps one-to-one with the source-stated interfaces. (Sources: `_CONTEXT.md` Anticipated Artifacts; `_Sources/26020-Package_Requirements.docx`, Physical Interface Summary.)
5. **As-built feedback is part of the CWP, not a follow-on.** Piping and instrument as-builts (PIP-028, INS-029) feed the facility-level as-built set and must be planned into the workface sequence. (Source: `_Sources/26020-Package_Requirements.docx`, Vendor Engineering Deliverables.)

## Considerations

- **Electric heater power conflict.** Major Included Equipment specifies "Heater to be controlled by SCR (600V)", which implies a substantial electrical power feed at the skid; the Physical Interface Summary marks "Electrical Power: No". Construction cannot start the electrical tie-in scope until this is resolved. (See Conflict Table.) (Source: `_Sources/26020-Package_Requirements.docx`, Major Included Equipment vs Physical Interface Summary.)
- **Heater capacity and final flow are TBD in source.** Until vendor MEC-014 calculation and MEC-003 datasheet pin them down, the workface plan should reserve flexibility for cable sizing, breaker selection, and foundation loading. (Source: `_Sources/26020-Package_Requirements.docx`, Scope Notes / Open Items.)
- **Interface file row reference.** The source refers to `26020-Packages_Interfaces.3.xlsx` column M and gives a row number (row 99) that does not match the package's workbook row (61). The interface file row should be confirmed before construction quantities are taken off. (ASSUMPTION: the row number reference may be a documentation error in the source — confirmation needed.) (Source: `_Sources/26020-Package_Requirements.docx`, Physical Interface Summary, Area/Exterior Lighting row.)
- **Drainage at the package.** Drain/Containment = Yes, while Grading/Site Drainage/Spill Containment = No. The CWP must treat package drains as point connections into the facility drainage system (designed elsewhere), not as new site grading scope. (Source: `_Sources/26020-Package_Requirements.docx`, Physical Interface Summary.)
- **F&G integration requires facility-level inputs.** TSF-003 mapping study output is a vendor deliverable but it must be reconciled with the facility F&G philosophy (TSF-002) before detector layout drawings (TSF-004) can be installed. (Source: `_Sources/26020-Package_Requirements.docx`, Vendor Engineering Deliverables — Fire and gas.)
- **Maintenance access.** Maintenance Access = Yes; the workface plan should not defer platform/ladder install to post-turnover, otherwise commissioning crews cannot reach instrumentation. (Source: `_Sources/26020-Package_Requirements.docx`, Physical Interface Summary.)

## Trade-offs

- **Pre-set vs post-set tie-in piping.** Setting the skid first simplifies craning but constrains tie-in routing; running tie-in spools first reduces field rework but risks interference with set. Vendor PIP-006/PIP-007 outputs and STR-002 GA should drive the call; this is a workface-plan decision, not a CWP requirement. (Source: `_Sources/26020-Package_Requirements.docx`, Vendor Engineering Deliverables.)
- **Hydrotest scope split.** Hydrotesting tie-in spools together with the skid may be more efficient but risks loading skid-side components beyond their design pressure. Workface plan should defer to vendor PIP-024 boundary definitions. (Source: `_Sources/26020-Package_Requirements.docx`, Vendor Engineering Deliverables.)
- **F&G hold for facility-philosophy alignment.** Holding F&G install until TSF-002 alignment is complete adds schedule risk; installing without alignment risks rework. Source does not state the philosophy alignment status — TBD. (Source: `_Sources/26020-Package_Requirements.docx`, Vendor Engineering Deliverables — Fire and gas.)

## Examples

- Source-stated by-others items that this CWP must own: shipping to site; installation; tie-in piping; electrical tie-in. (Source: `_Sources/26020-Package_Requirements.docx`, Scope Notes / Open Items.)
- Source-stated interface "Yes" rows that drive workface plan content: Process Piping; Utility Piping; Relief/Flare/Vent; Drain/Containment; Area/Exterior Lighting; Grounding/Bonding; I&C/Control Cabling; Fire & Gas/Safety Systems; Maintenance Access; Structural/Foundations/Supports. (Source: `_Sources/26020-Package_Requirements.docx`, Physical Interface Summary.)
