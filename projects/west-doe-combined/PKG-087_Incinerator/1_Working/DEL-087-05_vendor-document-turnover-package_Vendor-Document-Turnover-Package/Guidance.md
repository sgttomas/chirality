# Guidance — DEL-087-05 Vendor Document Turnover Package

## Purpose

This deliverable exists so the project receives a complete, auditable, and accepted set of vendor documentation for the Incinerator package (26020-Package_Requirements.docx package heading 40) — from engineering through manufacturing, FAT, shipping, installation, commissioning, and final turnover. It is the **documentary backbone** that supports the EPC Integrator's package acceptance (DEL-087-06), supports construction execution (DEL-087-03), and supports operations, maintenance, and regulatory reporting after handover.

Without this package the physical incinerator (DEL-087-04) cannot be safely or legally placed into service: pressure equipment registration of the upstream knock-out drum, burner-management-system functional safety records, emissions/permit basis documentation, and the Final Vendor Data Book are all required artifacts.

## Principles

1. **Index-first.** Establish PRQ-009 (Vendor Document Index) early and treat it as the single source of truth for what the vendor owes and the status of each item.
2. **Source-fidelity.** Document classes are fixed by the package source specification (26020-Package_Requirements.docx heading 40). The discipline-document enumeration in `Specification.md` is partly grounded in heading-40-specific source slices and partly in project-wide vendor-package convention; deltas vs. the heading-40 list (once parsed) must be reconciled and any extra/missing items routed through change control.
3. **Status discipline.** Every submittal carries an explicit status code (work-from / approved / not-approved / for-info) and a revision. Status codes drive whether downstream consumers (construction, commissioning, regulatory submission) may rely on the document.
4. **Provenance preserved.** Transmittals, revision history, and review markups are part of the turnover record; the Final Vendor Data Book is assembled from accepted final-revision documents.
5. **Separation of authoring vs acceptance.** This deliverable produces and routes documents (vendor authoring, EPC review). Final EPC acceptance authority lives in DEL-087-06.
6. **Functional safety is independently reviewed.** Burner Management System / SIF documentation receives independent functional-safety review in addition to ordinary discipline review.
7. **No agent self-certification.** No automated process certifies vendor documentation; humans (EPC Integrator reviewers and vendor responsible engineers) approve.

## Considerations

- **Shared 3-25/4-25 service.** The incinerator is a shared system handling spent-caustic and DSO off-gas from the 4-25 NGL mercaptan treating system and is physically located at 3-25 near the flare stacks (3-25_Comp_and_Liquids_DBM.md §"Incinerator Interface", lines 1568-1572). Service-split allocation is an open interface item (line 56, line 547). Reviewers should ensure vendor documentation does not foreclose the project's future ruling on the split — capacity, redundancy, and tie-in arrangements should be expressed in terms compatible with the eventual allocation.
- **Upstream KO drum.** A knock-out drum is included upstream of the incinerator to separate free liquids (3-25_Comp_and_Liquids_DBM.md line 1570). It is a pressure-retaining component and requires REG-022 jurisdictional registration; reviewers must confirm jurisdiction before vendor proceeds (see Conflict Table C-02).
- **Layout/spacing constraints.** Although vendor documentation does not itself author plot-plan layout, vendor GA and installation drawings (MEC-016, MEC-017) must support EPC verification of OGAOM Sec. 9.6.15 spacing (4-25_Deepcut_DBM.md §2.4, lines 276-300): 25 m to plant equipment, 80 m to public road / property line, 50 m to atmospheric condensate tanks, 25 m to fired heaters, etc. Reviewers should reject GA drawings that obstruct compliance verification.
- **Emissions basis.** Vendor supplies engineering inputs (combustion calculations, expected emissions per source/feed, stack height/diameter rationale) for PRO-024; the owner/regulator owns the permit. The DBM explicitly flags the final emissions section as "adequate for DBM scoping but not for permit-final emissions tables" (line 555). Vendor documentation must not be misrepresented as a permit-final basis.
- **Supplemental fuel gas.** The DBM (line 1572) carries supplemental fuel-gas rate and incinerator flow basis as TBD. Vendor documentation must reflect the as-RFQ'd values; reviewers should expect a "value pending owner confirmation" status on this point until resolved.
- **Flame-arrestor boundary.** Spent-caustic and DSO tanks have flame arrestors at their vent connections to the incinerator header (lines 402, 1561, 1564). Whether the arrestors are within the Incinerator vendor's package scope or within the tank vendor's scope is **TBD** — see Conflict Table C-03.
- **Open items from source.** "By others" delineation (typical for vendor packages — installation, tie-in piping, electrical connections, mounting/structural where applicable) must be clearly stated in vendor documentation so the EPC interface is unambiguous; the Tie-In List (PIP-004) is the key boundary artifact.
- **Spare parts (PRQ-015 SPIR).** Vendor RFQ governs commissioning vs operating spares scope. EPC Integrator should issue spares review well before shipping window. Pilot/igniter, refractory, burner tips, and thermocouples are typical incinerator critical spares (ASSUMPTION).

## Trade-offs

- **Early vs. accurate.** Pushing the vendor for early submittals improves construction planning and emissions-permit submission timing, but risks higher revision churn (especially around supplemental fuel-gas rate and emissions basis). Status-coding discipline mitigates this when followed.
- **Native files vs PDF only.** Native files (CAD, combustion calculation source, BMS logic source) preserve future modification capability; PDF only is faster to assemble but limits owner reuse. The source does not specify a position; assume both are required for engineering documents (ASSUMPTION).
- **Single VDB vs split mechanical/electrical/quality VDBs.** Project-wide convention enumerates both PRQ-016 (Final Supplier Documentation) and MEC-023 (Mechanical Final Documentation). For fired equipment with BMS, an electrical/controls volume should also be expected (ASSUMPTION pending heading-40 confirmation).
- **Combined emissions-test FAT vs site-only emissions test.** Some emissions can only be measured under representative feed; trade-off between exhaustive shop FAT and site emissions verification must be set in MEC-013/PRO-024 (ASSUMPTION pending RFQ).

## Examples

- A typical Vendor Document Index entry: `MEC-012 / Burner Data Sheet — Main Burner / Rev B / Status: Approved / Transmittal VTX-031 / 2026-10-04`.
- A typical Conflict Table entry would be raised when vendor-submitted supplemental fuel-gas rate (MEC-013) disagrees with the value used in ELE-002 Load List or PRO-011 Utility Summary — flag, reconcile against the as-RFQ'd basis.
