# Guidance — DEL-063-01 Scope of Work (PKG-063 Tanks, DSO (API 650))

## Purpose

This Scope of Work is the EPC Integrator's anchoring statement of *what the PKG-063 disulphide-oil (DSO) storage tank package is and how it integrates into the 04-25 Deepcut facility*. It is the upstream deliverable that the Package Datasheet (`DEL-063-02`), Construction Work Package (`DEL-063-03`), vendor-engineered equipment package (`DEL-063-04`), vendor document turnover (`DEL-063-05`), and EPC vendor-package review/acceptance (`DEL-063-06`) all consume (per `DELIVERABLE_REGISTER.csv` for `PKG-063`). Getting identity, function, boundary, responsibility, and interface set correct here prevents downstream rework when the package vendor receives the technical handoff and when the facility-integration disciplines design the tie-ins.

Source: `_CONTEXT.md`; `DELIVERABLE_REGISTER.csv`; package note "Mandatory Gate 5 EPC anchor deliverable defined by user instruction".

## Principles

1. **Vendor owns the package; EPC owns the integration.** Package engineering, design, vendor documentation, and equipment supply belong to the Package Vendor. Interfaces, tie-ins, constructability, procurement/construction coordination, and facility-level integration belong to the EPC Integrator. The by-others list in SOW-0212 (foundations, on-site mounting, E&I, platforms, staircase) is the operational expression of this split for `PKG-063`. Source: `PACKAGE_REGISTER.csv` ResponsibilityModel; `SCOPE_LEDGER.csv` SOW-0212.
2. **Source-anchored content; no invention.** Every non-trivial statement should cite Workbook Packages row 90, `26020-Package_Requirements.docx` package heading 18, the 04-25 Deepcut DBM (disulphide-oil disposition paragraph and DSO-disposal open issue), or another locally accessible source slice. Where a value is not in an accessible slice, mark `TBD` with `location TBD` rather than inferring it. Source: SKILL `four-documents` source-grounding rule.
3. **Process function is disposition, not regeneration.** The DSO tank is a disposition asset for a by-product of the NGL non-regenerative caustic treating system. The tank does not regenerate caustic or treat DSO; it stores recovered DSO for truck-out. Misframing this scope as part of caustic regeneration would pull in mistaken process-design content. Source: `DBM-Deepcut/4-25_Deepcut_DBM.md` disulphide-oil paragraph; `SCOPE_LEDGER.csv` SOW-0210.
4. **Pour-point maintenance is the design driver for thermal scope.** SOW-0211 ties the heater (vendor-designed, 32.2 °C / 90 °F minimum) and the insulation explicitly to keeping DSO above its pour point for truck-out and handling. This is the controlling thermal-design statement and should be reproduced literally; do not paraphrase away the pour-point rationale. Source: `SCOPE_LEDGER.csv` SOW-0211.
5. **Nine interface types form the integration surface.** The `INTERFACE_REGISTER.csv` rows for PKG-063 enumerate Process Piping; Relief / Flare / Vent; Drain / Containment; Grounding / Bonding; Area / Exterior Lighting; Cathodic Protection; I&C / Control Cabling; Grading / Site Drainage / Spill Containment; and Structural / Foundations / Supports. Omitting any of these in the SOW will create a hidden EPC scope item downstream. Note that Electrical Power and EHT are *not* listed as direct package interfaces in PKG-063's row set, even though the package contains a heater — the heater is vendor-designed within the package, and the on-site E&I tie-in falls under "by-others" per SOW-0212. Source: `INTERFACE_REGISTER.csv`; `SCOPE_LEDGER.csv` SOW-0212.

## Considerations

- **Equipment tag preservation.** SOW-0211 introduces the equipment as "Item No. DSO Storage Tank:" but the locally accessible source slice does not enumerate the tag number itself. Carry an explicit `TBD` for the tag number and resolve in the Package Datasheet (`DEL-063-02`) by extracting from `26020-Package_Requirements.docx` package heading 18 or the P&ID set. Do not assign a tag number speculatively.
- **DSO disposal open item.** The 04-25 DBM identifies "alternate mixing of recovered DSO into C5+ product" as a possible disposal path to be reviewed during detailed engineering. The current-scope basis is truck-out from the 400 bbl tank. Treat the alternate path as an open item, not as a designed alternate; if it advances, it materially changes tank piping, pumps, and metering scope. Source: `DBM-Deepcut/4-25_Deepcut_DBM.md` (DSO disposal open issue).
- **Heating system architecture.** SOW-0211 specifies "c/w heater at 32.2 °C (90 °F) minimum. Vendor to design heater." It does not state whether the heater is an internal coil (heat-medium-fed), an immersion electrical heater, or external EHT; nor does it identify the heat-medium source if any. This decision is the vendor's, but the EPC must surface the utility tie-in (heat medium, electrical) implication. Capture as Conflict ID `CONF-063-01-01`.
- **Minimum pour-point temperature is TBD.** SOW-0211 says "Minimum temperature TBD." Downstream insulation thickness, heater sizing, and winterization rely on a numeric minimum. Carry the TBD forward as an explicit open item rather than asserting an ambient design value.
- **Internal coating product is not stated.** SOW-0211 requires internal coating (floor, walls, roof) but does not specify the coating product. The 04-25 DBM cites "Devchem 253" for produced-water tanks; do not transfer that product into the DSO scope without source support — DSO is mercaptan-bearing and may impose different lining chemistry. Mark `TBD` with `location TBD`.
- **Sour-service classification.** DSO arises from sour-service NGL caustic treating and contains mercaptans; sour-service relief, drain, and venting requirements should apply at the package boundary even though the source slice does not classify the tank explicitly. Treat sour-service classification as an ASSUMPTION and surface it for human ruling.
- **Site spacing context.** The 04-25 DBM Site/Spacing tables (NFPA 30, API 2510, OGAOM Sec. 9.6.15) govern atmospheric-tank spacing to ignition sources, public roads, flares, and other tanks. These are facility-integration constraints carried by the EPC Integrator, not the Package Vendor, but the SOW should acknowledge they apply at siting.
- **Budgetary RFQ go-by is informational only.** `Bid Docs/_Budgetary/26020-01-PT-RFQ-19-001_Tanks_DSO_R0.docx` is a budgetary pricing/delivery go-by. Do not promote any value from it into a requirement without explicit human ruling. Source: `PACKAGE_REGISTER.csv` SourceRefRaw.

## Trade-offs

- **Specificity vs. source coverage.** The locally accessible source slices describe identity, function, equipment list, responsibility, by-others list, and interface set, plus the 400 bbl DSO disposition from the DBM. They do not give clause-level design conditions beyond design pressure (32 oz / 1.0 oz vacuum), capacity (400 bbl), and heater minimum (32.2 °C). SOW content should be specific where source supports it and explicitly `TBD` (with `location TBD`) elsewhere. Pushing more detail in compromises auditability.
- **EPC-authored vs. vendor-authored content.** This SOW is EPC-authored; technical design content (e.g., shell/floor thickness, foundation loads, vent sizing, internal coating product, heater control philosophy) belongs in the Package Datasheet (`DEL-063-02`) and the vendor's engineered package (`DEL-063-04`). Resist drift of vendor design content into this deliverable.
- **Interface enumeration vs. interface design.** Naming the nine applicable interfaces in this SOW satisfies the integration narrative requirement; interface *design* (e.g., vent header routing, drain containment sizing, cathodic-protection design current) belongs in the Package Datasheet and the discipline EPC deliverables.
- **Truck-out vs. alternate-disposal commitment.** Committing the SOW to truck-out only (per SOW-0211 current basis) keeps scope minimal and source-grounded. Expanding it to include alternate C5+ mixing would require an explicit human ruling on the DBM open issue and would pull in pump, metering, and product-routing scope.

## Examples

Source-grounded statement (good):
> "The package supplies one (1) atmospheric DSO storage tank — modified API 650, 400 bbl nominal, design pressure 32 oz / 1.0 oz vacuum, internally coated (floor, walls, roof), insulated and vendor-heated to 32.2 °C (90 °F) minimum to maintain DSO above its pour point for truck-out (SOW-0210; SOW-0211; `26020-Package_Requirements.docx` heading 18, Basic scope / Major included equipment; corroborated by `DBM-Deepcut/4-25_Deepcut_DBM.md` disulphide-oil paragraph)."

Insufficiently grounded statement (avoid):
> "The DSO tank is internally coated with Devchem 253 and has a pour-point design minimum of −10 °C." — there is no locally accessible source slice for either value; mark `TBD` with `location TBD`.
