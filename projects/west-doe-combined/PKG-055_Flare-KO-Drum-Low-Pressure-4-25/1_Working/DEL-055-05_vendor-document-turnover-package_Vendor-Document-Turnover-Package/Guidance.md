# Guidance — DEL-055-05 Vendor Document Turnover Package (PKG-055)

## Purpose

This guidance frames how the Vendor Document Turnover Package is to be assembled, interpreted, and reviewed for PKG-055 (Flare KO Drum (Low Pressure) 4-25 — one LP flare KO drum V-3900-1 and one transfer pump P-3900-1, shop-built as Module 390-1). It supports `OBJ-001`, `OBJ-004`, `OBJ-005`, `OBJ-006`, `OBJ-007`, `OBJ-008`, `OBJ-009`, `OBJ-010` (objectives are associated by package-grouping heuristic and remain ASSUMPTION pending human confirmation) by ensuring the EPC Integrator receives a complete, traceable vendor documentation set sufficient for facility integration, pressure-vessel regulatory readiness, and operations.

## Principles

1. **Source-driven document list.** The applicable document classes come from `_Sources/26020-Package_Requirements.docx` "Vendor Engineering Deliverables" (package heading 10 for PKG-055). This skill does not invent new document classes. Where the docx is not text-accessible at run time, the standard core/discipline ID set is mirrored from the sibling vendor-document-turnover deliverable (DEL-081-05) which previously walked the same template; rows so mirrored are explicitly labeled **ASSUMPTION** below and in `Specification.md`.
2. **Discipline filtering, not document invention.** The vendor and EPC reviewer apply the source's discipline tables to mark each line APPLICABLE / N/A with a brief rationale, rather than removing or re-inventing IDs.
3. **EPC Integrator as acceptor, not author.** Per `_CONTEXT.md` and the DELIVERABLE_REGISTER row, the Package Vendor authors; the EPC Integrator reviews and accepts via `DEL-055-06`. Acceptance is a human decision.
4. **Traceability over volume.** The Vendor Document Index (`PRQ-009`) is the canonical contents list; every document submitted must appear in it with current revision and status.
5. **Codes and standards stay sourced.** Where the accessible source set does not cite a specific standard clause (the case for most code citations on PKG-055 at this stage), the turnover set states the applicable standard and leaves clause-level claims to detailed-design documents.
6. **Pressure-vessel rigor.** Because the package contains an ASME-regulated pressure vessel (LP flare KO drum) in flare service, ITP hold/witness points, NDE records, hydrostatic test certificates, and ASME Data Reports are not optional — they are the spine of the turnover record.
7. **Shop-built module discipline.** The 390-1 LP Flare KO Drum Module is shop-built (DBM line 2783); the turnover record should include module-level FAT/integration evidence in addition to per-equipment records.

## Considerations

- **Mechanical discipline center.** The package is identified Mechanical (`_CONTEXT.md`). Mechanical equipment, pressure-vessel, and rotating-equipment document classes dominate. Electrical and I&C apply for the transfer-pump driver and the KO drum instrumentation. Civil applies for the vessel saddle, anchor bolts, and pump skid foundation.
- **Single-train equipment.** The package contains one LP KO drum (V-3900-1) and one LP KO drum transfer pump (P-3900-1) per the Deepcut DBM rows; the LP flare service is single-train. The vendor document set is correspondingly simpler than the HP analogue at PKG-081 (which has two KO drums and two pumps).
- **Flare-system context.** The LP KO drum receives PSV discharge from LP equipment including amine regeneration, TEG regeneration, VRU, and the reciprocating-compressor seal pot (DBM line 2029). The LP relief header is 508 mm / 20 in. The LP element piggy-backs on the common HP/cryo flare stack and includes an air blower for smokeless operation; the LP stack OD is itself TBD per DBM line 2031. Vendor documents must clearly identify nozzle sizes, ratings, and orientation against the LP header; flare-stack/blower design is outside this vendor's scope.
- **Interface basis.** Typical applicable interface types for a flare KO drum module include: Process Piping; Relief / Flare / Vent; Drain / Containment; Electrical Power; EHT; Grounding / Bonding; Area / Exterior Lighting; I&C / Control Cabling; Maintenance Access; Structural / Foundations / Supports. The specific interface line items per PKG-055 are TBD pending text extraction of the workbook row 57.
- **Cold-climate site.** Per DBM context (4-25 Deepcut plant), heat tracing (EHT), winterization, and electrical area-classification documentation are facility-level expectations that affect vendor documentation content even where the documents themselves are issued in standard ID classes. The LP KO drum boot/level service in particular is freezing-sensitive (ASSUMPTION).
- **Turnover gate.** Turnover records (`PRQ-016`, `MEC-023`, `QLT-020`, `QLT-021`, hydrostatic test certificates, ASME Data Reports) are the critical evidence for `DEL-055-06` acceptance. Plan FAT/hydrotest/release milestones backwards from the EPC Integrator's acceptance gate.

## Trade-offs

- **Breadth vs. signal.** A wide vendor document set is more defensible at regulatory and operational reviews, but increases review cost and submittal turnaround. Use the discipline applicability call to keep the set tight while preserving traceability.
- **Early submittal vs. as-built quality.** Releasing documents early gives the EPC Integrator time to coordinate facility-level integration but creates revisioning churn. The Vendor Document Control Procedure (`DOC-008`) should establish a small number of named milestones (e.g., preliminary, certified-for-construction, as-built) rather than continuous trickle.
- **Module-level vs. per-equipment documentation.** Because Module 390-1 is shop-built (one KO drum + one transfer pump on a single skid), documentation can be organized either by equipment tag or by module. Module-level organization simplifies shipping and turnover; per-tag organization simplifies long-term maintenance. Decide upfront and reflect in `DOC-008`.
- **Standalone vendor IOM vs. integrated turnover book.** A combined `PRQ-016` book is easier for operations to use long-term; per-document standalone files are easier for vendor revisioning. Decide upfront and reflect in `DOC-008`.

## Examples

- The source's standard `Vendor Engineering Deliverables` template is the same template instantiated for every package in the workbook; the PKG-081 vendor-document-turnover deliverable (HP Flare KO Drum, 3-25 plant) walked the same template and produced an analogous Datasheet/Specification/Guidance/Procedure set. PKG-055 instantiates the same shape with single-train LP-service discipline filtering rather than two-train HP-service filtering.
- DBM line 2029 explicitly enumerates the LP flare header service: "Low-pressure equipment, including amine regeneration, TEG regeneration, VRU, and reciprocating compressor seal pot, connects to LP flare. 508 mm (20 in) relief header and LP flare KO drum V-3900-1; LP KO drum pump P-3900-1 and truck-out provided; LP element piggy-backs on common HP/cryo flare stack." This validates the single-train equipment count and the LP-service-only header definition assumed in `Specification.md`.
