# Specification — DEL-049-06 EPC Vendor Package Review and Acceptance

## Scope

This deliverable specifies the EPC Integrator's review and acceptance activities for the Package Vendor's Sales Gas Booster Compressor package (PKG-049). It covers:

- Vendor document review and comment workflow
- Engineering/design verification against the EPC Scope of Work, the Package Datasheet (DEL-049-02), and the Construction Work Package (DEL-049-03)
- Factory/shop test and inspection witness/review evidence
- Package acceptance and turnover into facility integration

Out of scope (handled by other deliverables or parties): vendor-owned engineering/design/equipment production (DEL-049-04, DEL-049-05); shipping, pile installation, tie-in piping, electrical connections, mounting platform/stairs (EPC by-others per SOW-0172).

Source: SOW-0169 (ownership split); SOW-0172 (by-others scope).
