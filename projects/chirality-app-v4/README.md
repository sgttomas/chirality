# Chirality App v4

Working root for the conceptual undertaking that will produce the v4 product
basis: a fresh PRD and supporting core documents, developed with the owner
from the evidence of earlier Chirality generations.

**Position: Conceptual, in progress.** Nothing here is an accepted v4
requirement yet. The first completion boundary is an independently reviewed
seed set presented for the owner's acceptance (OD-12). The published
fallback product remains Chirality v3.0.1 until the owner decides otherwise
(OD-09).

## How to read this folder

Every file states its standing in its opening lines. The four kinds of
content are kept apart:

| Standing | What it means | Where |
|---|---|---|
| Source evidence | Pinned, preserved, or identified material from the reference project and foundation | [`foundation/thesis/`](foundation/thesis/) (preserved unchanged), [`reference/`](reference/), agent returns in the run record |
| Interpretation | The agents' accounts of what the sources show: exemplars, lessons, tensions | [`conceptual/`](conceptual/) working files, marked as interpretation |
| Proposed choice | Options and recommendations awaiting the owner's decision; later, the candidate PRD and core documents | [`conceptual/QUESTIONS.md`](conceptual/QUESTIONS.md); `docs/` once drafting begins |
| Accepted commitment | The owner's own directions and decisions, quoted | [`conceptual/DECISIONS.md`](conceptual/DECISIONS.md) |
