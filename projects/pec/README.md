# PEC — retained source

PEC is retired as an active product programme. There is no standing backlog,
provider-delivery commitment or required consumer adoption. Source and
compatibility interfaces are retained; retirement is not a product release.

The historical design is in [the PRD](docs/PRD.md). Its optionality, source
provenance and non-authoritative boundaries remain relevant when using
existing code. Development proceeds from deliverable files and available
repository tools without PEC. No replacement platform is part of this reset.

Use [LOOP_INIT](loop/LOOP_INIT.md) for explicitly requested maintenance.
Historical records are recoverable at `archive/pre-efficiency-cleanup-2026-10-09`.
