## Carry-forward notes (not part of this grant)

- **Larger counts.** If PEC ever needs counts above `2**53 - 1`, they would
  travel as strings; that is a separate decision.
- **Response-size budgets.** Each admitted field is bounded, but a record's
  field count is not. For agent consumers (D-PEC-90, direct query through tool
  calls) the limiting component is the agent's context, which total response
  size exhausts whether records are large or many. Response-size budgets
  (pagination, size caps) belong in the D-PEC-90 amendment (run-record node
  H6) and the API and orientation work, not in the ingest guard.
