# OD7-G3 ET-C — Additional Transport Deferral Candidate

**Status:** EXACT CANDIDATE — NOT ACCEPTED
**Candidate gate:** `OD7-G3-ET-C`
**Provisional PEC carrier:** `D-PEC-67`

## Exact candidate disposition

Defer any transport in addition to the currently authorized Unix-socket
architecture. No loopback TCP listener is authorized or implied.

This deferral expires before an accepted browser, remote-process, or
cross-sandbox consumer requirement cannot operate through the Unix-socket
architecture. At expiry, the Root owner must receive an exact governance and
product candidate before any additional listener is designed or implemented.

This disposition is independent of event-contract home. It does not select a
PEC-local socket, a shared-runtime client route, authentication, port, origin
policy, compatibility identity, or failure behavior.

- a non-binding notice to Root recording that PEC selected no new transport

No Root PRD, runtime contract, listener, security configuration, profile,
decomposition, ScopeOfWork, or implementation surface is authorized.
