# Core workflow authoring

The owner-approved App user-journey tranche adds `create-workflow` to the
bundled catalog and Root/product guidance. It is first in Core and is one of
seven central workflows. Agents load it before creating or revising a reusable
workflow, preserving the selected library's qualified identity.

Runtime retains its metadata parser, containment checks and native skill
discovery. Skills UI hiding affects App presentation, not background skill
availability. Existing sessions keep their supplied instruction history.

Follow-on: verify catalog resolution, new source packaging and selected-context
delivery with the coordinated App candidate. This is a routed source-change
record, not a new acceptance gate, supplier decision or publishing approval.
