# New Root software reverse-engineering workflow

Root is adding the reviewed `reverse-engineer-software` method to the bundled
catalog at source identity `chirality-root:bundled:workflow:reverse-engineer-software`.
It examines an existing product's capabilities, behaviour, relationships, and
constraints to support developing intent for a new implementation. Its package
includes an optional worked example. The workflow does not launch PRD work or
implementation by itself.
