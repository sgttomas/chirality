# Persistent Codex turn actor return

`CodexTurnSession` accepts only a trusted stdin/stdout/close transport, with optional bounded request/turn timeouts. No executable, environment, account or network authority enters its API. Host-owned process containment and exact supply checks remain prerequisites. Explicit caller model selection is mandatory, including turns; thread selection additionally requires caller continuity acknowledgement. Methods are initialize, sanitized account read without refresh, ephemeral workspace-write thread start, resume, turn start, wait, interrupt, one async event consumer and close.

JSONL parsing binds replies to outstanding IDs, rejects duplicate/unsolicited replies and unsupported server requests, and validates supported text/item/turn event shapes against current thread and turn. All unsupported approvals and item kinds fail closed, with structured RuntimeError and transport teardown. It never manufactures a terminal from interruption acknowledgement, process exit, protocol failure or timeout. Exact repeated terminals deduplicate; conflicting/late events poison the session; provider reuse of an old terminal ID rejects. Early notifications before method-response completion are handled. Terminal output comes only from validated message deltas/final text. Thread/account contents are not exposed beyond identifiers and account-presence/auth-required booleans.

Bounds: 8 outstanding requests; 1 active turn; 64 completed turns retained; 16MiB received per connection; 1MiB current parse buffer; 256KiB per message text; 1024 queued user events. Exceeding limits fails closed and asks the trusted transport to close. The supplied close callback owns actual process-group cleanup. The text adapter currently supports agentMessage/userMessage items only; reasoning/tool/status extensions remain unavailable until explicitly implemented and validated. This limited dialect is intentional and visible, not a successful-provider compatibility claim.

Validation: workspace typecheck PASS, 8 actual controlled-child tests PASS (409ms): handshake/account sanitation, explicit model/continuity, early notices, text and real terminal, interruption, concurrent turn refusal, identical/conflicting duplicate handling, late event rejection, reused turn ID refusal, unsupported approval/notification/malformed/flood failure, request error and real timeout. Every fixture transport kills/reaps its child. No actual account, hosted model turn or network was used.

Author: bounded ephemeral Agent2, OpenAI GPT-6; exact serving model ID unavailable; role not mechanically enforced/instruction-asserted. No delegation.
