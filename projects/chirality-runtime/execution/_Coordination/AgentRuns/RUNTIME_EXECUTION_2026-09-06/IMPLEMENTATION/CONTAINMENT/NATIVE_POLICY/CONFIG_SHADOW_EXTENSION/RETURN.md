# Same-turn configuration protection

Parent authorized automatic root/.codex action denial, including when missing, in the native policy. That explicit entry is now in expectedPermissions and semantic digest. This does not modify or create existing project configuration. Actual native same-turn denial remains a required conformance probe; pre-turn readback alone cannot prove it.

Protected literals may be future paths. The compiler requires absolute normalized spelling, finds their nearest existing ancestor with lstat, requires its realpath identical and directory-compatible, and rejects symlink aliases and dangling aliases. Existing in-root protected literals still work; equal/ancestor project denial and glob syntax remain unsupported and fail closed.

Compiler test passed for generated missing .codex denial, an explicit future nested literal and a future path through an aliased ancestor rejection. Daemon TypeScript build passed. No vendor/account/network execution occurred. Earlier statements that every nonexistent protected literal is unsupported are superseded by this extension; unsupported globs remain explicit incomplete G-PROT coverage.
