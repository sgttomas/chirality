# Approval store return

Completed bounded implementation, 20 focused tests PASS and workspace typecheck PASS. No delegation or real provider/account access. OpenAI GPT-6; exact serving model ID unavailable; role instruction-asserted and not mechanically enforced.

The runtime-owned store persists opaque attributed requests and immutable decisions through existing private fsync/CAS helpers. It binds root/account/epoch/policy/cwd/session/turn/worker generation and invokes the trusted caller live-state predicate on each operation. A pending request alone never authorizes ask-per-destination traffic. Explicit session acceptance is represented durably for the exact request; the store does not silently authorize other queued or unseen requests. Host/protocol and same-destination caveat are visible. Off defaults to denial; on requires unchanged attributed standing consent. Revoked/drifted consent invalidates old requests. No vendor prompt delivery, empirical provider grouping, or network wall enforcement is claimed.

Tests cover cross-principal/session/turn/generation rejection, stale live state, immutable conflicting concurrent decisions, idempotent same decisions, restart persistence, no automatic session grants, all three postures, consent drift, unsafe IDs/paths/symlinks, and strict networkApprovalContext projection. Public API routes must never permit clients to fabricate broker requests; only a trusted worker hook may call request(). The trusted caller is responsible for authenticating requestedBy/approvedBy; strings are attribution evidence, not authentication credentials.

Manager review corrected control storage: it must be outside the worker writable canonical root, owner-private/non-symlink and immutably root-bound, preventing approval records from being writable through project tools. Dedicated daemon control storage remains caller-owned and must stay outside every worker write grant. Prior evidence preserved in PRE_CONTROL_STORAGE_CORRECTION. External storage, worker-root storage rejection, cross-root reuse and storage aliases are tested.
