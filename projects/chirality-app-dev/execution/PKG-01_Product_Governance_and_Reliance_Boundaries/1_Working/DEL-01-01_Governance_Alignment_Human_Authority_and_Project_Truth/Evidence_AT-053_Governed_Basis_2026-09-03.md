## Rerun method

From any checkout at the basis (or a descendant, to detect drift):

```
cd "$(git rev-parse --show-toplevel)"
python3 projects/chirality-app-dev/execution/_Coordination/AgentRuns/APPDEV_V3_NODE_E_2026-09-03/build_at053_evidence.py --check
python3 projects/chirality-app-dev/execution/_Coordination/AgentRuns/APPDEV_V3_NODE_E_2026-09-03/verify_citations.py
```

`--check` regenerates both files in memory and exits non-zero if they differ from the committed bytes; `verify_citations.py` recomputes every SHA-256 in the JSON companion and writes `VERIFY_CITATIONS_RESULT.json` beside itself. Environment and exit statuses for the recorded run are in the run record's `CHECKS.json`. No disposable or quarantine state is created by either script.
