# Workflow duplicate retirement

Owner-authorized Root tranche `ROOT-WORKFLOW-DUPLICATE-RETIREMENT-20260926` retires six bundled workflow packages that duplicated canonical skills under D-GOV-42: `deliverable-consistency`, `preparation`, `proposal-format`, `researcher`, `software-code-review` and `software-defect-diagnosis`. The same-named skills under `.agents/skills/` remain and already ship in the App's bundled skill set. Before retirement, execution-critical details that existed only in the workflow copies were moved into the skills: the exact `_STATUS.md` form and scaffold tool operations for `preparation`, the research-packet command and return fields for `researcher`, write limits for `software-defect-diagnosis` and `deliverable-consistency`, and blocking labels for `software-code-review` findings.

Because the App hides skill browsing in v3.0.0, these six methods no longer appear in the Workflows panel's specialist groups. Codex background skill use, parent workflows that select the skills (`project-setup`, `scope-change`, `research-orchestration`) and chat requests are unaffected. The legacy-method ledger still resolves an unqualified legacy selection of each name to its skill, and `workflows/README.md` records each package's last revision for historical replay. `drawing-titleblock-page` is unchanged. This loop decides its own adoption; this source tranche grants no release.
