# D-APP-26 Ruling - Document Editor Build & Content-Write Contract

**Status:** RULED
**Date:** 2026-06-19
**Decision ID:** D-APP-26

SELECT: D-APP-26 **Option C — defer the editor tranche**. The editable document screen is
**not built now**; the shipped read-only viewer (`DocumentView` + the GET-only
`/api/working-root/deliverable/content`) remains the document surface. **No content-WRITE path
is authorized** — the content endpoint stays GET-only (D-APP-20 Option B is unchanged). The
CodeMirror markdown-source editor (D-APP-21) and its write contract are revisited when in-app
authoring is a concrete need or with the secondary phase.

The D-APP-21 constraints carry forward unchanged for the future tranche: when later built, the
editor is a CodeMirror 6 markdown-source editor, an inert read-only buffer until a content-write
ruling, and never performs governance-state transitions (`CHECKING`/`ISSUED` stays on the
existing `status/transition` route with `actor=HUMAN` + `approvalSha`).

This does NOT authorize any content-write endpoint, any editor dependency, or any in-app
document editing now.
