# D-APP-24 Ruling - Type-2 Task-Agent Interaction in Direct Chat

**Status:** RULED
**Date:** 2026-06-19
**Decision ID:** D-APP-24

SELECT: D-APP-24 **Option C now, with Option B as the staged follow-on**. The first
direct-chat (`/chat`) surface **restricts the persona picker to Type-0/Type-1**; Type-2 task
agents are excluded from direct chat and run only via the orchestrated/INIT path. The governed
**INIT-TASK brief form** for Type-2 (Option B) is the planned follow-on once that contract is
surfaced in the UI. Free chat with Type-2 (Option A) is **not** approved.

Constraints: the direct-chat screen must not weaken `subagent-governance` preflight (a future
brief satisfies, not replaces, the governed contract); mode is selected independently per the
§3.3 spec and passed to `PersonaComposer.buildSystemPrompt`; `npm run typecheck` +
persona-resolution / picker tests green.

This does NOT approve free-form Type-2 prompting or any relaxation of subagent governance.
