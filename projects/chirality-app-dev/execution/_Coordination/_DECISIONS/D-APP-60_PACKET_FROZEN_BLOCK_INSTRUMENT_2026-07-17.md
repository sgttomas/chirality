## S3 — Receipt convention for delegation exercises

Convention (validator-proven wording): the exercising receipt's
`Gate-Outcome` names the exercised judgment; `Pointers` names the rationale
artifact. Rationale artifacts live in existing homes only (F-APP-5):
deliverable-scoped exercises → that deliverable's `_run_records/**`;
cross-cutting exercises → the tranche's AgentRuns record. The rationale
artifact records **rejections alongside exercises**, and terminus slates

limit) — so the exercise/rejection ratio is derivable from pointed-to
artifacts without adding receipt records the D-APP-57 contract forbids. A
long run of exercise-only receipts with empty slates is itself a signal for
an owner look.
