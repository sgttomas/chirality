(`plans/PLAN_2026-06-16_runtime_stabilization.md`, tranches STAB-00 through

active queue.

## Boundaries

This ruling accepts the *program structure and tranche selection* only. It does **not**
pre-approve the human-gated rulings inside the program. The following remain pending in
`_DECISIONS/_REGISTER.md` and must be ruled before their dependent work implements:

- `D-APP-12` — default-provider cutover from the current default to the SDK-backed
  Anthropic path (`agentSdk`). The `agentSdk` provider remains **opt-in**; this ruling
  does not cut the default over.
- `D-APP-13` — exposure of bounded mutating Chirality MCP tools (`status_transition`,
  `deps_write`).

This ruling does **not** approve:

- concrete non-Anthropic provider implementation or provider routing;
- provider-network expansion beyond current approved policy;
- Pi adapter, fork, package import, Node 22 sidecar, runtime-floor migration, or spike;
- remote MCP servers, plugins, remote execution, or marketplace work;
- write/edit/bash/tool-execution exposure beyond what landed runtime and prior rulings
  already permit;
- Windows/Linux packaging;
- release-readiness, lifecycle issuance, professional approval, certification, sealing,
  authentication, or code-compliance claims.
