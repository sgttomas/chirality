# D-APP-39 Ruling - Autonomous Development Queue Released

**Status:** RULED
**Date:** 2026-06-20
**Decision ID:** D-APP-39
**Ruling basis:** owner directive, 2026-06-20: autonomy scope "Everything except hard fences"; commit
authority "Commit + push autonomously."

## Ruling

Release an autonomous development queue governed by
`plans/PLAN_2026-06-20_autonomous_development_queue.md`. The queue pulls the highest-priority eligible
roadmap item whose prerequisites are met, executes it, validates it, and **commits and pushes** the
validated tranche autonomously — repeating until only blocked or fenced items remain.

**Execution scope:** all roadmap work EXCEPT the hard fences below.

**Commit authority:** autonomous commit + push of validated tranches, under the shared-repo staging
discipline.

## Hard Fences (always human-gated; never autonomous)

1. Provider/network expansion beyond the Anthropic path.
2. Release/distribution posture: signing, notarization, publication, external distribution, or any
   release-readiness / professional / certification / sealing / authentication / code-compliance claim.
3. R7 domain-engine implementation; PKG-10 stays future-boundary/doc-only.
4. Any `CHECKING -> ISSUED` deliverable issuance.

## Standing Governance Gate (unchanged)

The agent does not self-rule. A genuinely new decision is raised as a `PROPOSAL` packet; that item is
marked `BLOCKED` and the queue continues with other eligible items. Humans remain the only ruling
authority (`docs/CONTRACT.md` K-AUTH; decision register).

## Required Guardrails

- Per-tranche validation must pass before commit (typecheck + tests + build/premerge/render bar for
  runtime/UI; `git diff --check` + reference checks + D-APP-38 reconciliation for governance/docs).
- Recompute ground truth; do not trust recorded metadata.
- Stage only `projects/chirality-app-dev/`; abort the commit if any path outside it is staged; never
  commit `projects/chirality-piping/**` or repo-root `tools/**`.
- Apply the CONTRACT K-ENGINE-6 strategic lens.
- Per-tranche CHANGE-agent closeout; commit messages end with the Co-Authored-By trailer; push.

## Stop Conditions

A hard fence; a new decision; an unrepairable validation failure; an out-of-`app-dev` staging stray; an
empty eligible queue. On stop, surface state and the decision/blocker queue; do not invent work or
revive completed plans.

## Scope Boundaries

- Does not grant ruling authority (the governance-decision gate stands).
- Does not lift any hard fence.
- Arming the queue does not launch an unsupervised run; the run begins when the owner launches an agent
  session via the init prompt.
