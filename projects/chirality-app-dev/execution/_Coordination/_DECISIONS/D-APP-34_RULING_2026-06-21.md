# D-APP-34 Ruling - Issuance Gate Model After INSP-03

**Status:** RULED
**Date:** 2026-06-21
**Decision ID:** D-APP-34
**Ruling basis:** owner chat directive, 2026-06-21: "I approve your recommendations as my rulings for the set of decision packets presented to me."

## Ruling

Select **Option B - Modify With Evidence Profiles**.

The project keeps `CHECKING`, `ISSUED`, human actor evidence, and approval SHA binding, but future
`CHECKING -> ISSUED` attempts must cite an issue-readiness profile and evidence package.

Approved profiles:

- Runtime/source.
- UI/product.
- Governance/control.
- Validation/release.
- Future-boundary/doc-only.

## Scope

- This ruling modifies the future issue-readiness process model.
- It preserves non-delegable human approval and SHA binding.
- It permits future governance/template work to define the evidence-profile package.
- It does not issue any deliverable.
- It does not approve release readiness, publication, certification, sealing, authentication,
  code-compliance acceptance, professional approval, provider expansion, or domain-engine activation.

## Follow-Up

Future issue attempts must select the applicable profile, cite current evidence, and use a fresh human
approval SHA bound to the then-current content.
