# D-APP-30 Ruling - In-Place Launch UX (loop-first matrix cell click)

**Status:** RULED
**Date:** 2026-06-19
**Decision ID:** D-APP-30

SELECT: D-APP-30 **Option B — guard mid-turn**. A Type-0/Type-1 matrix-cell click on the
loop-first portal swaps `?agent=` on the mounted loop **immediately when idle**; when a turn is
streaming the switch is **guarded** (blocked/confirmed) by reusing the shipped Tranche-5c
`streaming` / `useHarnessStreaming` flag — the same precedent that disables the session-list
"Open" button mid-turn — so an in-flight turn is never clobbered. A brief loop focus/transition
signals the boot.

Constraints (carried from the packet): preserve in-flight-turn survival — `ChatPanel` is never
unmounted by a cell click, and the guard reuses the shared `streaming` flag rather than a new
mechanism; no engine / public UIEvent contract / permission-plane change (launch-interaction
only); `npm run typecheck` + matrix / loop-first / chat-panel tests green.

This unblocks loop-first pivot tranche 28c. It does NOT approve immediate mid-turn persona swaps
(Option A) or a fresh session per cell click (Option C).
