# D-APP-21 Ruling - Document Editor Technology

**Status:** RULED
**Date:** 2026-06-19
**Decision ID:** D-APP-21

SELECT: D-APP-21 **Option C now, with Option A as the chosen technology when an editor is
built**. Phase 4 ships the **read-only viewer only** — no editor dependency is added now. When
in-app document editing is later taken up, it will be a **markdown-source editor (CodeMirror
6)**, chosen because deliverables are governed markdown source where round-trip fidelity and
clean git diffs outweigh WYSIWYG convenience, and the dependency is lighter than ProseMirror.

Constraints carried to the future editor tranche: no write path until content write is
authorized (the editor is an inert read-only buffer until then); document edits never perform
governance-state transitions (`CHECKING`/`ISSUED` stays gated through the existing
`status/transition` route with `actor=HUMAN` + `approvalSha`); bound the new dependency and
record its bundle-size impact against the Electron build gates.

This does NOT approve WYSIWYG/ProseMirror, an editor in Phase 4, or any document write
capability ahead of a content-write ruling.
