# D-APP-40 Ruling - G5 Runtime Naming and Taxonomy Reconciliation

**Status:** RULED
**Date:** 2026-06-21
**Decision ID:** D-APP-40
**Ruling basis:** owner directive, 2026-06-21: proceed according to the long-term consistency
recommendation, with no preference for backward compatibility and willingness to do necessary cleanup.

## Ruling

SELECT: D-APP-40 **Option B - add a dedicated interruption terminal taxonomy**, while retaining the
current method names, public event passthrough, and child-run record vocabulary.

Canonical runtime taxonomy:

- `TurnEngine.runTurn(request)` remains the product lifecycle method outside HTTP.
- `AgentEnginePort.startTurn(input)` remains the adapter stream method.
- `harness:event` remains a public `UIEvent` name for redacted provider-neutral `HarnessEvent`
  passthrough. Provider/SDK event names remain adapter metadata.
- Add `turn.interrupted` as the terminal event for explicit user interruption.
- Reserve `turn.cancelled` for non-user cancellation such as client disconnect or system cancellation.
- `ChildRunRecord.childRunId` is the canonical child-run record/key.
- Subagent lifecycle events remain `subagent.started`, `subagent.progress`, `subagent.completed`, and
  `subagent.failed`.
- Denied subagent attempts only require a denied child-run record after the runtime reaches the
  child-run record layer. Earlier denials may remain permission/hook evidence only.

## Required Follow-Through

- Update runtime event schemas, mappings, replay/UI handling, docs, local-kit materials, and tests so
  explicit user interruption terminates as `turn.interrupted`.
- Keep current source-aligned method names and child-run names; do not revert to older local-kit names.
- Reconcile `docs/SPEC.md`, `docs/TYPES.md` if needed, DEL-03 local kits, DEL-08 local kits, and
  runtime evidence.
- If authority documents are edited, run the D-APP-38 authority-corpus `status`, `bump`, and `apply`
  flow before closeout.
