## Ruled selection

The owner authorizes the bounded Pi/oMLX second-engine tranche described by SCA-APP-002:

- upgrade the desktop prerequisite to Electron `43.1.1` with its embedded Node `24.18.0`, electron-builder `26.15.3`, and project Node floor `>=22.19.0` before Pi integration;
- pin `@earendil-works/pi-coding-agent` `0.80.10` and run it in-process as an opt-in second adapter;
- permit oMLX only as an authenticated OpenAI-compatible endpoint at `127.0.0.1`, defaulting to `http://127.0.0.1:8000/v1`, with exact model IDs discovered from `/v1/models`;
- make the runtime engine boundary, session attribution, tool bridge, event translation, preflight, and per-turn routing provider-neutral;
- keep Claude Agent SDK / Anthropic as the key-aware default and supervisor;
- deliver the first Pi milestone only as a governed Agent 2 child with one declared Chirality-owned read-only tool;
- preserve Chirality ownership of sessions, permissions, tools, managed delegation, audit evidence, canonical events, and UI transport;
- require fail-closed conformance, credential, network, redaction, packaging, interruption, persistence, and recovery evidence.

## Exact prospective supersession

D-APP-01, D-APP-02, D-APP-03, and SCA-APP-001 remain immutable historical records. Effective prospectively from this ruling, their Pi-reference-only and no-concrete-non-Anthropic-implementation prohibitions are superseded **only** for the bounded selections above.

All other Pi/provider scope remains governed by the historical prohibitions or requires a fresh owner-ruling path.

## Explicit exclusions

This ruling does not authorize:

- a Pi fork or sidecar;
- Pi built-in tools, native subagents, extensions, skills, prompts, settings, credentials, or ambient `.pi`, `~/.pi`, or `.agents` discovery;
- remote or non-loopback providers, oMLX redirects, embedded URL credentials, remote MCP, or broader network access;
- automatic fallback between engines;
- direct Pi supervisor sessions;
- Pi write, shell, or network tools;
- graphical engine/model selection;
- release, publication, signing, notarization, issuance, lifecycle advancement, professional approval, or reliance claims.
