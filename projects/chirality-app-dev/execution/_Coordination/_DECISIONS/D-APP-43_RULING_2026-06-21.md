**Status:** RULED
**Date:** 2026-06-21

## Ruling

SELECT:

- **1B - interrupted tool results are non-success outcomes.** Tool results with `interrupted: true`
  are failed/interrupted outcomes for Chirality evidence and replay. Deterministic adapter-level proof
  is sufficient for ADQ-11 default validation; a live provider process-cancellation fixture is not
  required for this closure.
- **2B - adapter lifecycle mapping is the accepted PreCompact/Stop closure surface.**
  PreCompact/Stop closure is satisfied by canonical adapter-message/status/result lifecycle mapping:
  `context.compaction.started`, `context.compacted`, `context.compaction.failed`, `turn.completed`,
  `turn.failed`, and `turn.interrupted`. No synthetic SDK hook callback layer is required.
- **3B - strict canonical tool/workspace behavior.** Missing dependency-register state is explicit and
  non-inferential; exact-edit preconditions deny stale or unverifiable edits; Chirality-owned
  controlled writes use same-directory atomic rename where the controlled writer owns the mutation.

## Required Follow-Through

- Classify SDK tool results with `interrupted: true` as `tool.failed` while preserving safe stdout/stderr
  metadata and avoiding raw output persistence in event data.
- Add focused deterministic tests for interrupted Bash results and adapter lifecycle mapping for
  compaction and terminal outcomes.
- Update ADQ-11 evidence, active PKG-06 assessments, memory, dependency/source-state records, and the
  autonomous queue so the earlier blocked/deferred state is retired.
