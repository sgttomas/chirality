# D-APP-36 Ruling - AMD-01 UI Render-Test Acceptance Bar

**Status:** RULED
**Date:** 2026-06-21
**Decision ID:** D-APP-36
**Ruling basis:** owner chat directive, 2026-06-21: "I approve your recommendations as my rulings for the set of decision packets presented to me."

## Ruling

Select **Option B - Component/render tests required**.

UI/product deliverables require component-level render tests for user-facing controls, state, and
disabled/active behavior. Browser screenshots or browser-level checks are required only where layout,
viewport, visual overlap, or interaction risk is high.

## Scope

- This ruling defines the UI/product evidence bar for future issue-readiness work.
- Logic/API tests remain useful but are not sufficient by themselves for UI/product issue readiness.
- Browser E2E is not required for every UI/product deliverable.
- This ruling does not issue any deliverable or approve release readiness.

## Follow-Up

Apply this evidence bar when reconciling PKG-02 and UI-facing PKG-08 deliverables.
