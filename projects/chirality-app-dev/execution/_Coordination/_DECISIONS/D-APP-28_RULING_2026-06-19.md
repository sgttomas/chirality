# D-APP-28 Ruling - Full Loop-First Pivot

**Status:** RULED
**Date:** 2026-06-19
**Decision ID:** D-APP-28

SELECT: D-APP-28 **Option B — the full loop-first pivot**. The live loop becomes the **primary
surface app-wide**: the route surfaces (portal `/`, `/workbench`, `/pipeline`, file tree) are
demoted to **sidebar-reachable tertiary forms** rather than primary routes; the multi-view
sidebar moves to the **right across the app** (not only `/chat`); matrix-cell launches **boot a
session in-place** rather than `router.push`-ing to a route-as-main. This reaches the DESIGN
§3.1 target IA and **supersedes the D-APP-23 hybrid (Option C)** as the end-state; it also closes
the §5.2 transitional sidebar-left placement (sidebar is now right app-wide).

Constraints (carried from the packet): keep in-flight turns alive across the relayout (chat stays
mounted, as it already does on sidebar collapse); preserve the public UIEvent contract and the
permission plane **unchanged** — this is a routing/layout change, not an engine change; every
tertiary screen (portal / workbench / pipeline / file tree) stays reachable via the sidebar —
**nothing is deleted**; `npm run typecheck` + layout-geometry / route tests green and `next build`
prerenders the affected routes. Because this is the largest remaining rework
(`AppShell` / `ShellFrame` / routing / matrix), it is expected to land as **bounded, reviewed
tranches**, each typecheck- + test-green, rather than a single big-bang commit.

This does NOT approve deleting any route or tertiary screen, nor any engine / public-contract /
permission-plane change.
