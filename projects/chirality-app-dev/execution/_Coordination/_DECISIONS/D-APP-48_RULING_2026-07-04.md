## Ruling

**Option A - intra-repo SHA-pinned pull mechanism.**

`@chirality/harness-contract` remains `private: true`. The consumable mechanism
is a governed pull contract that pins repository, commit SHA, package path,
package name, Flow-A contract version, package export manifest, dependency-free
lint command, and provenance/checksum evidence. No registry publication or
external distribution is authorized.

## Scope not granted

This ruling does not authorize private/public package publication, F2 crossing,
F3 opening, live binding, piping source dependency installation, lifecycle
transition, or release/professional/certification claims.
