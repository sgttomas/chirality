# D-APP-38 Ruling - Reference-Integrity Model (Hybrid: Tool + Versioned Snapshots)

**Status:** RULED
**Date:** 2026-06-20
**Decision ID:** D-APP-38
**Ruling basis:** owner chat directive, 2026-06-20: "Option D: hybrid (e.g., A's tool feeding B's
snapshots). Changes are allowed, it just triggers a version change."

## Ruling

Select **Option D - Hybrid**: an automated reconciliation tool (Option A) feeds versioned authority-doc
corpus snapshots (Option B).

- A single versioned **corpus snapshot** records the canonical `sha256` of each authority-doc reference
  at a given corpus version.
- The **reconciliation tool** recomputes the authority-doc hashes, detects drift against the current
  snapshot, and reconciles deliverable `_REFERENCES.md` records to the current corpus version.
- **Authority-doc edits are allowed.** A content change does not break the model; it simply **triggers a
  corpus version bump** (the tool mints a new snapshot version with the new hashes). Deliverables remain
  bound to the corpus version they were reconciled against (encoded in their per-deliverable
  `ExpectedSHA256`), so drift remains visible until a deliverable is re-reconciled.

## Scope

- Authorizes building the reconciliation tool and the corpus-snapshot store under
  `execution/_Reconciliation/References/`.
- Authorizes a one-time reconciliation establishing corpus `v1` and refreshing all stale authority-doc
  references across the deliverable set to corpus `v1` (this executes the D-APP-35 PRD refresh as a
  special case under this model; D-APP-35 remains RULED and is subsumed).
- Authorizes recording the model in the issue-readiness / validation governance surfaces.
- Does **not** authorize editing the authority documents themselves as part of this reconciliation.
- Does **not** authorize any `CHECKING -> ISSUED` transition, provider expansion, release/distribution
  posture, or domain-engine work.

## Validation Requirement

- Corpus `v1` snapshot recorded with the seven authority-doc references and their current `sha256`.
- After reconciliation: no authority-doc reference row remains `HASH_MISMATCH`; all bind to corpus `v1`.
- The tool is idempotent: a second `status` run reports no drift; a second `apply` is a no-op diff.
- No runtime/source/package change; `git diff --check` clean.
