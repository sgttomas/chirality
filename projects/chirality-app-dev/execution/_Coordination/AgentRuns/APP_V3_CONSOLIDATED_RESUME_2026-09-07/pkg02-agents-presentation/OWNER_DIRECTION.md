# Owner direction — minimal Agents presentation

Owner-authorized UI edit: simplify the Agents projection to only the information necessary to understand the agent tree. Show a known agent type (`Agent 0`, `Agent 1`, or `Agent 2`), recorded role/persona, and a human-readable parent/tree relationship. Do not infer an unknown type or role and do not expose raw parent/session IDs as fallback labels.

Remove card metadata dumps: engine/model/provider attribution, currency, source/session identifiers, observed time, artifact/approval references, runtime `status unknown`, and verbose technical diagnostics. Simplify toolbar and detached disclosures to plain necessary relationship-unavailable language. Preserve truthful hierarchy placement, refresh/error access, disabled selection, selected state and recorded data internally. Do not build a details panel or change Runtime/contracts/permissions. Inspect other surfaces only; no broad redesign.
