`N1 -> G1 manager evidence check -> N2 -> G2 manager verifier check -> N3`

- G1 fails closed on source/package basis drift, a partial required
  observation, isolated-state failure, provider-backed skip, secret finding,
  cleanup residue, tracked product change, or boundary breach.
- G2 rejects a verifier that repairs N1, relies on unstated operator memory,
  or promotes unrecorded attribution/behavior.
- No node is concurrent with another node because N2 consumes N1's immutable
  evidence and all nodes share the run package.
