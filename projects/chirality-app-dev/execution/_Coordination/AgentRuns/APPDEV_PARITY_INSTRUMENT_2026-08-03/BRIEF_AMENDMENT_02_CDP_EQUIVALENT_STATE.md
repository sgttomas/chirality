`HELP_HUMAN` parent directed assessment of a standard Chromium remote-debugging
endpoint on the same packaged Electron application. This is acceptable only
when it inspects the native packaged renderer and does not substitute a dev
server, source-level component harness, fixture pass-through, or API-only

accepts the ordinary process switch
`--remote-debugging-port=<fresh-loopback-port>`. The same packaged executable
can therefore expose its packaged renderer's CDP endpoint for exact DOM,
accessibility-tree, route/state, and screenshot evidence while macOS remains
locked.
