# Sealed Brief — A2 UI and Packaging Reviewer

Role: ephemeral Agent 2 generalist; no delegation.

Objective: independently analyze the frozen D-APP-87 basis for the UI and
packaging lanes. Compare (A) lightly skinned one codebase, (B) shared core with
target-specific shells, and (C) at least one evidence-grounded third variant.
Do not select architecture.

Required review:

- map shared versus target-specific Woven Dialogue, typed-agent,
  structured-information, workflow, and decision-gate surfaces;
- define candidate skin/configuration and resource boundaries;
- identify accessibility and D-APP-36 evidence consequences;
- compare standalone/domain packaging artifact identity, configuration,
  resources, and unsigned local evidence;
- identify exact existing deliverables likely to require amendment versus
  cross-reference/no change;
- expose assumptions, coupling, reversibility, and evidence needed to eliminate
  an option.

Inputs: `ACTIVATION.md`, `BASIS_MANIFEST.csv`, `BASIS_INVENTORY.md`, and the
referenced repository files.

Write only:
`reviews/A2_UI_PACKAGING_RETURN.md` under this run root.

Return contract: findings, variant comparison, candidate deliverable mapping,
risks, gaps, and a verdict on whether the basis is sufficient for an owner
proposal. No product/source/authority decision and no foreign write.
