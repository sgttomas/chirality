## Sequencing judgment and actionable options

The plan ends with T2 and T3 able to run in parallel after T1 (04_IMPLEMENTATION_PLAN.md:202–211). The live T5 and account items explicitly split UI work from later right-view mounting. These are concrete evidence that not every visual improvement needs the deepest runtime integration first. Shared-file writes must nevertheless serialize against the active T3 freeze.

The existing containment, descriptor identity, native capability and CSP work is necessary for accepted local file behavior. This assessment does not establish that those security checks were needless or quantify elapsed effort. The avoidable effort is maintaining/proving redundant legacy composition and repeatedly repairing geometry before a design-fidelity checkpoint catches that the product shape is wrong. This conclusion is about source/UI evidence, not motive.

Recommended course correction, for the parent to route within existing instruments:
1. Finish current frozen verification without widening the concurrent source fence; report T3 as partial and design-misaligned in the specified respects.
2. Set the next presentation slice against actual mock light/dark images: single wordmark in navigator, white/lightest centre, one message box plus context line, one right control row, single Files location, adopted pane bounds. Resolve D120's exact omitted presentation seam separately from its no-folder capability question. Preserve current controls/state ownership while moving their placement.
3. Remove duplicated legacy region composition in the same coherent integration checkpoint. Retain explicit residuals for no-folder runtime, native PDF, T4 weaving, workflow live events and real account integration. Do not fake these to make the screenshot resemble the mock.
4. Advance 32px strip and other already split UI slices under their actual gates. Use design-fidelity comparisons at 1440 and960 both themes plus document/expand/replay states; keep functional/accessibility/security proof as separate acceptance dimensions. A screenshot matrix should show progress toward the target, not merely that inherited controls do not overlap.

Alternative: explicitly schedule a dedicated T2 composition milestone immediately after current T3 acceptance, retaining known T3 visual residuals until that integration. This is slower in visible results but lawful if the residuals are stated and assigned; it should not be represented as already matching the design. No owner disposition is made here.
