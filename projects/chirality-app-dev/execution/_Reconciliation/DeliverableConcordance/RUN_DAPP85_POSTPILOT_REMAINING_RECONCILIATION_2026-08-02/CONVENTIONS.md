# Conventions and Calibration Result

The run applies D-APP-85 packet §5 verbatim in effect:

1. One top-level bullet is one block; its continuations and nested annotations travel with it.
2. Every conjunct is inventoried independently; removal requires evidence for every conjunct or exact narrower replacement bytes.
3. Allowed recommendations are `EXACT_REMOVE_CANDIDATE`, `EXACT_RESTATE_CANDIDATE`, `NO_CHANGE`, and `ESCALATE_AUTHORITY_OR_EVIDENCE`.
4. Historical returns are leads; current implementation and current verification are required.
5. Tests prove only covered behavior.
6. A completed implementation tranche does not itself discharge a claim.
7. Unrelated sibling residuals are byte-preserved; changed input stops disposition.
8. Discovery changes no lifecycle, checking SHA, authority, decomposition, dependency, source, release, issuance, or reliance state.
9. Scope, authority, lifecycle, and dependency changes escalate to their owning workflow.
10. No result means blanket deliverable, package, pilot, or corpus completion.

Calibration used C02, C12, and C18. Exact source bytes were supplied to the
read-only Agent-2 workers after initial fail-closed returns identified that
their first briefs lacked those bytes. C02 and C12 calibrated to exact removal;
C12's nested annotation is removed only as part of its parent block, without
any historical inference. C18 calibrated to `NO_CHANGE`: the current PEC
profile says no runtime client is declared, so the registration work remains
open while the profile/RBAC/data/human/scratch-demo fences remain preserved.

No new convention or addendum was needed. Scale-out therefore proceeded over
the remaining 15 rows.
