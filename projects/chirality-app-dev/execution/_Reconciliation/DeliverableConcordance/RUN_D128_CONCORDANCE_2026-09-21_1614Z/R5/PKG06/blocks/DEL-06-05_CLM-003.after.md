### CLM-003 — Attributes

Shell execution must follow the user's selected host approval and sandbox policy and retain auditable permission, output and terminal-outcome evidence. Tool availability alone is not execution permission. Timeout, output-capture, result-metadata and interruption obligations remain; unavailable or unsuccessful interruption must not be represented as success.

D-GOV-43 items 2, 4 and 9 govern the live Codex path. SDK Bash names, the legacy default-deny mode table, overlay record shape and project-local audit-store path describe compatibility mechanisms. The canonical Runtime record and safe evidence linkage govern current records. Full access does not grant authority to bypass human gates or mutate protected project truth.
