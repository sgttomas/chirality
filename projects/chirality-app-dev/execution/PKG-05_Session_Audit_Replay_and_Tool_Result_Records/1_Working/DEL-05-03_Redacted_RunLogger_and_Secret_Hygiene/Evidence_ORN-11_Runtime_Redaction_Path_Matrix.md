# ORN-11 Runtime Redaction-Path Matrix

**Scope:** DEL-05-03 implementation evidence only. This matrix consolidates the live configured-API-key redaction paths and their focused fixtures. It does not issue DEL-05-03, satisfy dependency rows, broaden the configured-secret contract, define a withheld-sensitive result policy, or make a release-readiness claim.

**Redaction contract:** `frontend/src/lib/harness/run-logger.ts` reads UI, `ANTHROPIC_API_KEY`, and `CHIRALITY_ANTHROPIC_API_KEY` values; expands raw and URL-encoded variants; replaces matches with `[REDACTED_API_KEY]`; and recursively redacts JSON-like string values. Non-secret typed metadata remains available for audit and diagnosis.

## Residual boundary

- The live contract is configured-API-key redaction. A broader arbitrary-secret registry is not inferred or added by ORN-11.
- SDK transcripts remain secondary adapter state. Chirality JSONL persistence, replay, route, and browser surfaces are the governed runtime boundaries evidenced here.
- Explicit typed withholding of sensitive tool results and lifecycle issuance remain separate, gated work. This matrix changes neither.
