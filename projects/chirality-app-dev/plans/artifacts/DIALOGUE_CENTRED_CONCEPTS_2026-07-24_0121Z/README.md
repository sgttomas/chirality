## Why this replacement set exists

The first concept set correctly moved away from a system-shaped dashboard but
overcorrected by demoting the actual human–agent dialogue. The owner clarified
the central product thesis:

- the application brings human and agent together through dialogue;
- they produce artifacts of work through that dialogue;
- shared intent emerges through conversation and is not an authoritative field
  or object the interface can simply point to;
- agent workflows and recorded parent–child hierarchy remain valuable and one
  concept must make them visible without displacing dialogue.

The prior packet remains immutable concept history. Its recommendation is
withdrawn.

## Replacement concepts

1. **Dialogue Studio** — persistent centre dialogue with an artifact/context
   desk beside it.
2. **Collaborative Bench** — dialogue and active artifact share a resizable
   working area; an optional supervisory rail makes recorded agent workflow and
   parent–child hierarchy visible.
3. **Woven Dialogue** — artifact proposals, diffs, validation, returns, and
   evidence appear as rich objects inside the central conversation and expand
   into focused inspection.

All three keep Agent Room as a secondary supervisory capability and preserve
the accepted runtime, route, API, SSE, state, and migration ceiling.

## Explicit non-goal

An automatically generated “current shared intent” summary is not part of any
base concept. Local-model summarization may later be evaluated as a
non-authoritative projection because local inference makes frequent refresh
economically plausible; it is not required or authorized here.
