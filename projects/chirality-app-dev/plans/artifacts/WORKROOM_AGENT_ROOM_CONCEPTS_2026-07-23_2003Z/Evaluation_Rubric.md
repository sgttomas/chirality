# Concept Evaluation Rubric

> **NON_AUTHORITATIVE — CONCEPT EVIDENCE**

Each concept is assessed qualitatively against the same criteria. Scores are
decision aids, not authority.

| Criterion | Question | Weight |
|---|---|---:|
| Artifact primacy | Does sustained work remain centred on the document, diff, deliverable, evidence packet, or return? | 20 |
| Supervisory clarity | Can the user understand and control current governed work without reading raw streams? | 15 |
| Runtime truthfulness | Does the design avoid suggesting capabilities or authority absent from canonical contracts? | 15 |
| Task continuity | Can the user inspect, compare, delegate, monitor, and review without repeatedly losing context? | 15 |
| Migration safety | Can current routes, query parameters, APIs, SSE, provider state, and stored state coexist during cutover? | 10 |
| Professional calm | Is information hierarchy legible without command-centre density or ornamental status noise? | 10 |
| Accessibility | Is the spatial model tractable for keyboard, focus, landmarks, screen readers, reduced motion, and reflow? | 10 |
| Implementation economy | Does it reuse tested mechanics and avoid premature platform/runtime expansion? | 5 |

## Required disqualifiers

A concept is outside the accepted envelope if it:

- requires a new runtime endpoint or daemon capability;
- treats a UI projection as canonical project/session evidence;
- breaks the existing routes, API shapes, SSE names, or query semantics;
- requires new package/deliverable topology;
- authorizes retirement of the current UI;
- depicts arbitrary multi-agent graphs, automatic scheduling, or model
  residency control as current capability;
- makes chat or agent taxonomy the mandatory entry point for artifact work.

## Owner selection fields

The selected concept or explicit hybrid must freeze:

- primary home surface;
- desktop region composition;
- compact-window composition;
- Navigator information model;
- artifact tab and comparison model;
- Agent Room placement and expansion behavior;
- chat invocation and persistence behavior;
- Workbench/Pipeline placement;
- activity-shelf behavior;
- initial artifact types;
- state-migration posture;
- `SOW-005` and `DEL-08-02` disposition;
- compatibility and explicit deferrals.
