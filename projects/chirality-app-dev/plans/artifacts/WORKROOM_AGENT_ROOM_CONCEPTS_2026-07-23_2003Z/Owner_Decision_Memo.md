# Owner Concept-Selection Memo

> **NON_AUTHORITATIVE — AWAITING OWNER SELECTION**

## Recommended selection

Select **Concept C with Workroom as the default home**.

This freezes Concept C's shared frame and peer Agent Room while importing
Concept A's startup priority:

- Workroom opens by default.
- Agent Room is a full peer workspace, not a sidebar.
- Chat is contextual and supporting.
- The Activity Shelf is shared.

## Alternatives

### Select Concept A unchanged

Choose this if the Agent Room should remain a deliberately secondary
supervisory surface even when agent supervision becomes a major activity.

### Select Concept B

Choose this if governed session evidence should be the first screen on every
project, accepting that artifact work begins from a process-oriented foyer.

### Select Concept C unchanged

Choose this if the app should restore whichever peer surface was last used,
rather than always opening Workroom.

## Consequences of the recommendation

- `SOW-005` and `DEL-08-02` are modified rather than retired.
- The 3x4 matrix is no longer a target-shell requirement.
- Alias, routing, query compatibility, unavailable-persona handling, and
  mid-turn launch guards remain governed responsibilities.
- Gate 3 can draft exact amendments inside the accepted envelope.
- Production implementation remains unauthorized until Gates 3–5 complete.

Gate-2 envelope, SCA-APP-004 returns to Gates 1–2.
