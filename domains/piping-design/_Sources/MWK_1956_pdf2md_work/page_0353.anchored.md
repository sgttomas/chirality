## C-15. Guided Cantilever Chart

![C-15. Guided Cantilever Chart - Assumed mode of deflection of guided cantilever. L = Length of leg, ft. b = Lateral deflection, in. Value of E used = 29 x 10^6 psi. S_A = Code allowable stress range \(1.25S_c + 0.25S_h\), psi.](figures/MWK_1956_p0353_fig01_c-15-guided-cantilever-chart-assumed-mod.png)

Assumed mode of deflection of guided cantilever.

- $L$ = Length of leg, ft.
- $b$ = Lateral deflection, in.
- Value of $E$ used = $29 \times 10^6$ psi.
- $S_A$ = Code allowable stress range $(1.25S_c + 0.25S_h)$, psi.

*Instructions:* Determine value of $L/\sqrt{S_A}/10^3$. Enter with this value of ordinate scale and read over to line for proper nominal pipe size. Read down to abscissa scale. The value obtained will be the permissible lateral deflection for leg.
