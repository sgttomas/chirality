Any extraneous movement at the terminal point must, of course, be included in the summation. In other words, the pipe line from the terminal to the point in question is treated as an independent line whose free-end deformations can be determined since the moments and forces are known.

For the next point for which the deflections are required the same procedure is repeated with the shape coefficients summed from the first to the second point. This part of the pipe line is now considered as an independent line for which the terminal deformations are those calculated for the previous point.

Since

$$\delta^*_x = \delta_x - z\theta_y + y\theta_z$$
$$\delta^*_y = \delta_y - x\theta_z + z\theta_x$$
$$\delta^*_z = \delta_z - y\theta_x + x\theta_y$$

the actual deflections, $\delta_x$, $\delta_y$, $\delta_z$, can be computed.
