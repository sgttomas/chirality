## HISTORY AND DERIVATION OF PIPING FLEXIBILITY ANALYSIS

[FIGURE: Fig. A.12 The angle $\psi$ for circular members clockwise.]

For a circular member the *direction* may be either counterclockwise, or clockwise as the member is viewed in its working plane. For the counterclockwise direction the angle $\psi$ in the integrals for the shape coefficients is replaced by $(\alpha + \phi)$ where $\alpha$ is a constant angle, positive if measured from the negative vertical axis in the counterclockwise direction. The angle $\phi$ is a variable, positive in the counterclockwise direction. See Fig. A.11.

For the clockwise direction the angle $\psi$ in integrals for the shape coefficients is replaced by

$(\alpha - \phi)$ where $\alpha$ is defined in the same way as for the counterclockwise direction, and $\phi$ is a variable angle positive in the clockwise direction (Fig. A.12).

It should be noted that in the integration of the shape coefficients for concentrated loading the *counterclockwise* direction is used. If the *clockwise* direction is used the numerical values for the shape coefficients will be the same although the formulas will differ.

[FIGURE: Fig. A.13 Counterclockwise integration of shape coefficients for weight loading of circular members in the z-plane.]

$$l = R\phi \quad dl = R \, d\phi$$
$$x = a + R \sin (\alpha + \phi)$$
$$y = b - R \cos (\alpha + \phi)$$

$$\bar{x} = \frac{\int_0^\phi x \, dl}{\int_0^\phi dl} = a + R \frac{\sin (\alpha + \phi) - \sin \alpha}{\phi}$$

Integrations of the shape coefficients for weight loading applied to circular members are as follows, beginning with a member in the z-plane taken in the *counterclockwise* direction, as shown in Fig. A.13:

$$w_a = \int_0^\phi kQR^4 [\cos \alpha - \cos (\alpha + \phi) - \phi \sin (\alpha + \phi)] \, d\phi = kQR^4 [\Phi(\cos (\alpha + \phi) + \cos \alpha] - 2[\sin (\alpha + \phi) - \sin \alpha]$$

$$w_{ab} = +bw_a + w'_{aa}$$

where $w'_{aa} = -\int_0^\phi kQR^5 [\cos \alpha - \cos (\alpha + \phi) - \phi \sin (\alpha + \phi)] \cos (\alpha + \phi) \, d\phi$

$$= +kQR^5 \left\{ \frac{\Phi}{2} \left[ 1 - \frac{\cos 2(\alpha + \phi)}{2} \right] + \tfrac{3}{8} [\sin 2(\alpha + \Phi) - \sin 2\alpha] - \cos \alpha [\sin (\alpha + \Phi) - \sin \alpha] \right\}$$

$$w_{aa} = -aw_a + w'_{aa}$$

where $w'_{aa} = \int_0^\phi kQR^5 [\cos \alpha - \cos (\alpha + \phi)] \sin (\alpha + \phi) \, d\phi$

$$= kQR^5 \left\{ \frac{\Phi}{4} [\Phi - \sin 2(\alpha + \Phi)] - \tfrac{3}{8} [\cos 2(\alpha + \Phi) - \cos 2\alpha] - \cos \alpha [\cos (\alpha + \Phi) - \cos \alpha] \right\}$$
