- O.D. = Outside Pipe Size (in.)

- x,y,z = Change in Coordinates (ft.)
- k = Flexibility Factor
- i = Stress Intensification Factor
- q = Moment of Inertia Correction Factor
- Q = Stiffness Factor

- B.A. = Base Anchor
- Rx,Ry,Rz = Rotations (radians)
- Dx,Dy,Dz,Dt = Movement (in.)
- Cx,Cy,Cz,C = Spring Constant (lbs./in.)
- Lx,Ly,Lz = Directional Cosines
- Px,Py,Pz = External Loads (kips.)
