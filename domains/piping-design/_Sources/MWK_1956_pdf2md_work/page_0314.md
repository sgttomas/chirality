# HISTORY AND DERIVATION OF PIPING FLEXIBILITY ANALYSIS

For circular members shown in Fig. A.6 the variable is changed and the integrations are as follows:

$$z = \int_0^{\Phi} kQR \, d\phi = kQR\Phi$$

$$z'_a = \int_0^{\Phi} kQR \sin{(\alpha + \phi)} \, d\phi = kQR^2[\cos\alpha - \cos{(\alpha + \Phi)}]$$

$$z'_{aa} = \int_0^{\Phi} kQR \sin^2{(\alpha + \phi)} \, d\phi = kQR^3 \left[\frac{\Phi}{2} - \frac{\sin{2(\alpha + \Phi)} - \sin{2\alpha}}{4}\right]$$

$$z'_b = -\int_0^{\Phi} kQR \cos{(\alpha + \phi)} \, d\phi = kQR^2[\sin\alpha - \sin{(\alpha + \Phi)}]$$

$$z'_{bb} = \int_0^{\Phi} kQR \cos^2{(\alpha + \phi)} \, d\phi = kQR^3 \left[\frac{\Phi}{2} + \frac{\sin{2(\alpha + \Phi)} - \sin{2\alpha}}{4}\right]$$

$$z'_{ab} = -\int_0^{\Phi} kQR \sin{(\alpha + \phi)} \cos{(\alpha + \phi)} \, d\phi = \frac{kQR^3}{4}[\cos{2(\alpha + \Phi)} - \cos{2\alpha}]$$

[FIGURE: Fig. A.6 Integration of shape coefficients for concentrated loading of circular members.]

$$q = \int_0^{\Phi} (1.3 - k) \sin{(\alpha + \phi)} \cos{(\alpha + \phi)} QR \, d\phi = -(1.3 - k) QR \frac{\cos{2(\alpha + \Phi)} - \cos{2\alpha}}{4}$$

$$u = \int_0^{\Phi} [k \cos^2{(\alpha + \phi)} + 1.3 \sin^2{(\alpha + \phi)}] QR \, d\phi$$

$$= kQR \left[\frac{\Phi}{2} + \frac{\sin{2(\alpha + \Phi)} - \sin{2\alpha}}{4}\right] + 1.3 QR \left[\frac{\Phi}{2} - \frac{\sin{2(\alpha + \Phi)} - \sin{2\alpha}}{4}\right]$$

$$u'_a = \int_0^{\Phi} [k \sin{(\alpha + \phi)} \cos^2{(\alpha + \phi)} + 1.3 \sin^3{(\alpha + \phi)}] QR^2 \, d\phi = 1.3 QR^2 [\cos\alpha - \cos{(\alpha + \Phi)}]$$

$$+ (1.3 - k) \int_0^{\Phi} \sin{(\alpha + \phi)} \cos^2{(\alpha + \phi)} QR^2 \, d\phi$$

$$u'_{aa} = \int_0^{\Phi} [k \sin^2{(\alpha + \phi)} \cos^2{(\alpha + \phi)} + 1.3 \sin^4{(\alpha + \phi)}] QR^3 \, d\phi = 1.3 QR^3 \left[\frac{\Phi}{2} - \frac{\sin{2(\alpha + \Phi)} - \sin{2\alpha}}{4}\right]$$

$$+ (1.3 - k) \int_0^{\Phi} \sin^2{(\alpha + \phi)} \cos^2{(\alpha + \phi)} QR^3 \, d\phi$$

$$v = \int_0^{\Phi} [1.3 \cos^2{(\alpha + \phi)} + k \sin^2{(\alpha + \phi)}] QR \, d\phi$$

$$= 1.3 QR \left[\frac{\Phi}{2} + \frac{\sin{2(\alpha + \Phi)} - \sin{2\alpha}}{4}\right] + kQR \left[\frac{\Phi}{2} - \frac{\sin{2(\alpha + \Phi)} - \sin{2\alpha}}{4}\right]$$

$$v'_a = -\int_0^{\Phi} [k \cos{(\alpha + \phi)} \sin^2{(\alpha + \phi)} + 1.3 \cos^3{(\alpha + \phi)} + (1.3 - k) \cos{(\alpha + \phi)} \sin^2{(\alpha + \phi)}] QR^2 \, d\phi$$

$$= 1.3 QR^2 [\sin\alpha - \sin{(\alpha + \Phi)}]$$

$$v'_{aa} = \int_0^{\Phi} [k \cos^2{(\alpha + \phi)} \sin^2{(\alpha + \phi)} + 1.3 \cos^4{(\alpha + \phi)} + (1.3 - k) \cos^2{(\alpha + \phi)} \sin^2{(\alpha + \phi)}] QR^3 \, d\phi$$

$$= 1.3 QR^3 \left[\frac{\Phi}{2} + \frac{\sin{2(\alpha + \Phi)} - \sin{2\alpha}}{4}\right]$$
