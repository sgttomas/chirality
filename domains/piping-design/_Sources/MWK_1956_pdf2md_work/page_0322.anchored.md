# HISTORY AND DERIVATION OF PIPING FLEXIBILITY ANALYSIS

As mentioned previously in connection with the formulas of Table A.4, the effective wind load on a member is taken as the unit wind load multiplied by the length of the member's projection on a plane perpendicular to the wind direction. If the working plane of the member is perpendicular to the wind, the wind load is simply $w l$. The shape coefficients are then the same as those already found for weight loading, identified as $w_b$, $w_a$, and $w_{ab}$. For members in planes parallel to the wind, the wind load is $w l'$ where $l'$ represents the projected length of the member on a plane perpendicular to the wind direction.

![Fig. A.17 Integration of shape coefficients for straight members in the p-plane acted upon by z-wind.](figures/MWK_1956_p0322_fig01_fig-a-17-integration-of-shape-coefficien.png)

Formulas for calculating shape coefficients $w_b$, $w_{bb}$, and $w_{ab}$ are now derived for a straight member in the z-plane, acted upon by a wind parallel to the z (horizontal) axis as shown in Fig. A.17.

The relationships for $l'$, $\bar{y}'$, and $z$ accompanying Fig. A.17 are readily derived therefrom. The two functions expressing $l'$ are necessary since the unit load is considered positive and thus the total load $wl'$ and the length $l'$ itself must remain positive for any value of $\alpha$.

Performing the integrations as indicated by the formulas of Table A.4, yields the following results:

$$w_b = \mp \int_0^L kQ \frac{L^2}{2} \sin^2 \alpha \, dl = \mp kQ \frac{L^3}{6} \sin^2 \alpha$$

$$w_{aa} = -aw_a + w'_{aa}$$

$$\text{where } w'_{aa} = \mp \int_0^L kQ \left( \frac{L}{2} - l \right) \frac{l^2}{2} \sin^2 \alpha \, dl$$

$$= \pm kQ \frac{L^4}{24} \cos \alpha \sin^2 \alpha$$

$$w_{bb} = +bw_b + w'_{bb}$$

where $w'_{bb} = \mp \int_0^L kQ \frac{L^2}{2} \sin^2 \alpha \, dl$

$$= \pm kQ \frac{L^4}{24} \sin^2 \alpha$$

The upper signs apply when $\sin \alpha$ is positive ($0 < \alpha < \pi$); the lower signs when $\sin \alpha$ is negative ($\pi < \alpha < 2\pi$).

For straight members in the p-plane acted upon by *wind* along the z (horizontal) axis, the identical formulas apply because of cyclic permutation.

![Fig. A.18 Integration of shape coefficients for straight members in the p-plane acted upon by z-wind.](figures/MWK_1956_p0322_fig02_fig-a-18-integration-of-shape-coefficien.png)

$$l' = l \cos \alpha \text{ when } -\frac{\pi}{2} < \alpha < \frac{\pi}{2}$$

$$= -l \cos \alpha \text{ when } \frac{\pi}{2} < \alpha < \frac{3\pi}{2}$$

$$x = a + \tfrac{1}{2}(L - 2l) \cos \alpha$$

$$y = b$$

$$z = c + \tfrac{1}{2}(L - 2l) \sin \alpha$$

$$l' = c + \tfrac{1}{2}(L - l) \sin \alpha$$

For straight members in the p-plane acted upon by a wind parallel to the x (vertical) axis, shown in Fig. A.18, it is necessary to derive the coefficients $w_a$, $w_{aa}$, and $w_{ab}$.

$$w_a = \mp \int_0^L kQ \frac{L^2}{2} \cos^2 \alpha \, dl = \pm kQ \frac{L^3}{6} \cos^2 \alpha$$

$$w_{ab} = +b w_{ab} + w'_{ab}$$

$$\text{where } w'_{ab} = \pm \int_0^L kQ \left( \frac{L}{2} - l \right) \frac{l^2}{2} \cos^2 \alpha \, dl$$

$$= \mp kQ \frac{L^4}{24} \sin \alpha \cos^2 \alpha$$

$$w_{aa} = -a w_a + w'_{aa}$$

$$\text{where } w'_{aa} = \mp \int_0^L kQ \left( \frac{L}{2} - l \right) \frac{l^2}{2} \cos^2 \alpha \, dl$$

$$= \pm kQ \frac{L^4}{24} \cos^3 \alpha$$

The upper signs apply when $\cos \alpha$ is positive ($-\pi/2 < \alpha < \pi/2$); lower signs when $\cos \alpha$ is negative ($\pi/2 < \alpha < 3\pi/2$).

For straight members in the p-plane acted upon by *wind* along the z-axis, the identical formulas apply.
