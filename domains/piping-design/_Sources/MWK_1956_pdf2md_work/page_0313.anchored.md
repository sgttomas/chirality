312    DESIGN OF PIPING SYSTEMS

![Fig. A.5 Integration of shape coefficients for concentrated loading of straight members.](figures/MWK_1956_p0313_fig01_integration-of-shape-coefficients-for-co.png)

For straight members as shown in Fig. A.5, the integrations are as follows:

$$s = \int_0^L kQ \, dl = kQL$$

$$s'_{aa} = \int_0^L kQ \left(\frac{L}{2} - l\right) \cos \alpha \, dl = 0$$

$$s'_{aaa} = \int_0^L kQ \left(\frac{L}{2} - l\right)^2 \cos^2 \alpha \, dl = kQ \cos^2 \alpha \frac{L^3}{12}$$

$$s'_b = \int_0^L kQ \left(\frac{L}{2} - l\right) \sin \alpha \, dl = 0$$

$$s'_{bbb} = \int_0^L kQ \left(\frac{L}{2} - l\right)^2 \sin^2 \alpha \, dl = kQ \sin^2 \alpha \frac{L^3}{12}$$

$$s'_{ab} = \int_0^L kQ \left(\frac{L}{2} - l\right)^2 \sin \alpha \cos \alpha \, dl = kQ \sin \alpha \cos \alpha \frac{L^3}{12}$$

$$q = \int_0^L (1.3 - k) \sin \alpha \cos \alpha \, Q \, dl = (1.3 - k) \sin \alpha \cos \alpha \, QL$$

$$u = \int_0^L (k \cos^2 \alpha + 1.3 \sin^2 \alpha) Q \, dl = (k \cos^2 \alpha + 1.3 \sin^2 \alpha) QL$$

$$u'_a = \int_0^L \left(\frac{L}{2} - l\right) (k \cos^2 \alpha + 1.3 \sin^2 \alpha) Q \cos \alpha \, dl - \int_0^L \left(\frac{L}{2} - l\right) \sin^2 \alpha \cos \alpha \, (1.3 - k) Q \, dl = 0$$

$$u'_{aa} = \int_0^L \left(\frac{L}{2} - l\right)^2 \cos^2 \alpha \, (k \cos^2 \alpha + 1.3 \sin^2 \alpha) Q \, dl - \int_0^L \left(\frac{L}{2} - l\right)^2 \sin^2 \alpha \cos^2 \alpha \, (1.3 - k) Q \, dl = kQ \cos^2 \alpha \frac{L^3}{12}$$

$$v = \int_0^L (1.3 \cos^2 \alpha + k \sin^2 \alpha) Q \, dl = (1.3 \cos^2 \alpha + k \sin^2 \alpha) QL$$

$$v'_a = \int_0^L \left(\frac{L}{2} - l\right) \sin \alpha \, (1.3 \cos^2 \alpha + k \sin^2 \alpha) Q \, dl - \int_0^L \left(\frac{L}{2} - l\right) \sin \alpha \cos^2 \alpha \, (1.3 - k) Q \, dl = 0$$

$$v'_{bb} = \int_0^L \left(\frac{L}{2} - l\right)^2 \sin^2 \alpha \, (1.3 \cos^2 \alpha + k \sin^2 \alpha) Q \, dl - \int_0^L \left(\frac{L}{2} - l\right)^2 \sin^2 \alpha \cos^2 \alpha \, (1.3 - k) Q \, dl = kQ \sin^2 \alpha \frac{L^3}{12}$$

*Note:* $u'_{aa} + v'_{bb} = kQ \dfrac{L^3}{12}$
