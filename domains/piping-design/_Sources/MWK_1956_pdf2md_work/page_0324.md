The case of the circular member in the y-plane acted upon by a wind parallel to the x-axis is now considered. Figure A.21 shows such a member set up for integration in a *counterclockwise* direction.

$$w_{ax} = \mp \int_0^\phi kQR^3 \frac{[\sin(\alpha + \phi) - \sin \alpha]^2}{2} d\phi$$

$$= \mp k QR^3 \left[\frac{\Phi}{4}(2 - \cos 2\alpha) - \frac{\sin 2(\alpha + \Phi)}{8} + \sin \alpha \cos(\alpha + \Phi) - \tfrac{3}{4} \sin 2\alpha\right]$$

$$w_{ab} = + b w_a + w'_{ab}$$

where

$$w'_{ab} = \pm \int_0^\phi kQR^4 \cos(\alpha + \phi) \frac{[\sin(\alpha + \phi) - \sin \alpha]^2}{2} d\phi = \pm kQR^4 \frac{[\sin(\alpha + \phi) - \sin \alpha]^3}{6}$$

$$w_{az} = -aw_a + w'_{az}$$

where

$$w'_{az} = \pm \int_0^\phi kQR^4 \sin(\alpha + \phi) \frac{[\sin(\alpha + \phi) - \sin \alpha]^2}{2} d\phi$$

$$= \pm kQR^4 \left[\frac{\cos^3(\alpha + \phi) - \cos^3 \alpha}{6} - \frac{\cos(\alpha + \phi) - \cos \alpha}{2}\right]$$

$$- \frac{\sin \alpha}{2} \left[\Phi + \sin(\alpha + \Phi) \cos(\alpha + \Phi) + \sin \alpha \cos(\alpha + \Phi)\right]$$

The upper signs apply when $\Phi$ lies in the *I* and/or *IV* quadrant, the lower signs when $\Phi$ lies in the *II* and/or *III* quadrants. When $\Phi$ lies in the *I* and *II* quadrants or the *III* and *IV*, it must be split up into two arcs.

For the counterclockwise integration of circular members in the x-plane subjected to z-wind, the same formulas apply.
