## DESIGN OF PIPING SYSTEMS

$$x = b + \frac{L}{2} \sin \alpha - l \sin \alpha$$

$$z = a + \frac{L}{2} \cos \alpha - l \cos \alpha$$

$$x' = b + \frac{L}{2} \sin \alpha - \frac{l}{2} \sin \alpha$$

$$z' = a + \frac{L}{2} \cos \alpha - \frac{l}{2} \cos \alpha$$

[FIGURE: Fig. A.9 Integration of shape coefficients for weight of straight members in the y-plane.]

For a member in the y-plane as shown in Fig. A.9:

$$w_x = -\int_0^L kQ \frac{l^2}{2} \sin \alpha (k \cos^2 \alpha + 1.3 \sin^2 \alpha) Q \, dl + \int_0^L kQ \frac{l^2}{2} \sin \alpha (1.3 - k) \sin \alpha \cos \alpha \, Q \, dl$$

$$= -kQ \frac{L^3}{6} \cos \alpha$$

$$w_z = -\int_0^L kQ \frac{l^2}{2} \cos \alpha (1.3 \cos^2 \alpha + k \sin^2 \alpha) Q \, dl - \int_0^L kQ \frac{l^2}{2} \cos \alpha (1.3 - k) \sin \alpha \cos \alpha \, Q \, dl$$

$$= +kQ \frac{L^3}{6} \cos \alpha$$

$$w_{xx} + aw_x - bw_z + w'_{xx}$$

where $w'_{xx} = -\int_0^L kQ \left(\frac{L}{2} - l\right) \frac{l^2}{2} \cos^2 \alpha (k \cos^2 \alpha + 1.3 \sin^2 \alpha) Q \, dl + \int_0^L kQ \left(\frac{L}{2} - l\right) \frac{l^2}{2} \sin \alpha \cos \alpha (1.3 - k) \sin \alpha \cos \alpha \, Q \, dl$

$$- \int_0^L kQ \left(\frac{L}{2} - l\right) \frac{l^2}{2} \sin^2 \alpha (1.3 \cos^2 \alpha + k \sin^2 \alpha) Q \, dl + \int_0^L kQ \left(\frac{L}{2} - l\right) \frac{l^2}{2} \sin \alpha \cos \alpha (1.3 - k) \sin \alpha \cos \alpha \, Q \, dl$$

$$= kQ \frac{L^4}{24}$$

[FIGURE: Fig. A.10 Integration of shape coefficients for weight of straight members in the x-plane.]

$$y = a + \frac{L}{2} \cos \alpha - l \cos \alpha$$

$$z = b + \frac{L}{2} \sin \alpha - l \sin \alpha$$

$$y' = a + \frac{L}{2} \cos \alpha - \frac{l}{2} \cos \alpha$$

$$z' = b + \frac{L}{2} \sin \alpha - \frac{l}{2} \sin \alpha$$

For a member in x-plane as shown in Fig. A.10:

$$w_z = -\int_0^L kQ \frac{l^2}{2} \sin \alpha \, dl = -KQ \frac{L^3}{6} \sin \alpha$$

$$w_{bz} = -aw_z + w'_{bz}$$

where $w'_{bz} = \int_0^L kQ \frac{l^2}{2} \sin \alpha \cos \alpha \left(\frac{L}{2} - l\right) dl = kQ \frac{L^4}{24} \sin \alpha \cos \alpha$

$$w_{bb} = +bw_z + w'_{bb}$$

where $w'_{bb} = -\int_0^L kQ \frac{l^2}{2} \sin^2 \alpha \left(\frac{L}{2} - l\right) dl = kQ \frac{L^4}{24} \sin^2 \alpha$
