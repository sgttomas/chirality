HISTORY AND DERIVATION OF PIPING FLEXIBILITY ANALYSIS 319

[FIGURE: Fig. A.15 Counterclockwise integration of shape coefficients for weight of circular members in the y-plane.]

$$l = R\varphi \quad dl = R\, d\varphi$$
$$x = b - R\cos(\alpha + \varphi)$$
$$z = a + R\sin(\alpha + \varphi)$$

$$\bar{x} = \frac{\int_0^\varphi x\, dl}{\int_0^\varphi dl} = b + R\frac{\sin\alpha - \sin(\alpha + \varphi)}{\varphi}$$

$$\bar{z} = \frac{\int_0^\varphi z\, dl}{\int_0^\varphi dl} = a + R\frac{\cos\alpha - \cos(\alpha + \varphi)}{\varphi}$$

For y-plane members taken in the *counterclockwise* direction (Fig. A.15):

$$w_x = -\int_0^\varphi QR^3[\cos\alpha - \cos(\alpha + \phi)][k\cos^2(\alpha + \phi) + 1.3\sin^2(\alpha + \phi)]\, d\phi$$

$$\quad + \int_0^\varphi QR^3[\sin\alpha - \sin(\alpha + \phi) + \phi\cos(\alpha + \phi)](1.3 - k)\sin(\alpha + \phi)\cos(\alpha + \phi)\, d\phi$$

$$= -QR^3\left\{k\left[\frac{\Phi}{2}\cos\alpha - \cos(\alpha + \Phi) + 0.75\sin\alpha + 0.25\sin(\alpha + 2\Phi)\right]\right.$$

$$\quad \left. + 1.3\left[\frac{\Phi}{2}\cos\alpha + \Phi\cos(\alpha + \phi) - \sin(\alpha + \phi) + 1.25\sin\alpha - 0.25\sin(\alpha + 2\Phi)\right]\right\}$$

$$w_x = +\int_0^\varphi QR^3[\sin\alpha - \sin(\alpha + \phi) + \phi\cos(\alpha + \phi)][1.3\cos^2(\alpha + \phi) + k\sin^2(\alpha + \phi)]\, d\phi$$

$$\quad - \int_0^\varphi QR^3[\cos\alpha - \cos(\alpha + \phi) - \phi\sin(\alpha + \phi)](1.3 - k)\sin(\alpha + \phi)\cos(\alpha + \phi)\, d\phi$$

$$= QR^3\left\{k\left[\frac{\Phi}{2}\sin\alpha + \cos(\alpha + \phi) - 0.75\cos\alpha - 0.25\cos(\alpha + 2\Phi)\right] + 1.3\left[\frac{\Phi}{2}\sin\alpha\right.\right.$$

$$\quad \left.\left. + \Phi\sin(\alpha + \phi) + \cos(\alpha + \phi) - 1.25\cos\alpha + 0.25\cos(\alpha + 2\Phi)\right]\right\}$$

$$w_{xz} = +aw_x - bw_z + w'_{xz}$$

where: $w'_{xz} = -\int_0^\varphi QR^4 \sin(\alpha + \phi)\left\{k\left[\frac{\cos\alpha}{2} - \cos(\alpha + \phi) + \frac{\cos(\alpha + 2\phi)}{2}\right]\right.$

$$\quad \left. + 1.3\left[\frac{\cos\alpha}{2} - \phi\sin(\alpha + \phi) - \frac{\cos(\alpha + 2\phi)}{2}\right]\right\}d\phi$$

$$\quad + \int_0^\varphi QR^4 \cos(\alpha + \phi)\left\{k\left[\frac{\sin\alpha}{2} - \sin(\alpha + \phi) + \frac{\sin(\alpha + 2\phi)}{2}\right]\right.$$

$$\quad \left. + 1.3\left[\frac{\sin\alpha}{2} + \phi\cos(\alpha + \phi) - \frac{\sin(\alpha + 2\phi)}{2}\right]\right\}d\phi = 1.3QR^4\left[\frac{\Phi^2}{2} + \cos\Phi - 1\right]$$
