The shape coefficient expressions for concentrated loads become:

$$z = \int kQ \, dl$$

$$z_a = \int kQx \, dl = az + s'_a \quad \text{where } s'_a = \int kQz' \, dl$$

$$z_{aa} = \int kQx^2 \, dl = a^2z + 2as'_a + s'_{aa} \quad \text{where } s'_{aa} = \int kQ(x')^2 \, dl$$

$$z_b = \int kQy \, dl = bz + s'_b \quad \text{where } s'_b = \int kQy' \, dl$$

$$z_{bb} = \int kQy^2 \, dl = b^2z + 2bs'_b + s'_{bb} \quad \text{where } s'_{bb} = \int kQ(y')^2 \, dl$$

$$z_{ab} = \int kQxy \, dl = abz + as'_b + bs'_a + s'_{ab} \quad \text{where } s'_{ab} = \int kQx'y' \, dl$$

$$q = \int (1.3 - k) \sin \psi \cos \psi \, Q \, dl$$

$$u = \int (k \cos^2 \psi + 1.3 \sin^2 \psi) Q \, dl \tag{A.12}$$

$$u_a = \int x \, du - \int y \, dq = au - bq + u'_a \quad \text{where } u'_a = \int z' \, du - \int y' \, dq$$

$$v = \int (1.3 \cos^2 \psi + k \sin^2 \psi) Q \, dl$$

$$v_a = \int y \, dv - \int x \, dq = bv - aq + v'_a \quad \text{where } v'_a = \int y' \, dv - \int z' \, dq$$

$$u_{aa} + v_{aa} = \int z^2 \, du + \int y^2 \, dv - 2 \int xy \, dq = a^2u + b^2v - 2abq + 2au'_a + 2bv'_a + u'_{aa} + v'_{aa}$$

where

$$u'_{aa} = \int (x')^2 \, du - \int z'y' \, dq$$

$$v'_{aa} = \int (y')^2 \, dv - \int z'y' \, dq$$

The angle $\psi$ in the general expressions is a variable angle measured from the positive horizontal axis to the tangent at any point $P$ of the member. The angle, $\alpha$, constant for any given member, is the angle between the positive horizontal axis and the chord of tangency at $F$. For a straight member, $\psi$ is constant and equal to $\alpha$. For a curved member, $\psi$ is variable over the length of the arc. In the formulas which follow $\psi$ is replaced by $\alpha$ for straight members; for circular members, it is replaced by $(\alpha + \phi)$ and the limits of integrals are from 0 to $\Phi$.
