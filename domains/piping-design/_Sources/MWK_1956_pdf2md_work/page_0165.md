The inversion procedure is especially suitable where many branches are joined at one point. A system shown in Fig. 5.15 which represents 42 equations can be solved by the inversion method in solved by the inversion procedures in the following manner:

The rotations and deflections at $O$ are assumed to be $\theta_x$, $\theta_y$, $\theta_z$, $\delta_x$, $\delta_y$, $\delta_z$ and at point $I$ are $\theta'_x$, $\theta'_y$, $\theta'_z$, $\delta'_x$, $\delta'_y$, $\delta'_z$.

The system $OAB$ is set up as twelve equations as if $A$ is fixed end. The six equations for the $B$-branch are eliminated first and the remaining six equations are inverted. The systems $OCD$, $IBG$, and $IFH$ are treated the same way. A set of twelve equations can now be set up with the following unknowns:

$$\theta_x, \theta_y, \theta_z, \theta_a, \theta_b, \theta_c, \theta'_x, \theta'_y, \theta'_z, \delta^*_x, \delta^*_y, \delta^*_z$$

where

$$\delta^*_x = \delta'_x + y\theta'_z$$

$$\delta^*_y = \delta'_y - x\theta'_z + z\theta'_x$$

$$\delta^*_z = \delta'_z - y\theta'_x + x\theta'_y$$

and $x$, $y$, $z$ are the coordinates at point $I$.

The above problem can also be solved by the reinversion procedure which makes it possible to handle almost any piping system, no matter how complex it may be, without solving sets of equations of more than six unknowns.
