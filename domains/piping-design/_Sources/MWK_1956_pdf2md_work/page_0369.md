Similarly,

$$C = \begin{vmatrix} \dfrac{R}{2}(a_1\psi_1 + a_2\psi_2 + b_3R^2\psi_1) & 0 & 0 \\ 0 & \dfrac{R}{2}(a_1\psi_2 + a_2\varphi_1 + b_3R^2\psi_2) & 0 \\ 0 & 0 & R\theta(a_2 + b_1R^2) \end{vmatrix}$$

$$D = \begin{vmatrix} 0 & 0 & -2b_1R^2\sin\dfrac{\theta}{2} \\ 0 & 0 & 0 \\ 2b_2R^2\sin\dfrac{\theta}{2} & 0 & 0 \end{vmatrix}$$

Then the $X$ matrix is:

$$X = \begin{vmatrix} \dfrac{R}{2}(b_1\varphi_1 + b_3\varphi_2) & 0 & 0 & 0 & 0 & -2b_1R^2\sin\dfrac{\theta}{2} \\ 0 & \dfrac{R}{2}(b_1\varphi_2 + b_3\varphi_1) & 0 & 0 & 0 & 0 \\ 0 & 0 & b_2R\theta & 2b_2R^2\sin\dfrac{\theta}{2} & 0 & 0 \\ 0 & 0 & 2b_2R^2\sin\dfrac{\theta}{2} & \dfrac{R}{2}(a_1\varphi_1 + a_2\varphi_2 + b_3R^2\varphi_1) & 0 & 0 \\ 0 & 0 & 0 & 0 & \dfrac{R}{2}(a_1\varphi_2 + a_2\varphi_1 + b_3R^2\varphi_2) & 0 \\ -2b_1R^2\sin\dfrac{\theta}{2} & 0 & 0 & 0 & 0 & R\theta(a_2 + b_1R^2) \end{vmatrix}$$

c. *Construction of the $Y$ Matrix from Working Points.* So far, only the $X$ matrix has been constructed for a straight pipe as well as for a circular bend. To refer the shape coefficient matrix to a definite $z$-system at the chosen origin $O'$, the $X$ matrix appearing in Eq. 5A.30 must also be constructed, and the proper shape coefficient matrix will simply be $Y'XY$.

It is customary to specify working points whose coordinates are given in the $z$-system. For a straight pipe, the starting and terminal points are usually given (Figure 5A.4), and the necessary calculation for the construction of $Y$ matrix can be outlined below.

Given

$$\vec{a} = \vec{b} - \vec{a}_z$$

then

$$\left.\begin{aligned} l &= \sqrt{\vec{a} \cdot \vec{a}}, \\ \bar{x}_1 &= \vec{a}/l, \\ \bar{x}_2 &= \text{any unit vector satisfying } \bar{x}_1 \cdot \bar{x}_2 = 0, \\ \bar{x}_3 &= \bar{x}_1 \times \bar{x}_2, \end{aligned}\right\} \quad (b)$$

and, finally,

$$\bar{q} = \tfrac{1}{2}(\bar{a} + \bar{b}). \tag{c}$$

Now, let $\bar{q}$ be expressed by:

$$\bar{q} = q_1\bar{z}_1 + q_2\bar{z}_2 + q_3\bar{z}_3$$
