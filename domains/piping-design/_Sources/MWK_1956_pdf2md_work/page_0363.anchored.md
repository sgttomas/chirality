## 5A-2 Derivation of the Shape Coefficient Matrix

**1. Definitions and Nomenclature.** Unless otherwise specified in the text, the following definitions and nomenclature will be used consistently in this chapter.

(i) A vector is distinguished from a scalar by a bar over the symbol, thus $\bar{f}$ is a vector; $f_i$ is a scalar representing the component of $\bar{f}$ in the $i$-direction.

A vector with a superscript, $\bar{F}^i$, represents a six-component force (including moment) vector acting on the pipe branch $i$. Also, $\bar{x}^i$ represents a six-component displacement (including rotation) vector at the end of branch $i$.

(ii) An element in a matrix, located at the $i$-th row and the $j$-th column, is represented by a symbol with two subscripts, such as $A_{ij}$.

A matrix consisting of an array of numbers, $A_{ij}$, is represented by $|A_{ij}|$, or by a capital letter without subscript and vertical bars, e.g., $A$, $B$, etc.

A matrix with a superscript, $A^i$, represents the shape coefficient matrix of the branch $i$.

The transpose of a matrix $A$ (or $|A_{ij}|$) is denoted by $A'$ (or $|A_{ji}|$).

A zero (null) matrix is denoted as $|0|$. A diagonal unit matrix is denoted as $|I|$.

(iii) $\sum\limits_{i} = \sum\limits_{i=1, 2, 3}$ represents a summation with respect to $i$ of the term or terms following this sign, when $i$ varies from 1 to 3.

(iv) A right-hand, orthogonal coordinate system is denoted by one symbol with permutable subscripts 1, 2 and 3. The following coordinate systems are defined:

a. At the chosen origin, $O'$: $\bar{x}_1$, $\bar{x}_2$, $\bar{x}_3$, called the $x$-system;

b. At the convenient local origin, $q$: $\bar{x}_1$, $\bar{x}_2$, $\bar{x}_3$, called the $x_q$-system;

c. At any point along the pipe line, $P$: $\bar{\xi}_1$, $\bar{\xi}_2$, $\bar{\xi}_3$, called the $\xi$-system.

Note that $\bar{x}_i$, $\bar{x}_i$ and $\bar{\xi}_i$ are all unit vectors.

(v) The following position vectors are defined:

a. With respect to the $x$-system, the position vector of point $q$ is:

$$\bar{q}(x) = \sum_{i} q_i \bar{x}_i$$

and the position vector of point $P$ is:

$$\bar{p} = \sum_{i} x_i \bar{x}_i$$

b. With respect to the $x_q$-system, the position vector of point $P$ is:

$$\bar{p} = \sum_{i} \rho_i \bar{x}_i$$

Figure 5A.1 shows a space curve in the $x$-system. Any point $P$ on the curve can be defined by the equation:

$$\bar{p} = \sum_{i} p_i \bar{x}_i = \bar{q} + \bar{p} = \bar{q} + \sum_{i} \rho_i \bar{x}_i \quad (5A.1)$$

(vi) A vector defined in one coordinate system may be transformed to another system through a linear transformation defined as follows:

a. From the $\lambda$-system to the $\xi$-system:

$$\bar{\xi}_j = \sum_{i} \xi_{ji} \bar{x}_i \qquad j = 1, 2, 3 \quad (5A.2)$$

b. From the $x$-system to the $\lambda$-system:

$$\bar{x}_j = \sum_{i} \lambda_{ji} \bar{x}_i \qquad j = 1, 2, 3 \quad (5A.3)$$
