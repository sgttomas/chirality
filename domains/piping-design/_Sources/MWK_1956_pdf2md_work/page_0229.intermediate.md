While a trigonometric solution is indicated, it cannot be accomplished with sufficient accuracy on the slide rule, and the use of logarithms is time consuming. Hence, the following formulas were developed which are amply accurate, giving solutions to within a few minutes for small rotation angles (say about 5° or less). The notation is in accordance with Fig. 7.15, which shows a general three-hinge system.

If $\Delta_x$ is the effective displacement of joint $b$ relative to $a$, it may be defined as:

$$\Delta_x = \Delta_{xb} - \Delta_{xa} - xc$$

### Sample Calculation 7.2

*Given Data*

[FIGURE: Fig. 7.15 General three-hinge expansion joint system showing dimensions x, y, and displacements Δxa, Δxb, Δya, Δyb between joints a and b]

*Dimensions (ft)*

$x_a = 12.65 \quad y_a = 16.05$
$x_b = 9.85 \quad y_b = 1.75$
$x = 22.5 \quad y = 17.80$

*Calculations*

$\Delta_x = -0.034 + 0 + 0.184 = -0.218'$

$\Delta_y = -0.006 - 0.111 - 0.145 = -0.262'$

$x_b\Delta_y - x_a\Delta_x = 9.85 \times 16.05 - 12.65 \times 1.75 = 136$

**Case I**

$\phi_a = \frac{(-0.218 \times 9.85) + (-0.262 \times 1.75)}{136} \times \frac{180}{\pi}$

$\phantom{\phi_a} = -1.10°$

$\phi_b = \frac{(-0.218 \times 12.65) + (-0.262 \times 16.05)}{136} \times \frac{180}{\pi}$

$\phantom{\phi_b} = -2.94°$

$\phi_{ab} = 1.10 + 2.94 = 4.04°$

**Case II**

$\Delta_x = 0$

$\Delta_y = 0.275 + 0 + 0 = 0.275'$

$\phi_a = \frac{0 + (0.275 \times 1.75)}{136} \times \frac{180}{\pi} = 0.20°$

$\phi_b = \frac{0 + (0.275 \times 16.05)}{136} \times \frac{180}{\pi} = 1.86°$

$\phi_{ab} = 2.00 - 1.86 = -2.06°$
