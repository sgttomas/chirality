## Sanitary Sewer

This system collects raw waste from lavatories. If not discharged to the unit limit or lift station for disposal, it is routed to a septic tank or leeching field.

## Blowdown System

This system picks up drains around boilers and steam drums and is run as a separate system, preferably to the battery limit. It is permissible to tie into a sewer box in the oily water sewer system as long as it is located downstream from any sewer box that collects drainage from a furnace. This sewer box has an airtight cover and vents to the atmosphere if located within a minimum distance of 50 ft (15 m) from a fired heater.

## Pump-Out System
