**EXHIBIT 16-19**
Nomograph for Absorbing Leg on Vessel Piping

[FIGURE: Nomograph titled "CHART FOR DETERMINING THE ABSORBING LEG ON VESSEL PIPING". The nomograph consists of five parallel scales arranged horizontally, used by drawing straight lines across the scales to determine pipe absorbing leg requirements. Reference points 3.1 through 3.5 are marked on the scales, with dashed construction lines connecting them through a pivot line.

Scales (from top to bottom as oriented in the figure):

1. NOMINAL DIAMETER (INCHES) — values listed: 72", 60", 54", 48", 42", 36", 30", 24", 22", 18", 16", 14", 12", 10", 8", 6", 4", 3", 2". Reference point 3.4 is marked on this scale near 30".

2. PIPE STRESS (POUNDS PER SQUARE INCH) — values listed: 10,000; 12,000; 14,000; 15,000; 16,000; 18,000; 20,000; 25,000; 30,000; 35,000; 40,000; 45,000; 50,000; 55,000; 60,000. Reference point 3.1 is marked near 14,000–15,000.

3. PIPE LENGTH — values listed: 200, 100, 70, 50, 40, 30, 20, 10, 7, 5, 3, 2. Reference point 3.5 is marked near 20.

4. PIVOT LINE — a single horizontal reference line with no scale values; construction lines pass through it. Reference point 3.3 is marked on this line.

5. TOTAL THERMAL EXPANSION (INCHES) — values listed: 20, 15, 10, 7, 5, 4, 3, 2, 1.5, 1.0, 0.5, 0.4, 0.3, 0.20, 0.10. Reference point 3.2 is marked near 0.20.

Two dashed construction lines are drawn: one from point 3.2 (Total Thermal Expansion) through point 3.3 (Pivot Line) to point 3.4 (Nominal Diameter); another from point 3.1 (Pipe Stress) through point 3.5 (Pipe Length) to the pivot line, illustrating the procedure for using the nomograph.]
