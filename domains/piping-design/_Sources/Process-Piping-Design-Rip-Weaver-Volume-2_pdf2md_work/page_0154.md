*Frs* and *Frd* = *(Fx² + Fy²)*^½

and the following:

*For suction nozzles*
a. *Fxs* ≤ 1.3*w* ≤ 160*D*
b. *Fys* (in compression) ≤ 1.2*w* ≤ 200*D*
c. *Fys* (in tension) ≤ 0.5*w* ≤ 100*D*
d. *Fzs* ≤ *w* ≤ 130*D*

*For discharge nozzles*
a. *Fxd* ≤ (1.8*w* ± *Fxs*) ≤ 160*D*
b. *Fyd* (in compression) ≤ (2*w* ± *Fys*) ≤ 200*D*
c. *Fyd* (in tension) ≤ 0.5*w* ≤ 100*D*
d. *Fzd* ≤ (*w* ± *Fzs*) ≤ 130*D*

End suction and top discharge pump nozzles are limited by:

*Frs* = *(Fzs² + Fys²)*^½

and

*Frd* = *(Fxd² + Fzd²)*^½

and the following;

*For suction nozzles*
a. *Fxs* ≤ 1.2*w* ≤ 200*D*
b. *Fys* ≤ 0.6*w* ≤ 130*D*
c. *Fzs* ≤ *w* ≤ 160*D*

*For discharge nozzles*
a. *Fxd* ≤ (1.8*w* ± *Fxs*) ≤ 160*D*
b. *Fyd* (in compression) ≤ (2*w* ± *Fys*) ≤ 200*D*
c. *Fyd* (in tension) ≤ 0.5*w* ≤ 100*D*
d. *Fzd* ≤ (*w* ± *Fzs*) ≤ 130*D*

Side suction and top discharge pump nozzles are limited by:

*Frs* = *(Fxs² + Fys²)*^½

and

*Frd* = *(Fxd² + Fzd²)*^½

and by the following:

*For suction nozzles*
a. *Fxs* ≤ 1.3*w* ≤ 160*D*
b. *Fys* ≤ 0.5*w* ≤ 130*D*
c. *Fzs* ≤ 1.2*w* ≤ 200*D*

*For discharge nozzles*
a. *Fxd* ≤ (1.8*w* ± *Fxs*) ≤ 160*D*
b. *Fyd* (in compression) ≤ (2*w* ± *Fys*) ≤ 200*D*
c. *Fyd* (in tension) ≤ 0.5*w* ≤ 100*D*
d. *Fzd* ≤ (*w* ± *Fzs*) ≤ 130*D*

## Cast Iron and Aluminum Pump Force, Moment and Stress Limitations

Cast iron and aluminum pumps are subject to the same limitations outlined for steel pumps except that allowable values are much lower. Bending stress is also limited by *Sh*×3 and *Sh*×2 as noted for steel pumps, but the resultant shear force is limited to a 500 pound maximum. Resultant forces are further limited by the following:

1. Suction nozzles:
   *Frs* ≤ 1.6*w* ≤ 50*D*

2. Discharge nozzles:
   *Frd* ≤ (2*w* - *Frs*) ≤ 50*D*

Top suction and top discharge nozzles are further limited by:

*Frs* and *Frd* = *(Fx² + Fy²)*^½

and the following;

*For suction nozzles*
a. *Fxs* ≤ 1.3*w* ≤ 40*D*
b. *Fys* (in compression) ≤ 1.2*w* ≤ 50*D*
c. *Fys* (in tension) ≤ 0.5*w* ≤ 25*D*
d. *Fzs* ≤ *w* ≤ 35*D*

*For discharge nozzles*
a. *Fxd* ≤ (1.8*w* ± *Fxs*) ≤ 40*D*
b. *Fyd* (in compression) ≤ (2*w* ± *Fys*) ≤ 50*D*
c. *Fyd* (in tension) ≤ 0.5*w* ≤ 25*D*
d. *Fzd* ≤ (*w* ± *Fzs*) ≤ 35*D*
