**Figure 1    Schematic of typical horizontal pig trap system**

NOTES:

1. This drawing shows an example of weld end valves for isolating the main pipeline and flanged valves elsewhere.
2. XI = pig signaller, PI = pressure indicator
3. See fig. 5 for code break options.
4. \* indicates the location of an additional valve plus bleed valve in the case of "double block and bleed" requirement.

The schematic is an isometric/3D illustration of a typical horizontal pig trap system showing the following labelled components and lines:

- **MAJOR BARREL** — upper horizontal barrel with PI (pressure indicator) instrument and VENT connection
- **MINOR BARREL** — lower horizontal barrel with PI instrument, VENT, RELIEF VALVE, and XI (pig signaller) instrument
- **END CLOSURE** — at the end of the barrels
- **TELL-TALE VALVE** — on the barrel body
- **DRAIN VALVE** and **DRAIN LINE** — drainage provisions
- **TO CLOSED DRAIN SYSTEM OR SUMP PIT** — destination of drain line
- **PURGE CONNECTION** — on the minor barrel side
- **BALANCE LINE** with **BALANCE VALVE** — equalisation between barrels and main line
- **KICKER LINE** with **KICKER VALVE** — pig launching/receiving connection from main line
- **PRESSURISING LINE AND VALVES** — pressurisation provision
- **BYPASS LINE** with **BYPASS VALVE** — bypass around the pig trap valve
- **MAIN TEE** — connection point to main pipeline
- **PIG TRAP VALVE** — main isolation valve (PI pressure gauge and XI pig signaller shown)
- **PIG TRAP SYSTEM BOUNDARY LIMIT** — dashed boundary line
- **ESD VALVE (IF APPLICABLE)** — emergency shutdown valve on main line
- **MAIN LINE** — the pipeline running through the system
- **MAIN SECTION OF PIPELINE** — indicated on main line beyond the trap
- **ADJOINING FACILITY** — connection at left
- **ISOLATION VALVE** — at the adjoining facility connection
- **CHEMICAL INJECTION VALVE** — chemical injection point
- \* symbol indicates double block and bleed valve locations
