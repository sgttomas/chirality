**Figure 5      Code break for pig traps**

Four sub-diagrams (5A through 5D) illustrate piping schematic arrangements showing the code break boundary between ANSI B31.3 and ANSI B31.4/8 at pig trap installations. Each diagram shows a pig launcher/receiver barrel with associated valves and the location of the code break demarcation line.

- **Figure 5A** (recommended option) — Code break shown downstream of the pig trap isolation valve; boundary line is horizontal (dash-dot) with ANSI B31.4/8 above and ANSI B31.3 below.
- **Figure 5B** — Launcher labelled "LAUNCHER"; ANSI B31.3 region indicated above the barrel; ANSI B31.4/8 and ANSI B31.3 labels appear at the right side of the boundary; code break is a horizontal dashed boundary across the top of the barrel.
- **Figure 5C** (not recommended) — Code break shown as a vertical dashed line between ANSI B31.3 (left) and ANSI B31.4/8 (right), positioned at the isolation valve.
- **Figure 5D** (not recommended) — Similar vertical dashed-line arrangement as 5C; ANSI B31.3 on left, ANSI B31.4/8 on right.

Note: These drawings show examples of all valves being flanged
