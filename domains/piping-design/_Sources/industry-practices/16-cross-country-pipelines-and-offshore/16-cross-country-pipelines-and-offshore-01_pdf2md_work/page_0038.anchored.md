## 5. CONSTRUCTION

### 5.1 GENERAL

Pipeline construction shall be performed in accordance with the relevant sections of the ANSI/ASME Codes, supplemented by this chapter, and shall comply with any additional criteria resulting from the design.

Construction activities close to existing facilities should be planned in coordination with the operations function, as shut-down of these facilities may be required.

The construction contractor shall provide all necessary calculations and procedures to ensure that the pipeline is installed in a safe and timely manner and with minimum impact on the environment. The procedures should include as a minimum:

| :--- | :--- |
| - Safety and Environment | - Safety and Environment |
| - Quality assurance | - Quality assurance |
| - Right of way and trenching | - Pipeline installation (laying initiation, normal laying, pipeline abandonment and recovery, post-installation survey) |
| - Stringing and cold bending | - Riser installation |
| - Welding and non-destructive testing | - Shore approach |
| - Field joint coating | - Pipeline trenching/burial |
| - Logging in, backfilling and site reinstatement | - Welding and non-destructive testing |
| - Roads, railways and river crossings | - Field joint coating |
| - Concrete coatings for river crossings | - Crossings |
| - Permanent markers and barriers | - Fabricated assemblies |
| - Fabricated assemblies | - Cathodic protection |
| - Cathodic protection | - Filling, cleaning and hydrostatic testing |
| - Filling, cleaning and hydrostatic testing | - Precommissioning |
| - Precommissioning | - Preparation of as-built records |
| - Preparation of as-built records | |

The key equipment used by the construction contractor should be fully tested on mobilisation to prove that the requirements of the work can be met. Care shall be taken during construction that debris, muddy water etc., do not enter the pipeline.
