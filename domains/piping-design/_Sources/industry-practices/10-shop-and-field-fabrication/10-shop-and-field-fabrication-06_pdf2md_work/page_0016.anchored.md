ASME/ANSI B31.3 allows an **alternative leak test** when both hydrostatic and pneumatic testing are impractical. See Code Sections 345.1(c), 345.8, and 345.9.

For completion testing of pipelines under ASME/ANSI Codes B31.4 and B31.8, see the *Pipeline Manual*, Section 700.

## 642 Hydrostatic Testing of Piping Systems

A test program should normally be prepared by the design organization, using Standard Form PIM-EF-121, Field Hydrotest Schedule, accompanied by test diagrams (markups of Piping and Instrument Diagrams). These diagrams define the separate systems for test and are coded to designate the test pressures.

Assembled piping systems are often tested with connected small pressure vessels and similar equipment to simplify testing procedures and minimize testing time and construction interference. Form PIM-EF-121 provides for test data for drums, vessels, columns, furnaces and heat exchangers, as well as for piping systems. For a small plant, however, it may be possible to fully specify testing in a few paragraphs in the construction specifications.

Model Specification PIM-MS-3541, Field Hydrostatic Testing of Piping Systems, should be used in conjunction with the Field Hydrotest Schedule. See Section 3 of this specification for limitations on use of valves to isolate instruments, equipment, and sections of piping having different test pressures.

When a system contains one or more subsystems at different test pressures, it may save testing time to first test the subsystem subject to the highest test pressure, then those with progressively lower test pressures, each together with the previously tested subsystems. Some piping and equipment is tested more than once, but filling and draining time and test equipment setup time is saved.

### Determining Test Pressure

ASME/ANSI B31.3 Section 345.4.2 specifies the piping hydrostatic test pressure at any point in the piping system to be not less than 1.5 times the design pressure. When the design temperature is above the test temperature, the minimum test pressure P_T is:

$$P_T = 1.5P \left(\frac{S_T}{S}\right)$$

where:

- P = design pressure, psi
- $S_T$ = stress value at test temperature, psi
- S = stress value at design temperature

$S_T$ and S are basic allowable stresses per Table A-1 of ASME/ANSI B31.3. The value of $S_T$/S shall not exceed 6.5. If testing at P_T would produce a hoop stress in excess of the specified minimum yield strength (SMYS) at test temperature, the test pressure must be reduced so as not to exceed the SMYS at test temperature.
