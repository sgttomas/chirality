**Fig. 1400-3** Key Factors and Recommendations for Hand Operated Block Valves (2 of 3)

| Key Factors | Recommendations |
| :--- | :--- |
| **Use the Correct Packing Type** | - For new valves, use the manufacturer's standard packings if they meet the guidelines discussed in "Packing Guidelines from Valve Manufacturers" on page 1400-41.<br>- The best performing flexible graphite (die-formed rings) valve packings for hydrocarbon service are:<br>&nbsp;&nbsp;&nbsp;&nbsp;◆ Garlock EVSP &nbsp;&nbsp;&nbsp;&nbsp;◆ Simplified Garlock 70#<br>- The best performing flexible graphite packing for field installation is Garlock 1395FEP, Slade 3000G and RM Graphaseal have had mixed results.<br>- The best performing non-graphite packings are DuPont Kalrez and Garlock Teflon.<br>- Before using any packing, check the compatibility of the packing material with the intended service. |
| **Install the Packing Correctly** | - All existing packing should be removed carefully, preferably with a water jet, before installing new packing.<br>- Visually inspect the valve condition to make sure that no obvious flaws, such as a corroded stem, exist. A damaged valve may need to be reconditioned or replaced (repacking alone may not be sufficient).<br>- Manufacturer instructions, if available, should be followed when installing packing.<br>- While packing, each ring should be compressed 2-3%. When the entire packing set is in place, it should be compressed to about 20-25% less than the original height (30% for braided graphite systems). Alternatively, a torque wrench could be used, if available, to tighten the packing gland to the manufacturer's specifications. |
| **Repair Leaking Valves**(1) | - The first attempt at repair should be to tighten the packing gland and fittings. A torque wrench can be used if a bolt torque is specified.<br>- If the valve can be taken out of service, it should be checked for corrosion damage and repacked using low emission valve packing.<br>- If the valve cannot be taken out of service, and it cannot wait until the next shutdown for repair (because the material is toxic or a compliance violation would result), the valve can be leak sealed.<br>- Injection of soft packing can be successful in stopping leaks but should only be used if no other options are available.<br>- There are many factors such as needing staging or a fresh air supply that should be taken into consideration when deciding whether to attempt an immediate repair or to place the valve on the "allowable leaker" list. |
