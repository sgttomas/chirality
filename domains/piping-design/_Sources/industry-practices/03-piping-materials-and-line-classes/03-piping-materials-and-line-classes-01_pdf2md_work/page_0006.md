## 2.2 FIRST LETTER

For the first letter, the code is as follows:

[TABLE: First letter piping class codes]

| Code | — | Description |
| :--- | :---: | :--- |
| A | – | sulphuric acid |
| B | – | hydrochloric acid |
| C | – | caustic |
| G | – | glycol (see Note 1) |
| H | – | hydrogen (see Note 2) |
| J | – | process and catalyst slurry |
| P | – | process-general (see Note 3) |
| R | – | low temperature service, below -29 C (-20 F) |
| S | – | steam and condensate |
| T | – | solids transport |
| U | – | air and water |
| X | – | chlorine |
| Z | – | piping with jurisdiction of ASME Boiler Code |

**NOTES:**

(1.) For glycol/water heat tracing Piping Class refer to Shell STD. 3-3.32, Glycol Tracing - Installation, Class GAA.

(2.) Hydrogen service is defined as process streams containing relatively pure hydrogen or component streams containing hydrogen above a partial pressure of 50 psia at design conditions.

(3.) Process service is defined as the handling of liquid and/or gaseous hydrocarbon materials and also includes lube oil, nitrogen, DEA, sulphur dioxide, carbon dioxide, phenol, ammonia, hydrogen sulphide, glycol other than tracing and boiler feed water.
