## 1.3 CONSTRUCTION CLASSES

**service requirements**

**1.3.1** Piping systems are specified by the designer as one of three quality levels called **Construction Classes**. The appropriate class is chosen by the designer based on severity of service as per Shell STD. 3-1.01, Plant Piping - Design. Construction Class 1 is the highest quality, whereas Construction Class 3 is the lowest quality.

**quality**

**1.3.2** Each Piping Class has one or more permitted Construction Classes tabulated in Section 4.0, Piping Class Listing, based on the construction quality that will result from using the specified piping components, and the extent of inspection and construction procedures. The extent of inspection and construction procedures are described in design, manufacturing and installation standards.

**matching quality to service**

**1.3.3** Piping Classes chosen for an application must be permitted for the design construction class specified by the designer. Use of a Piping Class with a permitted construction class rating that falls below the design Construction Class will result in inadequate quality for the intended service. Use of a Piping Class with a permitted Construction Class that exceeds the design Construction Class will result in excessive quality for the intended service. If no appropriate Piping Class exists, a new one must be generated and approved by Shell Engineering Services Division.

## 2.0 PIPING CLASS ABBREVIATIONS

### 2.1 GENERAL

**2.1.1** Piping Classes are identified by a three-letter code system, (e.g., SAB).

The first letter designates SERVICE, the second letter designates MATERIAL and the third letter designates RATING (ANSI Class).
