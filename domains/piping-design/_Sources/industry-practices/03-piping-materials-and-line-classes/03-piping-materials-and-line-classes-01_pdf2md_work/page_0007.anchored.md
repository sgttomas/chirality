## 2.4 THIRD LETTER

For the third letter, the code is as follows:

- D  –  ANSI 300 (UP TO 260 C (500 F) MAX., EXCEPT STEAM SERVICE 425 C (800 F) MAX.) (SW/FLG'D)
- E  –  ANSI 300 (ABOVE 260 C (500 F)) (SW/FLG'D)

- J  –  ANSI 1500 (SW/FLG'D)

- Z  –  ANSI 150 (FLG'D UNDERGROUND FIREWATER)

## 2.5 SUFFIXES

Piping Class suffixes shall be used in the following cases:

- o **(H)** This denotes either a change in the bolting and/or gasket specification due to higher operating temperature of the piping. Refer to sub-sections 3.4 and 3.5.
- o **(SR)** This denotes piping is to be post-weld heat treated (stress relieved). This suffix is used for Carbon Steel only.
- o **(T)** This denotes Tubing Classes utilizing tubing and associated fittings. Tubing Classes are referenced to corresponding Piping Classes. Refer to Section 5.0, Tubing Class Listing.
- o **(1)** This denotes decrease in corrosion allowance from the minimum standard. Refer to sub-section 3.9.
- o **(2)** This denotes increase in corrosion allowance from the minimum standard. Refer to sub-section 3.9.
