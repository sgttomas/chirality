# 3 Criteria

This specification covers material and component requirements for all new piping systems for Process and Utility Piping Systems built in accordance with ASME B31.3 piping code. Also covered are plants, manifolds, terminals, and interconnect piping built in accordance with ASME B31.4 and/or B31.8 piping codes using 0.5 and 0.6 design (F x SMYS) factors.

## 3.1 General

The line class designation for each piping system will be identified on the piping and instrumentation diagrams (P&IDs) and isometric piping drawings. The Contractor Process Engineer is responsible for checking the complete line designation, especially the line classes on process and instrumentation drawings.
