## 1110 Section 1—General

The Company's HE&LP (Health, Environmental and Loss Prevention) Group fully supports and concurs with the requirements and recommendations of API Standard 2510, *Design and Construction of Liquefied Petroleum Gas (LPG) Installations*, and API Publication 2510A, *Fire-Protection Considerations for the Design and Operation of Liquefied Petroleum Gas (LPG) Storage Facilities*. All new LPG facilities shall be designed and constructed in compliance with API 2510 and API 2510A.

This guideline covers only those areas where Company recommendations exceed or differ from those in API 2510. It is a **supplement** to API 2510 and must be used in conjunction with that document. For easy reference, the organization, numbering and paragraph headings of this guideline match those of API 2510, Sixth Edition, April 1989. Sections are noted as being *additions or exceptions* to API 2510.

### 1.1 Scope

*(Addition)* All new LPG facilities shall be designed and constructed in compliance with API 2510, *Design and Construction of Liquefied Petroleum Gas (LPG) Installations*, which this guideline supplements. This guideline covers only those safety features where Company recommendations exceed those in API 2510. It is intended for Company-wide use. However, it is the responsibility of local management to assess their facility's exposure (the potential human, economic and environmental impact) in the event of an LPG release incident and to decide how closely they will adhere to the recommendations of this guideline.

The philosophy and principles of 2510A, *Fire-Protection Considerations for the Design and Operation of Liquefied Petroleum Gas (LPG) Storage Facilities* should also be incorporated into the design, operation and maintenance of all new LPG facilities. Local management should assess the applicability and value of API 2510A in reducing risks.

*(Exception)* Although the scope of API 2510 and API 2510A covers only **LPG storage and loading facilities**, the principles and guidance contained in this guideline, API 2510, and API 2510A may be helpful in reducing risk if applied to the design and operations of **LPG processing facilities**.

#### Background *(Addition)*

In designing LPG facilities, special precautions are necessary because failure of piping or equipment can release liquid hydrocarbons which quickly vaporize to form a heavier-than-air, highly flammable cloud that does not readily disperse. For this reason, the fundamental objective is to minimize the release of LPG to the atmosphere. This is accomplished by providing high equipment reliability, minimizing the number of connections, avoiding unnecessary equipment, and protecting against inadvertent damage or failure.
