## 1.0 SCOPE

### 1.1

This Practice covers the requirements for identifying service lines on Piping and Instrumentation Flow Diagrams, piping plan and elevation drawings and piping isometric drawings.

### 1.2

Any deviation to this Practice must be approved by the procedure described in REP 1-1-3.

### 1.3

An asterisk (*) indicates that a decision by the Owner or Owner's Engineer is required.

## 3.0 DEFINITIONS

### 3.1

Additional Notes - Designations which identify additional attributes of a piping system, see REP 5-1-1.

### 3.2

Insulation Condition - Designation which identifies attributes of the insulation system:

1. H-heat conservation
2. C-cold insulation
3. PP-personnel protection
4. ET-electric tracing
5. ST-steam tracing

### 3.3

Line Number Sequence - A number assigned to each line starting with Number 1 for each fluid symbol.

### 3.4

Line Service Symbol - The fluid service in each line is identified by a letter symbol. One, two, or three letters may be used for a fluid symbol, see Table 1.

### 3.5

Owner - Phillips 66.

### 3.6

Owner's Engineer - A Phillips 66 appointed engineer.

### 3.7

Pipe Size - More than one pipe size may be required for a line. Each line size is shown along with its physical data. Normally, only one line of a Line Rating Sheet is used for each line size listed. However, for additions, a second size can be included if an unused space is not available. There is one exception - pipe sizes in material classes which require wall calculations must have each size listed independently.

#### 3.8

Piping Material Specification - Specific designation based on pressure class, piping material, service, and temperature. Permissible designations are described in REP 5-2-3. Normally only one material class is assigned for piping covered by a single line number. This requires a piping system to carry two line numbers when a class-break occurs. However, two classes may be included under one number where there is a limited amount of pipe or piping components in the second class.

#### 3.9

Unit Identifier - An abbreviated string of Alpha-Numeric characters used to identify the Plant unit or area to which the line number corresponds.
