Figure 4 HFE Focusing, Work Systems Analysis and further HFE activities

Flow:

1. List Work Systems of Project
2. HFE Focusing Tool
3. Work Systems Analysis Tool
4. Identify HFE activity levels
5. Activity level branches:
   - 0 -> No HFE Input -> Include in BOD and Stop
   - 1 -> Existing HFE standards/procedures -> Include in BOD and Stop
   - 2 -> Existing HFE standards/procedures and HFE Review -> Include in BOD and Stop
   - 3 -> Professional HFE Analysis -> Include in BOD and Create HFE Plan -> Continue with HFE Procedure
6. Identify all Level 2 and Level 3 HFE inputs for the project.
7. Include HFE Requirements in the PEP and proceed.

**Description of activities:**

1. List the work systems that make up the project in the left-hand column in Table 6 (examples are currently provided in the areas of Facilities, Buildings, Human Computer Interactions and Other Human Machine Interaction). Also, list any new technology, job task or work constraint in this column.

2. Address all of the System/Project Performance Factors that correspond to the questions in the Focusing Tool (Appendix 1) and Screening Tool (Appendix 3).

3. Consider the Modes of Operation: Normal (N), Emergency (E) and Shutdown/Start-up (S).

4. Address each blank box with the question, 'What level of HFE input is required (derived from Table 5) to ensure that an appropriate standard is reached in relation to the Performance Factors, for the specified modes of operation N, E and S.'

5. After filling in the blank boxes in Table 6 with the level of HFE required, use the scoring for the various work systems to determine the detailed project scope and identify where HFE input is required in the project

6. Once the input analysis have been completed, identify all of the Level 2 and Level 3 HFE inputs for the project. These activities will require HFE competence and the Level 3 HFE activities will require HFE expertise (Skilled or Mastery). The Level 1 and 2 HFE activities will be carried out by the local HFE focal point (Knowledge).

7. Include HFE Requirements in the PEP and proceed.
