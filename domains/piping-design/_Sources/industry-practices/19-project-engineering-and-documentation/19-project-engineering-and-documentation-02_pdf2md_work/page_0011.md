# Figure 2 Flow schemes of HFE activities during Project Development Phase

[FIGURE: Figure 2 Flow schemes of HFE activities during Project Development Phase]

## Development Phase (BDP) - FED2

- START
- 1: Assemble Project Ergonomics Team (PET)
- Apply HFE in Project?
  - 2: NO -> STOP and Record
  - YES -> Identify hotspots in design + performance issues
- Focusing Tool + Work Systems Analysis (WSA) Tool -> Identify hotspots in design + performance issues
- 3: Identify hotspots in design + performance issues -> Levels 1 & 2
- 4: Identify HFE scope of work -> Level 3
- Develop HFE Plan
  - 5: HFE Plan
- Include HFE Plan into PEP

## Development Phase (BDEP/PS) FED3

- Conduct HFE Analysis (when specified)
  - 7: Investment Justification Results
- Investment Justification Tool -> Specs. and work specs accepted by PM
- Specs. and work specs accepted by PM
  - 8: NO -> Investment Justification Results
  - YES -> Include HFE requirements into PS
- 9: Include HFE requirements into PS -> HFE Requirements
