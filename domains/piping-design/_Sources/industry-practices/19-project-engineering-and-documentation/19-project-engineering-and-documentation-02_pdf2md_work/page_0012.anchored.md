Implementation Phase (Detailed Design & Engineering)

- Determine HFE Implementation Plan
  - 10 -> HFE Implementation Plan
- PM Approval of Plan
  - NO -> HFE Implementation Plan
  - YES -> Include HFE Implementation Plan into PIP
- Include HFE Implementation Plan into PIP
- Execute HFE Activities
  - 11 -> Design Criteria

Implementation Phase (Construction)

- Determine Construction Plan
  - 14 -> Construction Plan of Action
- Construction Plan Approval
  - NO -> Construction Plan of Action
  - YES -> Implement Construction Plan
- Implement Construction Plan

Post Implementation Phase

- Evaluate the application of HFE in the project
  - 17 -> Post Implementation Report
- STOP
