## 1.3.2 Specific definitions and abbreviations

> **Table - Specific definitions and abbreviations** - see [source crop](tables/19-project-engineering-and-documentation-02_p0003_tbl01_specific-definitions-and-abbreviations.png)

| Term | Definition |
| :--- | :--- |
| BDP | Basic Design Package |
| BDEP | Basis Design and Engineering Package |
| CAD | Computer Aided Design |
| CAPEX | Capital Expenditure |
| CCR | Central Control Room |
| CM | Construction Manager |
| Effectiveness | Accuracy and completeness with which users achieve specified goals. |
| Efficiency | Resources expended in relation to the accuracy and completeness with which users achieve goals. |
| EFP | Ergonomics Focal Point |
| GFT | General Failure Types |
| HCI | Human Computer Interaction |
| HRA | Health Risk Assessment (though HRA also means Human Reliability Assessment - an approach used in HFE) |
| HF | Human Factors |
| HFE | Human Factors Engineering |
| HIP | Human Factors Engineering Implementation Plan |
| HMI | Human Machine Interface |
| Hotspot | Problem in the past with a specific area of a project |
| HSE | Health, Safety, Environment |
| HSE-MS | Health, Safety and Environment Management System |
| MHMS | Minimum Health Management Standards |
| OU | Operating Unit |
| PE | Process Engineer |
| Performance issue | Opportunity to improve the performance of the system via design |
| PFS | Process Flow Scheme |
| PEFS | Process Engineering Flow Scheme |
| PEP | Project Execution Plan |
| PET | Project Ergonomics Team |
| PIP | Project Implementation Plan |
| PIR | Post Implementation Review |
| PM | Project Manager |
| PS | Project Specification |
| PT | Project Team |
| RAM | Risk Assessment Matrix |
| SI-HE | Shell Health Services |
| Usability | Extent to which a product can be used by specific users to achieve specified goals with effectiveness, efficiency and satisfaction in a specific context of use. |
