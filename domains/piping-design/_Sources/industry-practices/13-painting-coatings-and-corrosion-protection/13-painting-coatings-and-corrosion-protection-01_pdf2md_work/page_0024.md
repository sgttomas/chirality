## SYSTEM #8

**PURPOSE:** New Work and Maintenance

**TYPE:** Non-Skid Epoxy Mastic

**USE:** For Concrete or Steel Walkway Surfaces where Non-skid Finish is Desired – See Note 2

[TABLE: System #8 Coating Manufacturers and Coat Specifications]

| COATING MANUFACTURER | FIRST COAT | SECOND COAT See Note 1 | THIRD COAT | COMMENTS |
| :--- | :--- | :--- | :--- | :--- |
| PPG Amercoat | New or Existing Coating System | Amercoat 237M | | |
| Carboline | New or Existing Coating System | Indulon 868 HS | | |
| American Safety Technologies (Sherwin-Williams) | New or Existing Coating System | AS-250 | | |

**Notes:** 1. This non-skid coating is applied as a last coat and in addition to the normally specified coating systems as follows. For new non-galvanized steel, apply System #3 before this coating. For new concrete, apply System #15 before this coating. For existing painted or galvanized steel, apply System #2 before this coating. For new galvanized surfaces, apply System #10 before this coating.

2. As an alternative to these non-skid coatings, copper slag may be used in conjunction with System #2 or System #3.
