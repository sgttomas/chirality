From Eq. (5.8), the deflection curve for the right-hand portion of the beam becomes

$$y = \frac{P\beta}{2k} e^{-\beta x}(\cos \beta x + \sin \beta x) \tag{5.9}$$

From which we have the following relations

$$\theta = \frac{dy}{dx} = -\frac{P\beta^2}{k} e^{-\beta x} \sin \beta x \tag{5.10}$$

$$M = -\text{EI}\frac{d^2y}{dx^2} = -\frac{P}{4\beta} e^{-\beta x}(\sin \beta x - \cos \beta x) = \frac{P}{4\beta} e^{-\beta x}(\cos \beta x - \sin \beta x) \tag{5.11}$$

$$V = -\text{EI}\frac{d^3y}{dx^3} = -\frac{P}{2} e^{-\beta x} \cos \beta x \tag{5.12}$$

The above equations can be written with American Society of Mechanical Engineers (ASME) notations [1, 2] as follows:

$$y = \frac{P\beta}{2k} f_3(\beta x) \tag{5.13}$$

$$\theta = -\frac{P\beta^2}{k} f_4(\beta x) \tag{5.14}$$
