The through-run moment can be taken as one-half of the difference of the absolute sum of the moments at both sides of the run minus the absolute value of the branch moment. This is done for each direction of the moment. Because this method involves only the absolute values, it does not matter if the sign is lost or if the sign convention is not consistent with the one implied by the code.
