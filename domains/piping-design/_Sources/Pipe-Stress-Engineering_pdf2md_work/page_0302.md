With all that has been stated about piping loads on tank nozzle, many existing tanks all over the world seem to work just fine without those considerations. In the "Scope" of Appendix P, API Standard-650, judging from past experiences, emphasizes that the method need not be applied to piping connections similar in size and configuration to those on tanks of similar size and thickness for which satisfactory service experience is available. However, engineers are cautioned about this similarity argument. There is no guaranty that just because the tank connection operates satisfactorily for now, it will not fail eventually. The tank shell displacement and rotation swing in cycle for each fill-empty operation. The failure process is accumulated through each operating cycle. It can break when the proper time comes. Therefore, an understanding of the behavior of the connection and its theoretical evaluation is very valuable. At the very least, the piping layout should provide some basic elements for absorbing the displacement and rotation expected from the connection.
