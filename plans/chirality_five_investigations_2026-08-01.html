T5 · The single-owner assumption

  • The singularity lives in one file plus one ruling: the K-* invariants are actor-neutral; human_actors.md has exactly one row ("sole author of binding rulings"), and RD-2 expressly declined delegates (A2) and quorum (A3) in favor of "a single root owner governs the root; one accountable owner per root."
  • Plurality seams already exist: per-loop ownership structure, per-loop decision registers and receipt contracts, RASCI and attribution fields, the capacity-separability doctrine (engineer-of-record ≠ root owner), and the piping D-49/D-52 nondelegable taxonomy — a ready-made template for a scoped human grant.
  • The minimal second-owner amendment is mapped: one allowlist row (with alias scoping), one scoped D-GOV grant borrowing the nondelegable list, one RD-2 clarification — plus the single unavoidable new mechanism: merge-channel identity (a second authenticated GitHub actor; today every merge rides one personal account, territory no doctrine governs).

Every containment device bounds agents; the human is the unbounded terminus (D-GOV-17 makes owner rulings machine-unblockable; supersede-never-edit grants temporal supremacy; the ruling grammar carries no identity). Two owners sharing a surface requires, for the first time, rules that bind a human inside the system — and the record already locates the honest cost: RD-2's declined authentication substrate, which would pressure D-GOV-01 itself.

Cross-cutting synthesis (supervising session)

  • The unnamed-identity pattern. Four instances of one missing object — a durable definition of "the same / matches / who": the runtime's compatibility epoch (OUT-002), the solver's tolerance policy, the App's parity instrument, and ruling authentication. Root cause: the system's sole mechanical identity primitive is byte equality (SHA), and every equivalence class beyond bytes requires a ruled definition that nothing has forced. The gaps sit, without exception, at seams between local areas — none in an interior. Notably, all four domains refused to improvise a local definition rather than inventing one: four consistent absences, i.e., coherent incompleteness rather than incoherence.
  • Consistency stack (assessment, not authority): interiors hold by local coherence and transmitted taste (independently evidenced: fail-closed, user-entered-with-provenance, and evidence-binds-to-bytes each recur across loops that never coordinated); seams need a small number of explicitly ruled shared objects (one exhaustive review found four); currency holds by drift-made-visible-and- triaged, not prevention (documentation's half-life is measured: the thesis drifted behind its own catalog, the App PRD contradicts its own §17, indexes lag code). The identified falsifier: if periodic cross-cutting reviews keep finding new one-question-in-N-places patterns, local-coherence-plus-triage is insufficient and an explicit seam discipline becomes necessary.
  • Candidate instruments discussed with the owner (un-ruled, recorded here as candidates only): a comparison-basis rule in the K-AUTH-2 lineage — no reliance on a "matches/conforms/compatible" claim without a ruled, SHA-pinned comparison basis naming definition, tolerance, and version — with each loop instantiating parameters; and a default four-pillar coherence heuristic (ontology / epistemology / praxeology / axiology, checked locally and program-wide at decision time), evaluated as sound if given operational glosses, a single high-leverage placement, and an explicit surface-don't-conform escape valve.
